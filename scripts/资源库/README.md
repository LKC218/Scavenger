# 前线资产库维护

场景与独立原型的发布契约见已授权执行的[Airbase全图与场景资产双层入库实施计划V004](../../docs/Airbase全图与场景资产双层入库-实施计划.md)。当前revision7已登记133种真实原型及1个全图，技术与限定AI视觉通过、人工验收待审；发布和正式回归见[全图报告](../../reports/断箭/Airbase全图与双层入库验证报告.md)。现有12款角色发布命令不能直接接受整图清单。

## 场景候选与依赖收集

[发布场景.py](发布场景.py)的`candidate_index`只读校验真实清单，将候选投影到既有模型／声音／场景查询契约，保留实际正式revision并单列候选摘要；拒绝遮蔽当前ID，不写正式指针。候选中的技术、AI视觉和人工状态分别保留，不因预览成功将完整范围或网页性能关口置为通过。

[收集场景依赖.py](收集场景依赖.py)提供`--id 资源ID --role runtime或blend或manifest --output 未占用本地目录`。默认读取当前正式登记；增加`--manifest 候选清单`后只读候选。复制前核对依赖闭包、大小和SHA256，保留包内相对层级，拒绝覆盖、越界、链接和目录联接。收集成功只表示复制完整，工程还须用[核验场景依赖.py](../断箭/核验场景依赖.py)独立重开，确认真实链接和打包图像。

候选网页使用`断箭/启动正式资料库.py --serve --candidate 候选清单 --port 独立端口`，禁止候选接管8767。CLI使用`断箭/查询资料库.py --candidate 候选清单 --type scene --json`；关联场景ID可查询独立原型。`验证场景候选.py`使用临时回环服务串行核对Chrome与Edge，结束即关闭；固定正式入口不重启。

## 场景包事务

[发布场景.py](发布场景.py)使用`schema=1`清单：`package_root`指向本地独立收集包，`files`按包内规范相对路径冻结字节、SHA256及依赖，`assets`登记独立原型，`scene`登记整图，`acceptance`区分四项技术、AI视觉及待人工状态。每个原型保留来源键、版本、尺寸、作者锚点与建议锚点、材质、碰撞及细节层；场景保留范围、坐标、逐项覆盖和完整原型ID集合。具体实际清单仍由全图产物阶段生成，不用夹具冒充交付。

`validate`只读核对候选；`publish`要求完整范围、模块化、网页、入库及AI视觉全部通过，人工状态必须保持待人工验收。两者均核对全部文件摘要、真实GLB外部依赖、路径与目录联接、循环和失联依赖。发布共用维护排他锁及预期指针摘要／版本检查，拒绝覆盖已有ID。文件保留包内目录，避免Blender相对链接及外置贴图在复制后失联；只开放冻结`/scene-media/包摘要/相对路径`白名单。

技术通过清单必须提供`acceptance.binding`：`schema=1`、凭证包内路径`receipt`及`subject_sha256`。凭证使用`scene-technical-acceptance-v1`，绑定包根、场景、全部资产和除自身以外的完整文件表，并逐项引用其他验收凭证的摘要及字节。五个关口、133种原型的技术与AI状态和人工待审状态分别核对；仅修改布尔值不能通过发布。

发布新增独立索引快照及`场景登记.json`，场景卡片放在独立`scenes`字段，既有模型／音频集合及运行消费者映射保持兼容。每份文件先复制到独立临时文件，摘要核对后原子落位；中断副本不占最终名称，同一清单可继续，失败产物不自动删除。发布前保存原指针、计划新指针和准备凭证，再原子切换；提交后回执写入失败会用预先保存的原指针原子恢复。切换后中断留下准备状态时，`rollback`仍须匹配实际新指针、计划摘要及完整旧快照；已有后续发布则拒绝回滚。

```powershell
python -X utf8 -B scripts/资源库/验证场景发布.py --output local-data/独立任务/未占用事务验证目录
python -X utf8 -B scripts/资源库/发布场景.py validate --manifest 本地冻结场景清单
python -X utf8 -B scripts/资源库/发布场景.py publish --manifest 本地冻结场景清单 --expected-revision 实际版本 --expected-pointer-sha 实际指针摘要
python -X utf8 -B scripts/资源库/发布场景.py rollback --receipt 本次发布凭证目录 --expected-pointer-sha 本次新指针摘要
```

[验证场景发布.py](验证场景发布.py)在独立沙盒覆盖18种情况，包括候选只读及状态计数、锁、竞争、摘要、真实依赖、路径逃逸、人工状态、未通过关口、ID冲突、验收误绑或缺失、伪升状态、复制中断续跑、回执失败恢复、切换后中断及过期回滚拒绝。它只验证事务，不证明真实模型、全图、浏览器或人工验收通过；真实发布仍在A4关口执行。
