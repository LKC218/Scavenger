先按这组步骤试玩

  1. 点击“全场总览”，按4选择固定翼。
  2. 右键一个靶标，观察自动进场扫射。
  3. 按B，左键拖出至少60米的航线；箭头给方向，中点给落弹区。
  4. 按E取消，观察飞机继续盘旋；C只聚焦一次。

需要读懂的反馈

K拖线扫射，Shift下令追加队列，Esc只退出未提交预览。固定翼不接收Q攻击移动或G地面单轮开火。K／B是本原型快捷键。

速度52米／秒、转率0.55弧度／秒、巡航72至92米均为游戏化参数。炸弹通过实际离机位置和当前朝向预测落点，释放后不制导；建筑会拦截弹道。

统计口径与性能边界
  • CPU P95只计模拟推进，不包括场景矩阵、DOM、GPU和合成。帧时间取真实RAF间隔，完整分位使用正式采样段；图中时间线每秒抽样，P95来自最近最多3600帧，不能当成逐帧曲线。
  • 静态模式冻结单位运动；移动模式在两纵深间往返；交战模式使用开阔地30个恢复靶，摧毁后2秒重生。时间线检查首尾发射与命中继续增加，不把销毁后的空闲片段写成持续交战。
  • 入画数量统计单位标签位置的投影中心；当前所有实例仍提交顶点，没有逐实例视锥剔除。大量重复模型降低绘制调用，但不会自动减少总三角形。
  • 全部样本为独立无窗口Chrome或Edge，同机串行；不代表可见窗口长期试玩、内置浏览器、笔记本、移动端或其他显卡验收。
  • 采样期间地图、数量、负载、画质、声音与音量保持不变。暂停或切到后台会中止采样；镜头可操作，正式测量保持全场总览。

04 / 网页成本的处理先控制重复开销，再决定进一步减面

几何与模拟

同型号按材质和可动部件合并为实例批，镜像节点在烘焙时同步反转绕序。保留外观三角形，贴图上限1024。地面寻路使用缓存网格、二叉堆A*和静态空间网格，邻域避让代替全量两两扫描。

单位卡片每页40个，标签与选中路径最多40个；限制显示不删除真实单位或命令。640／480只降低像素负载，不降低模型顶点、寻路和声音成本。

音频与密集齐射

监听点位于战术中心上方8米，声音不随高空观察相机变远。总音量70%，参考距离100米；240米内最多8路引擎，总声部48，320米外不新建事件。

主音量输入后经过动态压缩、逐声道软限幅与设备输出。1024样本分析窗记录末端抽样峰值；实际混音函数另经离线逐样本检查非静音、增益和限幅，仍不能替代完整战斗波形与人工听审。引擎分段重播，尚未验收无缝接缝。

05 / 可追溯验证规则、键鼠与测量分别留证

本轮解决的问题与可复用经验
  • 普通炸弹最初因进场对准太晚而落后。修正航线前瞻，提前480米引导，并使用真实释放点预测落点；不把普通炸弹改成追踪弹来掩盖偏差。
  • 路径的第二段曾遗漏高度字段，导致NaN包围球。规则通过不能替代实际显示检查；浏览器控制台错误作为失败条件。
  • 单靠动态压缩会放过启动瞬态。补末端软限幅时发现滤镜接线顺序误判，修复设备输出链；旧样本退出正式结论，修正后通过实际波形与战斗采样重新检查。
  • 镜像挂载不能直接使用负尺度实例矩阵；烘焙局部变换后反转三角形绕序，保留材质与部件关系。

详情已沉淀至项目开发经验；模块职责、参数与运行方式见靶场说明。

06 / 下一轮试玩先判断是否容易指挥

  1. 进场等待是否可理解：飞机可能先转向或离开地图进场，关注任务状态、脱离和再次下令的节奏。
  2. 声音是否足够且不过响：分别听坦克主炮、旋翼引擎、GAU-8与炸弹；密集齐射是否盖住关键反馈。
  3. 100单位是否仍容易选中：测试局部指挥、全场总览、分页、混选和子选择；200／500用于探索容量。

后续建议优先补充城市道路堵塞、飞机离图提示和武器攻击结果可读性，再考虑更复杂敌人和战场机制。
