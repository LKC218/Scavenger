# 断箭交互参考研究

`索引交互资源.py`使用现有UnityPy环境只读GUI、单位标签与VFX三个明确候选包；写本轮V003目录的索引、16张GUI图像及两个机炮预设的原始字段关系。不启动游戏、不修改原包、不批量导出全库、不更新共享资料库索引。执行：`local-data/tools/python-unity/Scripts/python.exe -X utf8 -B scripts/断箭/索引交互资源.py`。读取本机已忽略配置；已有原包摘要变化时拒绝覆盖本轮证据；输入包名、大小和SHA保存在本轮索引中。

`审阅公开视频.py`复用公开B站播放接口，不登录、不读取Cookie，检查完整时长、媒体摘要和预览标记。已有视频拒绝覆盖。默认生成时间码联系表；`--字幕 --间隔 0.5`使用现有RapidOCR环境生成底部字幕OCR时间线；`--开始 秒 --结束 秒 --间隔 0.5 --分段 10`仅生成关键片段连续联系表。完整顺序解码不等于逐帧观看，OCR不等于音频转写，必须保存实际观察范围与未知项。

源码和资源边界见[实施计划](../../docs/音效与渲染/断箭交互与空中音效-V003-实施计划.md)，来源与结论见[研究目录](../../research/断箭/交互音效研究/V003-01a1a2af/README.md)。新增来源先检查标准公开接口是否返回完整可播放内容，不绕过登录或访问限制。
