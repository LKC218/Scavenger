# 大地图肃清候选工具

当前只实施G01第一步，G02及后续目标暂缓；后续全部目标在战术演训原型Airbase内搭建和人工验收。移动指挥实施卡见[总计划G01章节](../../docs/大地图肃清-开发目标与人工验收.md#g01-镜头与空地交互样本)，新演训候选使用[独立工具](../战术演训/README.md)。本目录继续维护原8810样本的工具和记录，本轮不修改其脚本或接管其服务。

以下保留原独立候选的工具说明，配套[运行模块](../../src/大地图肃清/README.md)及[开工包V001原文](../../docs/大地图肃清-首批三线并行开工包.md)。新轮次先登记保护，未授权时不接管旧候选和其他服务。

## 入口

| 工具 | 作用 |
| --- | --- |
| `服务.py` | 精确资源预检、不可覆盖源码候选、媒体摘要白名单、独立回环服务 |
| `验证交互.py` | 实际鼠标键盘、地空选择、滚轮锚点、跟随与重置 |
| `验证规则.mjs` | 命令、行为、弹药守恒、弹丸碰撞、爆伤、视野及损失边界 |
| `验证表现.py` | 来源、实际炮口、网格与反馈连接检查；三份回执写独立目录，拒绝覆盖 |
| `核对视听素材.py`、`派生视听素材.py` | 原作定向只读提取、来源核对、网页必要派生与缺项登记 |
| `验证集成.py` | 浏览器载入、真实开火与音频、分档身份检查、逐帧与原生窗口长测 |

## 候选流程

```powershell
python -X utf8 -B scripts/大地图肃清/服务.py --preflight
node scripts/大地图肃清/验证规则.mjs
python -X utf8 -B scripts/大地图肃清/服务.py --prepare
python -X utf8 -B scripts/大地图肃清/服务.py --serve --port 8810
```

`--prepare`冻结全部本批源码、共享加载器、具体媒体身份、Three.js与服务程序摘要。每次生成独立修订，`当前候选.json`只定位本批候选，不切换旧原型入口；服务启动时核对冻结文件。启动后台进程使用无窗口参数并记录自身PID、端口和候选身份，服务须独立登记保护。

```powershell
python -X utf8 -B scripts/大地图肃清/验证交互.py --headless --channel chrome
python -X utf8 -B scripts/大地图肃清/验证集成.py --channel chrome
python -X utf8 -B scripts/大地图肃清/验证集成.py --performance --channel chrome
```

集成默认无窗口冒烟；`--performance`默认前台，`--headless`追加时仅作诊断且不能报正式性能通过。`--channel msedge`分别检查Edge。技术输出在本批本地目录，不覆盖人工结论。

R002恢复轮当时按工程师要求只用内置浏览器，桌面Chrome／Edge正式前台长测没有完成。当前G01按总计划先由工程师在Edge逐项试玩，Chrome补验；正式性能另约条件采样。上述命令保留为工具用法，本次未运行浏览器测试或启停服务。

`验证表现.py`默认将三份回执写入本批`验证回执/`下的独立UTC修订；`--output-dir`指定统一新目录，兼容`--output`时两份侧回执随主文件父目录。任一目标已存在就拒绝覆盖，失败或续跑另选新目录。媒体输入仍限定原`视听/`范围；不把输出边界当作媒体输入授权。详见[表现说明](../../docs/大地图肃清-表现与性能说明.md)。

## 测量边界

主验每场预热30秒、180秒逐帧，组合600秒。固定内部1280×720、DPR1，CSS视口1920×1080；分级构型以正交宽460米、焦点原点、方向0为基准，500全个体另用360米，默认交互仍为360米。460米下角色高度约5.17个内部像素，符合个体／替身阈值口径。记录实际视锥内外数量，初始构型标签不代替视锥计数。

规则Node耗时只测纯规则，不能代替浏览器整帧。主验整帧P95、长帧、模拟欠时、真实GPU与源码／资源身份分别留证；焦点中断的前台样本保持未通过。原生窗口证明只读复用已有验证模块的`NativeWindow`，不操作其他应用。

战斗长测中的本轮重置是受控重复交战，记录各轮身份、耗时及人数曲线，不能称为任务内无限弹药或复活。载荷和必要证据按保护规则保留，等待工程师具体版本确认后再处理旧版退役。
