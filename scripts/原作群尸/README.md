# 原作群尸制作与运行工具

原作防线用`python -X utf8 -B scripts/原作群尸/启动.py --defense`独立进入8798，群体仍由原群体入口进入8797。根目录“打开载具靶场.cmd”已作为8784“战术演训原型”的兼容入口；本模块源码、版本及验收身份保持。见[统一命名说明](../../docs/地图与载具/战术演训原型统一命名-实施记录.md)。

本模块把原作Walker、Runner的LOD2派生为独立运行版，保留原骨架、九段原生动作和013原始工程；提供GPU合批、独立验证台、新旧180秒对比及防线适配。范围见[实施计划](../../docs/尸群研究/原作群尸运行与替换-实施计划.md)，运行说明见[场景模块](../../src/原作群尸/README.md)。

## 当前制作参数

输出为`local-data/断箭/批次/BA-26273833-014/`；原始013工程只读。运行GLB每款一个蒙皮网格、一个材质，46个原骨架节点及9段原生动作。Walker330、Runner447三角形，256默认贴图。首帧偏移仅在运行派生中整体归零，原始工程、片段名和相对关键帧间隔保留。

Blender网格属性中的源切线为留档数据，不是顶点颜色。运行GLB剥离导出器附带的COLOR辅助属性，原始数据仍在原工程和派生工程中。Meshopt解码复用本机Three.js已有加载器，不引入新安装或在线依赖。

## 测试与采样

```powershell
python -X utf8 -B scripts/原作群尸/启动.py --start
python -X utf8 -B scripts/原作群尸/验证运行.py
python -X utf8 -B scripts/原作群尸/验证运行.py --performance --headless
```

工程师选择继续使用电脑，本轮正式矩阵使用无窗口GPU压力对比，不当作独立前台稳定60帧验收。旧有窗口节流样本保留为不合格条件记录，不与正式矩阵合并。每组固定640×360、相同镜头与30Hz群体逻辑、10秒预热、180秒记录；两款各半，旧十三款均匀分配，循环顺序为500、650、800各先旧后新。帧时间、GPU有效样本、CPU分段、实际入画、持续动画、模型分布、三角形、绘制和模拟欠时分别保存。

正式数据在`local-data/原作群尸/V001-01a1aa48/样本/`；测试任务标记在`长测/无窗口/`。统计分析和图像整理在全部采样结束后执行；长测期间不运行其他WebGL测试、Blender或报告分析。

初轮48Hz为参数探索，完整保留。全顶点采样检查发现帧间峰值约5.3毫米，改为96Hz后降至约1.74毫米；最终六组对照使用`--run 高精度九六`单独归档，不把两轮混用。

## 生命周期

开始前登记源013、运行014、工具、冻结源码、样本和实际V003声音图像依赖。长驻8797与8798分别交接保护，不能借原作替换关闭8794或其他会话保护。旧卡通来源、主工程、正式库和分享包按实际消费者分别审计；迁移默认入口不等于已经完成文件退役。缓存及旧运行修订按冻结身份登记，工程师对具体候选验收后才accept。
