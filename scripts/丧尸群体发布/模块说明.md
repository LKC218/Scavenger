# 丧尸群体测试

这是分享包内的独立运行模块。页面通过本机服务读取可移植资源清单，并加载十三款固定角色。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html`、`界面.css` | 页面结构、控件、状态面板和响应式布局 |
| `入口.mjs` | 生命周期、固定步长、输入、采样与界面更新 |
| `群体.mjs` | 场地、流场、目标、空间网格和局部分离 |
| `角色.mjs` | GLB加载、骨架克隆、动画混合和角色计数 |
| `角色配置.mjs` | 角色清单检查、固定种子分配和逐款汇总 |
| `场景.mjs` | 镜头、光照、障碍、投影、拾取和视锥计数 |
| `统计.mjs` | 帧时间分位数、GPU查询、采样和文件导出 |

群体模拟每显示帧最多追七个 1/30 秒步长。动画使用真实时间推进。性能统计的 FPS 按总帧数除以实际帧间隔总和计算，P95 和 P99 取真实长帧分位数。

修改源码后应重新启动服务并重新采样；正在运行的服务会拒绝使用源码摘要不一致的新样本。操作、调试和修改示例见包根目录的`开发者阅读说明书.md`。
