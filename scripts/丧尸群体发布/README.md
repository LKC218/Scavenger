# 丧尸群体发布工具

本模块从冻结的十三款角色交付生成两个独立交付物：

- 运行研究版：可移植源码、十三款256／512 GLB、固定Three.js、报告、研究摘要、运行服务和开发者阅读说明书。
- 完整研究版：在运行版基础上加入原始GLB、Blender工程、制作与回读资料、完整性能样本、统一库元数据和完整Three.js源码。

## 安全边界

- 生成器拒绝覆盖已有发布目录。
- 发布目录默认位于`local-data/丧尸模型/发布/`，不进入Git。
- 运行版只生成相对路径清单，不读取原项目统一资源库。
- 完整研究版原样保留本地证据，因此部分回执可能包含制作电脑路径；它不应作为公开网站或正式游戏运行目录。
- 两个包都不代表独立Chrome／Edge前台性能或人工外观、动作已经验收。

正式版固化与候选批次生成分开。内部批次保留可追溯编号，对外正式包使用稳定中文名称；固化脚本校验来源回执、SHA-256、ZIP CRC和归档条目后只复制交付载荷，不改写包内代码或资源。

开始新一轮时先建立独立清理任务，用`protect`登记读写范围并运行`status --task 本轮任务名`。发布输入只读保护，迁移和依赖核查完成前不关闭登记。

## 生成

从项目根目录先执行只读检查：

```text
python -X utf8 -B scripts/丧尸群体发布/生成发布包.py --package-id ZOM-SHARE-YYMMDD-NNN --dry-run
```

生成新版本：

```text
python -X utf8 -B scripts/丧尸群体发布/生成发布包.py --package-id ZOM-SHARE-261104-006
```

`--package-id`为必填项；也可以显式指定`--output`改变候选目录。默认输出：

```text
local-data/丧尸模型/发布/ZOM-SHARE-261104-006/
├─ 运行研究版/
├─ 完整研究版/
├─ Scavenger-丧尸群体模拟-ZOM-SHARE-261104-006-运行研究包.zip
├─ Scavenger-丧尸群体模拟-ZOM-SHARE-261104-006-完整研究包.zip
├─ 两个ZIP对应的SHA-256文件
└─ 发布回执.json
```

生成器核对冻结交付、十三款稳定ID、双档文件、技术回执、Three.js固定文件及来源原件。任何输入摘要不匹配都会停止。

## 固化为正式版

候选批次通过工程师确认后，从项目根目录运行：

```text
python -X utf8 -B scripts/丧尸群体发布/固化正式版本.py --dry-run --promotion-basis "工程师确认依据"
python -X utf8 -B scripts/丧尸群体发布/固化正式版本.py --promotion-basis "工程师确认依据"
```

默认把`ZOM-SHARE-261104-006`固化为：

```text
local-data/丧尸模型/发布/丧尸群体模拟-正式版-V1.0/
├─ 丧尸群体模拟-V1.0-正式运行版.zip
├─ 丧尸群体模拟-V1.0-完整研究版.zip
├─ 使用指南.html
├─ 使用指南-桌面预览.png
├─ 使用指南-移动预览.png
├─ 正式发布说明.md
├─ 正式版核验报告.json
├─ SHA256SUMS.txt
└─ 验收证据/
```

旧批次只迁移小型发布回执与核验证据，正式目录不复制解压后的完整载荷。脚本拒绝覆盖已有正式目录，并通过同目录临时目录完成后原子改名。

## 包内核验

运行版：

```text
python -X utf8 -B <运行研究版>/scripts/核验发布包.py --rules
python -X utf8 -B <运行研究版>/scripts/核验发布包.py --rules --browser-channel chrome
python -X utf8 -B <运行研究版>/scripts/核验发布包.py --rules --browser-channel chrome --resolution 512
```

`--resolution`支持`256`和`512`，会同时核对服务实际加载的档位。`--browser-channel`支持`chrome`和`msedge`，使用无窗口浏览器检查真实WebGL加载、500只角色、十三款模型和500套独立骨架。该检查不替代可见窗口性能矩阵。

## 修改与继续采样

开发者修改源码或角色后，在包根目录运行：

```text
python -X utf8 -B scripts/刷新发布身份.py
python -X utf8 -B scripts/核验发布包.py --rules
```

`刷新发布身份.py`重算代码摘要、双档GLB摘要和包内文件清单。源码或角色摘要变化时，会标记包为局部修改；角色变化还会建立局部交付身份，原始上游身份仍保留在清单中。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `生成发布包.py` | 白名单复制、可移植清单、两份目录与ZIP、发布回执 |
| `固化正式版本.py` | 复核已验收候选并生成稳定命名的正式ZIP、指南、核验报告与摘要清单 |
| `发布服务.py` | 包内只读白名单服务、可选256／512档、采样归档 |
| `核验发布包.py` | 清单、摘要、使用指南、内部服务、Node规则及可选浏览器冒烟 |
| `刷新发布身份.py` | 修改后的源码、资源、交付身份和校验和刷新 |
| `运行包README.md` | 包根启动与操作说明 |
| `使用指南.html` | 离线展示解压、WorkBuddy新建任务及添加项目文件夹流程 |
| `assets/WorkBuddy操作截图.png` | 使用指南内嵌的操作截图 |
| `已知限制.md` | 分享包的结论边界 |
| `许可与来源.md` | 模型署名、修改说明及Three.js许可 |
| `模块说明.md` | 包内群体模块逐文件入口 |
| `完整研究包说明.md` | 完整研究资料导航 |
