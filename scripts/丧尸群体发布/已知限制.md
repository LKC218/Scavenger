# 已知限制

## 实验状态

- 十三款角色、双档 GLB、统一骨架朝向和冻结交付身份已通过技术核验。
- 内置 Chromium 的十五组矩阵和 500 只开阔／通道 180 秒样本已归档。
- 独立 Google Chrome 与 Microsoft Edge 的原生前台矩阵仍属于单独验收项。
- 人工外观、步态观感和目标设备性能不能由文件技术通过代替。

## 模拟范围

- 模拟固定为 30Hz，显示阶段使用插值。
- 群体避让是平面软分离，没有完整人群物理、足部 IK 或动态碰撞。
- 当前实验不包含载具战斗、伤害、死亡、攻击或正式游戏胜负规则。
- 5000 只是界面保护上限，不能写成已验证的 60 FPS 容量。
- 500 只是当前内置浏览器条件下的最高双场景已通过档，不能外推到其他硬件、浏览器、分辨率或完整战斗负载。

## 性能口径

- 平均 FPS 不能单独代表稳定程度，必须同时查看 P95、P99、长帧比例、模拟欠时和视锥内数量。
- CPU 分项不包含完整 GPU 时间；GPU 查询不受支持时应显示缺项。
- 页面记录几何与纹理资源数量，不代表总内存或显存字节数。
- 修改源码、角色资源、贴图规格、采样镜头或画质后，旧样本不能直接作为新版结论。

## 运行边界

- 页面依赖 WebGL 2，不支持时会在页面显示初始化失败。
- 本机服务只监听 `127.0.0.1`，不提供局域网或公网部署。
- 采样写入包目录，因此包目录需要可写。
- Windows 原生前台核验只适用于 Windows。其他系统仍可运行模拟和手动导出，但自动前台验证保持未通过。
- 包内不包含 Blender、Playwright、浏览器或操作系统运行时。
