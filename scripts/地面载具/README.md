# 地面载具共通能力检验台

[服务.py](服务.py)提供独立的本机白名单服务，首版仅用于地面载具共通能力和已核实武器的检验。页面及规则位于[src/地面载具实装](../../src/地面载具实装/)。本入口尚未接入Airbase地图、尸群或完整肃清任务，不替代8784战术演训原型、8794通过版或8798候选。

## 启动

先按[维护清理规则](../../docs/版本退役与缓存清理规则.md)为本轮制作及长驻服务分别登记读写依赖，再从项目根目录运行：

```powershell
python -X utf8 -B scripts/地面载具/服务.py --serve --port 8809
```

浏览地址为`http://127.0.0.1:8809/`，控制台按Ctrl+C结束。仅绑定127.0.0.1；占用端口直接失败，不停止或接管既有进程。本工具不派生后台服务，不修改旧快捷文件或其他服务配置。

## 清单与质量边界

`/manifest.json`从当前正式资料库revision7读取77条`ground`记录，先核对指针登记的全部索引元数据摘要，再检查模型URL、SHA256与字节数在路由中一致。`models`为数组，每项提供`id`、`name`、`quality_status`、`url`、`model_url`、`sha256`、`bytes`、`deployable`、几何概况及原有限制。75条`passed`允许部署；LAV旧车体及Flyer两条`partial`保留目录身份，禁止部署。角色、武器与能力由页面规则按稳定ID明确配置，服务不根据型号名称推断。

只开放这77条记录的默认模型媒体URL；不开放其他型号、工程、声音、预览图或任意目录。原始质量状态保持，不把静态模型技术通过写成武器、动画或完整玩法验收。若正式索引不再为revision7或数量／状态分布变化，服务拒绝启动，由后续任务明确升级契约。

## 请求与来源核验

- 静态白名单为`index.html`、`入口.mjs`、`规则.mjs`、`界面.css`及共享`/compressed-loader.mjs`，启动时冻结字节；没有目录列表。
- Three.js沿用已固定版本及官方来源校验表，提供`/vendor/build/three.module.js`与`/vendor/examples/jsm/`所需模块及解码器，另保留`/vendor/three.module.js`、`/vendor/addons/`别名。
- 模型仅只读引用正式库原位置，不复制媒体，也不在启动时全库计算媒体摘要；每份实际请求的媒体按打开的句柄检查大小和SHA256，相同大小、修改及创建时间的已核验句柄身份缓存至本进程。文件发生变化时重新核验，摘要不符拒绝提供。
- GET与HEAD均执行白名单及文件身份检查，媒体支持单段HTTP Range。未列文件、路径穿越、链接及目录联接拒绝提供，Host限制本机回环地址。
- `/api/status`返回`app=scavenger-ground-workbench`、`version=V001`、PID、端口、来源指针、清单及源码集合摘要，便于消费者核对具体服务身份。

每次启动使用独立UTC时间与随机标识，将冻结静态字节、`源码身份.json`、`运行清单.json`、`服务状态.json`及`访问日志.jsonl`保存在已忽略的`local-data/原型/地空载具实装/V001-01a1ac6a/运行/`下；正常结束追加`服务结束.json`。不覆盖旧运行目录，日志和冻结身份属于本轮凭证，不能自动当作缓存清除。

## 核验入口

`build_manifest()`只读构造清单与媒体白名单；`create_server(port=8809)`构建独立服务并冻结身份，供本轮验证器导入，调用方负责`shutdown()`及`server_close()`。不启动服务即可用`python -X utf8 -B scripts/地面载具/服务.py --help`核对参数。

服务启动后应检查API身份、77／75数量与两条partial、四份页面模块、固定vendor及解码器、真实模型完整与Range请求、未列媒体及穿越拒绝；浏览器再验证模型实际解析与共通能力。HTTP通过不代替画面、武器行为、操作手感或正式性能验收。
