# 前线资产库固定入口使用说明

## 当前统一版本

正式名称为“前线资产库”。8767及原CLI使用revision7：276模型入口、253声音及1个Airbase全图场景。新增133项场景原型保留完整工程；场景、建筑、道具、植被和草丛可分类检索，整图点击后按区域加载。既有模型保留256默认、256远景和512细节档。角色编号0显示为“丧尸角色00”，原包标注“丧尸角色整包（来源对照）”，旧名继续可搜索。当前路径为`local-data/资源库/`，既有980份可读文件身份保持，新增场景按冻结包内层级存储；见[统一库说明](资源与资料库/统一模型音频库使用说明.md)及[全图报告](../reports/断箭/Airbase全图与双层入库验证报告.md)。8768、8769使用同库媒体，十三款冻结交付已重新绑定当前指针。以下V1／V2目录和旧发布命令仅作历史说明。

## 打开与浏览

项目根目录唯一资产库快捷文件为[打开前线资产库.cmd](../打开前线资产库.cmd)。启动器检查固定端口身份，复用已有资料库服务或隐藏启动本机服务，然后从内置浏览器打开 http://127.0.0.1:8767/ 。服务已经运行时，可从内置浏览器收藏夹直接打开固定地址；服务未运行时使用快捷文件启动。命令行使用`--start`只启动服务，兼容参数`--open`仍用于系统默认浏览器。固定端口被其他程序占用时会报错，不结束其他程序。

页面采用“战术资产检验台”：桌面为资产索引、检验台和上下文三栏，底部传输条不覆盖内容；模型库可搜索型号或角色、看图片或按需加载三维、播放相关声音。音效库保留未关联声音，用途、关联和技术状态可组合筛选，并逐条查看事件、检查与来源。窄屏使用单列布局和“切换资产／切换声音”抽屉。切换模型停声，页面默认不自动播放、不自动加载大模型。模型、Blender工程和声音均可“打开文件位置”，由本机服务按当前资产ID与登记URL定位，不接收任意路径。

## 开发者与Agent检索

无需网页服务，在项目根目录执行：

```powershell
python -B scripts/断箭/查询资料库.py --query A-10 --type model --json
python -B scripts/断箭/查询资料库.py --related-to model:US_A10 --json
python -B scripts/断箭/查询资料库.py --type audio --status review --json
python -B scripts/断箭/查询资料库.py --type scene --id scene:BA_Airbase_full_v001 --json
python -B scripts/断箭/查询资料库.py --related-to scene:BA_Airbase_full_v001 --limit 200 --json
```

`--id`精确查稳定ID，`--limit`默认20、最大200，`--offset`分页。JSON包含版本号、命中总数、状态、来源、关联和`local_paths`；查询结果不等于文件已经人工验收。型号标点和全角字符可宽松匹配。不要扫描整个批次或猜文件名。

服务运行时也可使用`/api/search?q=A10&type=model`；字段`id`、`related_to`、`status`、`limit`、`offset`与CLI对应。API不输出本机绝对路径；`/api/catalog`返回网页共用索引，`/api/status`返回应用身份及版本。只有登记媒体能通过`/media/摘要.扩展名`读取，没有目录列表。`POST /api/reveal`仅供页面在本机固定地址调用，要求JSON请求体、当前资产稳定ID及该资产登记URL；只返回文件名，在Windows资源管理器中定位并选中已登记文件。

## 历史数据与维护记录

`local-data/断箭/正式资料库/当前版本.json`指向不可覆盖的版本快照。每版保存资源索引、私有资源路由、来源清单和核验记录。首版直接登记原模型与声音；V2整理后，当前媒体已独立存入正式库的分类目录：

| 目录 | 内容 |
| --- | --- |
| `资源/模型/空中或地面/稳定ID/` | GLB、Blender工程、整体预览 |
| `资源/音效/用途/` | 按摘要共享的WAV；跨用途同内容归入共享分类 |
| `入库记录/` | 必要结构化来源的原样副本 |
| `验收/` | 阶段技术、迁移及页面证据 |

模型目录CSV、音效目录CSV位于`资源/`，便于人工查阅；它们标注版本，实时查询仍使用CLI。`local-data/断箭/README.md`集中导航正式资料与历史批次，`维护/模型音效资料整理/`保存迁移及逐文件分类清单。

旧批次仍作为历史证据和其他任务依赖保留，旧版本快照不回写路径。当前靶场仍引用部分旧声音，不能按“重复”直接删除。新增资源用[增量入库说明](资源与资料库/资料库增量入库说明.md)的验证、发布流程，目录职责及本次核验见[整理报告](../reports/断箭/模型音效资料整理报告.md)。

服务前台调试用`python -B scripts/断箭/启动正式资料库.py --serve`，Ctrl+C停止。默认启动器后台运行的PID和日志位于本地正式资料库，停止前需核对PID及命令行，不能按端口批量结束其他服务。

技术核验：`python -B scripts/断箭/核验正式资料库.py`。源码说明见[模块README](../src/资料库/README.md)。目录不可随意迁移；改路径需要新版本路由登记。

旧交付副本的退役与来源回读使用[显式归档工具](../scripts/断箭/旧版资料归档说明.md)：历史记录保持原样，迁移对照按原记录指纹和具体字段验证，再从同摘要正式副本读取。阶段工具准备候选，独立执行器仅按另行批准的固定摘要删除。956份旧交付副本已执行完成，10份其他对话保护资源及原始证据仍在原位；逐文件回执位于本地阶段002的`删除执行001/`。当前正式查询入口和资料版本不因此切换。

## 已知边界

当前库为276个模型入口、253项声音及1个场景；149项声音暂未关联，250项技术通过、3项待复核，4个既有模型为待修参考。全图及133原型技术和限定AI视觉通过，工程师人工验收待审；来源使用范围保持本机离线研究。浏览器已完成旧模型三档、音效、靶场与群体回归，未逐条听审或验收手机硬件性能。场景完整依赖使用`收集场景依赖.py`的runtime／blend／manifest角色收集，不能只复制外置媒体GLB。
