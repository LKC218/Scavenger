# 大地图肃清-规则与结算说明

## 入口与职责

本模块对应已批准首批开工包的C规则线，版本为V001。实现入口为[规则模块](../src/大地图肃清/规则.mjs)，纯Node验证入口为[验证规则](../scripts/大地图肃清/验证规则.mjs)。公共参数由[配置](../src/大地图肃清/配置.mjs)维护，命令和状态字段见[契约](../src/大地图肃清/契约.mjs)，支撑、墙体和区域见[受控样本场景](../src/大地图肃清/样本场景.mjs)。

规则唯一维护位置、高度、行为、弹药、装填、耐久、弹丸、玩法声源和结果事件。交互提交意图，表现消费状态及事件。音量、画质、视锥裁剪、合批及声音播放数量不会修改玩法结果。三线主循环由集成入口调度。

## 调用方式

```js
import { Simulation } from './规则.mjs';
const simulation = new Simulation({ config, world });
simulation.reset({ preset: 'behavior', seed: 1105 });
const state = simulation.snapshot();
simulation.dispatch({
  runId: state.runId, commandId: 1, unitIds: ['tank-1'],
  type: 'selectAmmo', weaponId: 'main', ammoId: 'heat',
});
simulation.step(1 / 30);
const events = simulation.drainEvents();
```

`reset`更换`runId`、清除旧事件和命令去重集合，有限数量尸群与库存重新建立。游戏中的毁车没有复活入口。`dispatch`返回`{ok, reason, runId}`；同轮`commandId`已处理时返回`duplicate: true`，不重复执行。旧轮命令、无效支撑、不合法目标和永久损失单位均拒绝并产生`commandRejected`事件。诱饵命令允许空的`unitIds`，表示G03受控地面摆放工具。

`step(dt)`累计输入秒数后完整执行30Hz固定步，不丢弃欠步。时刻取`tick * config.step`，装填、瞄准、诱饵、搜索和遗留物均比较绝对模拟时刻；浮点量级的余数归零。感知与空间网格在10Hz更新，移动、接触和弹丸每固定步更新。空间格按16米分桶，候选查询留出感知间隔内位移余量；不会进行全群两两距离检查。

`snapshot()`返回身份稳定、递归禁止写入的实时视图，调用自身不复制全群。单位及公开尸群记录的`position`、`previousPosition`对象复用。每固定步开始将当前坐标写入前态，表现可按主循环给出的`alpha`插值；规则命中始终使用当前真实坐标。重开后的旧快照保留旧轮身份，消费者应同时更换引用。

`drainEvents()`取出本轮尚未消费的事件，再次调用为空。事件含`runId/seq/tick/time`，主循环只取一次再分发给表现和声音；渲染方不得回写伤害。事件类型及基础字段按公共契约，`weaponFired.result`包含弹丸ID和已确定的发射目标点，`impact.result`包含实际命中对象类别、命中数及死亡数。

## 运动与世界支撑

- 地车先核地面支撑，再按半径验证通行。路线使用实体墙外扩角点的可见图；中途及落点再次验证，不以未知高度补0。加速、速度、转向和最终到点半径读公共配置。中间拐角采用小容差抵达，防止提前切角卡进外扩墙体。
- 直升机巡航和作业高度均相对当前合法地面。升降限速，前向预判障碍净空；爬升不足时停在安全侧，未知支撑保持已有高度并显示状态。作业切换只接受合法空地。
- 固定翼持续45米每秒飞行，到指令点80米范围进入80米盘旋。高度为场景最高障碍加80米，支撑未知时`groundY`为`null`，不伪造地面高度。飞机没有本批武器或返航系统。

可见图处理当前受控墙体场景；不宣称已实现任意大地图导航。未知支撑区若没有可证明合法的路径会明确拒绝，不以穿过缺口完成移动。

## 有限尸群与行为

Walker和Runner交替创建，普通生命、速度相同，各有独立相位和状态开始时刻。`homeZoneId`在出生时确定，跨区、追击、搜索、死亡均不改变。初始以24—40只小群为主，少量96只较大群；近处、远处、画外是实际不同位置的互斥出生构型，非只有统计标签。

性能预置按公共配置创建500、2000、5000只，另加8辆地车和2架飞行器。主近场以`(-70,-30)`为中心100米内，远群中心位于`x=125—200/z=−150—−110`，固定种子下含群内偏移的远群距原点仍超过160米；非战斗画外群的中心位于`x=180—220/z=225—255`，避免未加载支撑。画外子集围绕第7辆地车真实接近和接触，分别为32、128、256只；有限耐久耗尽后自然停战，因此持续战斗采样需要集成线按批准规则标明受控重置及其开销。500全个体构型另列，不能替代混合分级性能结果。

分级候选基准由集成线使用正交可视宽460米、原点聚焦、水平角0；交互默认宽360米继续由公共配置维护。个体5像素阈值按1280×720内部绘制缓冲计算。`fixture.actualDrawCounts`应由集成和表现线以当前相机、实际绘制对象及代表人数记录，不能直接抄写出生构型数量；本规则模块只给真实逻辑位置与人数，不生成绘制计数。该候选场景仍需浏览器实测确认远群全在视锥、画外群不进入视锥以及近群满足像素条件。

每轮感知中的`group.center`按当前存活成员的位置计算，`group.home`始终保留出生时的游荡与返回中心；两者职责独立。30米内且无遮挡的地面单位优先于声源；否则从发动机、实际开火和启动后的诱饵中按有效距离和强度选择，同等条件保留当前声源。声音可越墙，移动仍绕实体墙。失去目标或声源后在最后位置搜索12秒，随后返回原群出生位置附近并游荡。动画状态为待机、行走、攻击和死亡；表现可读取`animationState/phase/stateSince/deathAt`。

接触判定使用目标碰撞外缘加配置的1米接触带，只由实际接触者每秒造成2点伤害，不用整群数量远程扣血。地车1200耐久，无恢复；归零发出一次永久损失事件并关闭全部武器。诱饵在5秒后开始发声，最长30秒，50耐久，接触者可将其摧毁。死亡尸群不再感知、移动和伤害。

尸体保留20秒、末2秒淡出、最多200具；残骸30秒、末3秒淡出、最多20具。`remainsVisible/opacity`只表达遗留物，不改变死亡计数，遗留物不阻挡通行。

## 双武器、炮口与命中

首场两个武器均`enabled=false`且`ammoId=null`。默认警戒开启，只有玩家已经选定弹种并启用的武器才自动攻击当前可见目标。关闭警戒仍可执行手动目标；手动目标优先于自动选择。

主炮AP与HEAT各自库存，使用同一个`main.readyAt`。换弹不补弹、不重置已开始装填、不自动切换耗尽弹种。M2独立维护含当前箱在内的120总量、30发箱、5发组、0.1秒弹间、0.6秒组间、6秒换箱。每次实际发射才同时扣总库存和箱内弹数；主炮可在M2换箱期间继续按自身条件发射。两武器可分别禁用和独立瞄准，并按批准网页适配支持移动射击。

`calculateMuzzle(unit, weaponId, config)`只接受已经核实的`muzzle.position/pivot/pitchPivot`。缺失或未核实时禁发，`weapon.reason`说明原因。`turretYaw/m2Yaw`均相对车体，俯仰为绕+X仰角。M2以`m2Yaw-turretYaw`补偿独立偏航，再应用主炮塔父链和车体偏航，避免将挂点固定在车体中心。射界取配置内核实的主炮−10至20度、M2−20至60度。源炮口校准不等于合并炮管网格已经具备独立俯仰动画，机械动画仍由表现与人工验收单列。

射前使用120米地面单位视野和墙体遮挡核对目标，失联取消锁定。攻击地面只要求合法支撑，允许盲射。普通弹射出后保留原方向，不追踪目标；实际三维线段依次比较墙盒和敌人受击盒，采用最早碰点。友军完全不参与拦弹及受伤候选。

AP伤害120和M2伤害18仅打中第一只敌人，无穿透。HEAT在实际爆点到受击中心的三维距离2米内造成180，线性降至7米边缘45，圈外0；允许范围伤害越墙。HEAT直击只进入同一次范围结算，不再额外叠一份完整直击伤害。命中事件位置为实际碰点，不用目标中心伪造撞墙反馈。

## 敌情权限与计数

普通`combat`预置的`snapshot.zombies`仅含当前可见个体及可见死亡记录；内部全逻辑群体不直接外发。公开记录独立于内部可变对象，失联后旧公开引用停止同步位置、前态及状态，避免通过旧引用追踪隐敌。`lastSeen`保存最后目击时刻及当时位置，不追踪当前位置。`heardGroups`只有`listenerId`和8方位粗方位，不提供群体真实中心。隐藏死亡事件不发隐藏坐标。性能预置的`vision: all`是明确标记的技术构型，允许观察全群。

| 字段 | 含义 |
| --- | --- |
| `counts.total/alive/dead` | 全逻辑人数，不受渲染和视野隐藏影响；存活加死亡等于总数 |
| `counts.visibleAlive/visibleDead` | 当前规则视野中的存活及死亡数 |
| `counts.hidden` | 规则视野隐藏的存活数，等于`alive-visibleAlive` |
| `counts.byZone/byHome` | 同一归属区统计表的两个名称，含总数、存活、死亡，不带坐标 |
| `counts.initialDistribution` | 实际出生时的近、远、画外构型数量，死亡后仍保留 |
| `counts.distribution` | 上述构型中当前存活数 |
| `counts.fixtureOffscreenCombat` | 初始画外构型中当前实际近接攻击的个体数 |
| `counts.offscreenCombat` | 上字段兼容名称；不表示当前相机视锥外数量 |

真实相机的可见个体、替身人数、绘制批次和视锥外存活/交战由表现线依据当前相机统计，不能将上述出生构型或`hidden`冒称相机结果。

## 验证与验收边界

从项目根运行`node scripts/大地图肃清/验证规则.mjs`。受控夹具明确使用`fixture: true`简化炮口或内部测试摆位，不进入运行入口。验证覆盖只读视图和失联旧引用、命令去重与重开、地面支撑和绕墙、速度和转向、位置前态复用、直升机升降、固定翼60秒持续飞行、真实构型及画外接触、声源和诱饵、家区稳定、AP实弹、HEAT三维边界及真实撞墙、双武器独立和共享装填、M2全120发守恒、射界、永久损失、尸体时限，以及静音/特效裁剪前后相同结果。

当前19项纯规则测试通过。四档各推进600步、20模拟秒，并报告纯规则P95及峰值；该数字不含浏览器整帧、GPU、加载、窗口或人工操作，不能据此判定网页60帧通过。G01—G04人工操作、画面、声音及Chrome/Edge性能仍等待集成和工程师具体验收。
