# 游戏版整库优化实施计划

工程师已确认整库生成256主体贴图、简化材质和几何细节层，保留512回退与所有原始资源。输出独立于全库第一版，不删除旧文件，不改正式资料索引。

## 任务

1. 固定227唯一模型的输入摘要与处理参数，复用已有骨骼和动作核验规则。
2. 生成256与512两档：底色与透明保留；去掉细微法线；金属度和粗糙度采用原图通道统计值乘原材质系数；遮蔽贴图保留低精度版本，避免破坏层次。
3. 每档生成完整几何与两个静态细节层；骨骼、变形和动作模型保留拓扑，保留机械节点。
4. Chrome及Edge整库加载和结构验证；在固定靶场光照、640及480宽、最近及默认视野进行静态与运动对照；失败项保守回退并记录原因。
5. 同一冻结源码与清单下，对照原运行版、256游戏版与512回退；冷缓存、10Mbps和50Mbps限速加载，区分模型传输与首次可操作时间。数据不外推公网或普通电脑结果。
6. 接入通过验证的游戏版，提供可复现预览、离线HTML报告、查询入口和回退说明；同步文件导航、模块说明和经验。

## 保护和验收

- 不删除原件、旧派生、归档及其他会话文件。新产物内容摘要与回读验证关联；不自动批准已有删除候选。
- 层级、变换、骨骼、动画保持一致，静态细节层仅改几何。精度按实际游戏视角验收，自由贴近查看不作为游戏版清晰度承诺。
- 轮廓、颜色差异用自动指标提示，再保留截图供工程师验收；材质简化不沿用原保真压缩的通过结论。
- 音效沿用已验证派生，保持音量；本轮不重复有损编码。
