## 已确认范围

工程师批准先规范模型与音效，保护其他对话正在进行的任务。正式媒体按模型空地分类、稳定ID及声音用途独立存放；历史提取批次保留证据。采用复制、摘要验证、发布新索引的顺序，清理必须单独依据精确清单批准。

## 任务清单

1. 冻结635条媒体路由及来源清单，盘点历史文件，列出正在使用、证据、重复与临时文件。
2. 正式媒体迁入分类目录，结构化来源复制归档；保留ID、URL、关系和质量状态，发布V2路径版本。
3. 增量入库沿用分类规则，核验新旧摘要、CLI、HTTP、浏览器及原型已有引用；不修改载具靶场或丧尸模块。
4. 更新使用说明、导航、资料目录和整理回执，形成重复文件及其保留原因清单；只有无依赖候选才进入删除确认。

## 保护与验收

保护`src/载具靶场/`、丧尸模型、原型脚本与派生资源、其他研究和报告；共享文档只定点补充本模块说明，不改其他对话段落。没有新提取、型号匹配或游戏集成。

正式媒体目标为`local-data/断箭/正式资料库/资源/模型/空中或地面/资源ID/`及`资源/音效/用途/摘要.wav`。跨用途同内容共用一份，放入共享分类，通过索引保留各自用途。来源归入`入库记录/`，校验回执归入`验收/`。版本快照不可覆盖，旧记录不回写路径。

历史原文件仍可能被旧快照、冻结输入和正在开发的靶场引用，不因内容相同直接删除。盘点清单保存路径、字节、SHA256及依赖原因。整理不停止或修改其他服务，不触碰原游戏。
