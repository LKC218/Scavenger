# 正式资料库整合-实施计划

## 已确认目标

工程师确认以载具为中心整合模型和声音，升级为本机正式资料库，提供固定浏览入口、开发者和Agent命令行查询，并允许后续增量入库。清理仅涉及缓存及被替代页面，模型、声音和提取证据保留；精确删除清单提交后再确认执行。

## 实施任务

1. 建立本地正式目录、稳定资源ID、同一份网页与命令行索引及不可覆盖的版本快照；核对001模型、007声音和009既有关联证据。
2. 实现载具卡片、按需三维预览、相关声音直接播放及全部音效入口，技术细节折叠，选择与滚动状态保留。
3. 实现本机固定服务与启动器、Agent查询、新资源清单校验及显式发布，增量更新保留旧版本、按摘要去重并原子切换索引。
4. 验证资源摘要、双向关系、搜索、HTTP范围请求与边界、切换和异步生命周期。条件允许时进行新页面真实浏览器验收，限制如实记录。
5. 同步使用文档和导航，形成精确缓存与旧页面退役清单，列出依赖、保留范围及预计释放量，等待该清单删除确认。

## 目录与范围

实际源码放在`src/资料库/`，维护脚本放在`scripts/断箭/`。正式索引、版本、私有资源路由、新增资源及入库日志位于已忽略的`local-data/断箭/正式资料库/`。已有大文件使用明确登记的原路径，不复制完整模型和音频。

首版129个美军模型入口、250事件及101已关联声音保持原有质量状态；149未关联、3静音待复核、4模型待修及旧缺项均不改写。正式化表示固定入口、受控登记和更新流程，浏览器功能、实际听审、设备性能分别验收。本轮不开展原游戏动作联动或新资源提取。

固定服务仅绑定127.0.0.1，不开放项目目录浏览。Agent查询无需启动服务，返回稳定ID、状态、关联和本机资源路径。新增资源先验证再显式发布，版本号检查及独占写锁避免覆盖其他更新。

## 清理原则

不按整个批次或整个tmp删除。仅清单文件可退役，已有冻结指纹保留为历史证据；记录旧页面与替代入口关系。新正式索引不依赖旧HTML。其他研究、37个并行候选及提取尝试目录不纳入本次删除。
