# 前线资产库使用说明

正式名称为“前线资产库”，统一浏览模型、角色动画和音效；页面名称及入口统一使用该名称，文档文件名和资源目录继续保留，便于既有链接与跨会话引用。

后续模型或声音优化先参考[复用指南](../项目开发经验/模型与音频优化复用指南.md)，选择资源路线、预算、回退及验收步骤。本页负责当前目录和使用入口，历史优化案例与排障经验单独维护。

旧8770、44433资料库端口跳转8767；13261、23699、47061旧靶场端口跳转8768。旧媒体URL不再提供内容。独立游戏版靶场保留规格验证职责，也从当前库选资源；模型与音效浏览统一使用前线资产库。

## 当前规格

静态模型使用256主体贴图、简化材质、几何层1；远景可显式选择256层2，512细节档使用层1并提高贴图尺寸上限。未接入自动距离切层。骨骼／形变模型保持完整拓扑与动作，只提供256／512贴图档，不进行通用静态减面。512细节档继续沿用现有简化材质。

共享KTX2／Meshopt加载器不依赖CDN。材质去掉法线图，以原图均值保留金属度与粗糙度倾向；机械节点保留，不能合并掉炮塔和旋翼。像素画面并不能消除顶点、材质批次和骨骼更新成本。
