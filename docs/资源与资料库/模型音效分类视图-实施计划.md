# 模型音效分类视图-实施计划

## 已确认范围

工程师已确认按上一轮建议开始实施：将已有101项已确认声音关系接入新的模型分类视图，保留250项声音的用途浏览，其他149项事件单列未关联。当前模型范围为129个美军资源入口，含配置变体，其中126个已有声音，3个无当前单位精确关联。

首版使用008批次；目录元数据继承了旧库的范围说明，因此保留首版记录与工具原件，修正工具后在009批次交付当前候选。001模型清单、005两份分类CSV及核验资料、007全部浏览库文件均只读。新视图引用007现有WAV，不重复复制声音，不根据事件名称或模型外形创建对应关系。

## 实施设计

1. 固定来源及工具摘要，对照005冻结输出校验CSV，对照005输入记录校验001模型清单，对照007冻结输出校验全部浏览库文件。
2. 以真实事件GUID、事件路径和WAV摘要核对101项既有声音；按005的884条有音频引用建立多对多关系。672个空字段、56条未索引引用和3个无单位关联入口继续保存，不转为有效声音。
3. 生成离线候选页面，提供按用途、按模型、未关联三个入口。模型支持空中、地面和型号选择；全部129个入口可查，无声音入口说明原因。详情列出使用型号和用途字段，关联状态与技术状态分别展示。
4. 输出JSON、关联CSV、完整引用复核、README及指纹。检查所有模型与事件集合、双向引用、技术状态继承、相对媒体链接和页面筛选逻辑。

新页面继续采用现有深绿与黄铜色档案样式，单播放器、默认不自动播放，切换时停止前一条。页面无需联网或Three.js；依赖相邻007批次的WAV，不作为独立运行资源包交付。003正式版与007候选入口保持原样。
