# 城市固定翼原型实施计划

工程师已确认五项推荐：音量默认70%并校准衰减；A-10C机炮与普通炸弹；单次攻击后盘旋待命；100单位以60 FPS为主验目标、200及500探索极限；静态简模城市与三型号重复实例。镜头手感已获试玩确认，继续沿用。

## 范围与顺序

1. 保留小靶场对照，增加1200米见方地图、约360米城市、静态建筑及分散靶标。空中使用安全高度，地面与弹道受建筑阻挡。
2. 默认总音量70%，提供滑杆；监听位置与高空观察相机分离，限制远处引擎并发，检查混音峰值。复用既有声音运行时，不改变资料库播放器。
3. 核验A-10C原模型身份、可见挂载和声音关联，只制作独立贴图派生。加入持续前进、受限转弯、移动后盘旋、点目标攻击、拖线扫射与轰炸、脱离、取消和队列。
4. 提供10／30／50／100／200／500数量档位、持续恢复靶标和静止／移动／交战负载，记录总数、入画、模拟、发声及帧时间；重复模型按部件实例化，寻路与邻域查询适配地图。
5. 完成规则、双浏览器实际输入、资源身份、60秒分档与100单位180秒记录，同步说明与可阅读报告。结果按实测声明，不预先承诺所有档位60 FPS。

## 实施结果与验收边界

已实现三型载具、96栋静态简模城市、固定翼点目标与拖线任务、取消／队列、70%音量、分档负载和JSON采样。新规则11组加原规则11组通过；Chrome／Edge分别通过9组新交互、10组原操作、8组镜头回归。真实混音函数经过双声道离线逐样本核验，低电平增益6.02dB、强输入峰值约0.9496且输出非静音。

9组正式性能样本已完成：Chrome覆盖50静态、100静态／移动／180秒交战、200／500交战、100静音及480对照；Edge完成100单位180秒交战。每组先预热10秒。两浏览器100单位180秒P95均7.20ms、P99均7.30ms，最长帧14.20／14.40ms；500单位60秒P95为7.20ms，但最长55.20ms、超过33.34ms共16帧。500为已测探索档，不作为最大容量或全程稳定60 FPS结论。

环境为Windows 11、Ryzen 7 9800X3D、RX 7900 XTX、1600×1000视口，内部640×395或480×296，独立无窗口Chrome 156.0.8078.79／Edge 156.0.4314.58，串行运行。完整数据、源码摘要和操作说明见[可视化报告](../reports/载具靶场/城市固定翼与性能验证.html)；离线、9样本5指标、图片链接、390窄屏与打印样式检查通过。可见窗口长期试玩、实际声音听感、复杂城市拥堵及其他设备仍未验收。

本地回执在`local-data/原型/载具靶场/验证/城市修订1/`，最终执行日志前缀为`稳定-`。音频接线修订前的样本单独保留排障，不进入最终数据。采样源码身份覆盖11个HTML／CSS／模块文件；报告生成器复核当前文件及新交互、压力回执的身份一致后才生成。
