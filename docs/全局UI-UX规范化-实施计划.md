# Scavenger 整体 UI/UX 规范化实施计划

本计划经工程师批准立项，用于将项目 UI/UX 从早期分散的原型探索升级为主流商业游戏级别的**单源设计系统（Game UI Design System）**，严格匹配已冻结的 [渲染风格与分辨率基线规范](渲染风格与分辨率基线规范.md)（`680p + 复古微缩 Stylized`，`16:9: 1208×680` / `21:9: 1588×680` 双画幅，UI 原生高清无滤镜）与 Three.js 60FPS 实时运行预算。

---

## 一、阶段 0 已锁定默认视觉基因

| 决策项 | 锁定基准 | 核心考量 |
| :--- | :--- | :--- |
| **整体颜色搭配** | **`A3` 烟炭双金融合** | 中性微冷烟炭暗底（`#0d0e13` / `#1b1c24`）与 3D 场景 `sepia(0.06)` 轻暖复古微缩色调拉开冷暖层次；常规高亮用耐看香槟金（`#f0d372`），高危警戒与主行动用工业琥珀黄（`#ffb800`）提纯，7 维作战通道色零撞色 |
| **按钮表现质感** | **`B2` 战术微描边精工** | 常规结构按钮保留 `1px` 清晰细描边，悬停边框与文字同步点亮；L1 场景边缘高频提示采用无底框硬黑外描边（`paint-order: stroke fill`）＋ 描边隔离键位徽章；每屏仅保留唯一 L3 主行动 CTA |
| **倒角处理策略** | **`C4` 外柔内锐** | 容器层级（`--r-surface: 12px`）保持现代柔润高级感，内部交互控件（`--r-control: 5px`、`--r-sm: 4px`）收紧以突出军工操控利落感，规避纯切角描边维护开销与无语义混用圆角 |
| **材质性能分级** | **战斗实底 / 菜单毛玻璃** | 实时战斗常驻 HUD 禁止大面积 `backdrop-filter`，统一采用高透暗实底＋极细内高光以守住 100 载具 + 500 丧尸 60FPS 预算；暂停菜单、系统设置与模态弹窗允许毛玻璃景深 |
| **品牌与唯一权威** | **中立自有体系（Code SSOT V2.2）** | 所有离线早期参考目录已全量收口并清退，正式权威统一归入 [src/界面规范/](../src/界面规范/README.md) 与唯一主端口 `/ui-spec`，所有页面文案、令牌与类名采用 `Scavenger` 自身语义 |

## 三、红线与治理原则

1. **历史冻结端口零触碰**：`8767`、`8768`、`8769`、`8780`、`8781`、`8784`、`8811`～`8814`、`8794` 等已冻结验证入口与快照保持原样不回溯修改。
2. **阶段串行、验收驱动**：每阶段交付须给出具体文件摘要、自动检查与浏览器实测结果，获工程师明确确认后再进入下一阶段。
3. **离线自包含**：阶段 1～2 所有 HTML 预览严格满足 `<html lang="zh-CN">`、无外部 CDN、无本机绝对路径，且不依赖 `local-data/` 或 `tmp/`。
