日常先看两份：**[正式策划书](大地图肃清-正式策划书.md)**看玩法方向，**[开发目标与人工验收](大地图肃清-开发目标与人工验收.md)**看当前任务、实施卡和验收要求。查源码时再打开[文件与文档导航](apps-code-map.md)。

## 后续放置规则

现行计划、冻结批准件和有固定路径依赖的资料保留根层，其余专题放入上方四个主题目录；项目经验沿用原目录。新增文档先确定已有落点，避免重复建立总计划或任务状态表。

部分专题保留根层，是因为发布器、审计器、报告模板或协作规则使用了固定路径。本次没有删除文档或改动这些程序；目录分类也不表示历史任务结束、资源通过或旧版获准退役。

实装前制作的所有界面与交互 HTML 预览统一归入 [界面预览目录](界面预览/README.md) 下的分类子目录（`docs/界面预览/<分类目录>/`），并同步更新总索引与分类目录 `README.md` 的功能记录，不得散放其他文档目录。
