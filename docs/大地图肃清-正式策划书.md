# 大地图肃清正式策划书

版本：V002。更新日期：2026年11月6日。

**核心方向：指挥少量军队，在大地图上侦察、诱导并消灭尸群，通过占区补充兵力和物资，最终控制三个区域。**

本文汇总工程师已确认的规则，是设计与实施依据。**G01及后续所有目标，统一在战术演训原型的Airbase地图中搭建、测试和人工验收。** 当前先完善G01，G02及后续目标暂缓；各目标状态、已确认实施卡和人工清单统一维护在[开发目标与人工验收](大地图肃清-开发目标与人工验收.md)。规则确认不等于功能完成或版本通过。

快速阅读：先看首关目标和开发顺序；进入某个目标时，再打开对应人工验收章节。

## 一 首关目标

| 项目 | 规则 |
| --- | --- |
| 推进 | 三个任务区自由选择顺序，无强制倒计时；既有防线只作为专项测试场 |
| 肃清 | 原属该区的尸群必须全部消灭，区外击杀也计入；区内外来尸群也要清除 |
| 占领 | 可移动的地面作战载具在占领点驻守一段时间；补给车不能占领 |
| 中断与失守 | 尸群进入会中断占领或导致失守；重新肃清占领不重复发奖励 |
| 获胜 | 三个区域必须同时处于己方控制 |
| 失败 | 没有可用作战力量，而且无法通过补给或增援恢复；暂时缺弹、正在返补或增援在途不直接算失败 |

## 二 尸群系统

只使用《断箭》丧尸，后续开发和验收退出旧卡通方案。多个模型先增加外观多样性，共用普通尸群规则；特殊能力另设目标。

| 项目 | 规则 |
| --- | --- |
| 分布 | 开局有限预置，不无限刷新；分散小群为主，搭配少量大型尸群 |
| 游荡 | 无目标时在原属区域小范围游荡，跨区行动不改变归属 |
| 吸引与追击 | 诱饵、开火、发动机都会吸引，强弱不同；优先攻击发现的近处地面部队，否则追寻声源 |
| 失去目标 | 在最后声源附近搜索一段时间，再返回原区域 |
| 通行与攻击 | 沿可通行路线绕行，不穿墙、不攀爬、不破坏；近身持续损耗载具耐久 |
| 死亡 | 死亡动作配适量血液和命中效果，不做断肢、尸体物理；尸体按时间和数量上限逐步消失 |
| 群声 | 附近迷雾内可听到模糊群声，只提示大致方位，不透露精确位置和数量；吸引规则与玩家音量设置分开 |

**优化优先：稳定帧率和大群压迫感优先，个体细节服从战术观察距离。**

- 近处保留低模个体，远处允许群体替身：用更便宜的画面代表同一批真实丧尸。
- 首版聚焦待机、行走、攻击、死亡四类动作，错开播放时间，避免整群同步。
- 优先评估复用现有GPU动作共享与合批，再优化模型、材质、动画更新、空间分块和群体调度；技术手段用基准验证。
- 简化表现不改变实际人数、归属、伤害、声音响应和任务判定；画外战斗持续运行。
- 先做分档基准，再叠加行为、视听、地图和载具火力，确定可验收规模。独立尸群成绩不代替完整任务验收。

## 三 镜头与空地交互

| 项目 | 规则 |
| --- | --- |
| 观察 | 固定俯视角，可水平旋转；围绕鼠标指向位置缩放，尽量保持该处不偏移 |
| 聚焦与跟随 | 聚焦定位一次，持续跟随单独操作；手动平移立即退出跟随 |
| 点选与框选 | 都按屏幕中的可见机身位置判断，标签和单位卡片可辅助选择 |
| 重叠选择 | 提供地面／空中筛选，全部模式下可循环切换重叠单位 |
| 空中下令 | 以鼠标地面落点为准，显示目的地和高度关联提示，区分机身位置与地面位置 |
| 直升机 | 自动管理巡航高度，投放等任务自动切换作业高度 |
| 固定翼 | 持续飞行，到达普通移动目的地附近后盘旋；攻击任务单独下达 |

移动指挥沿用成熟战术原型：右键按住预览、拖动设置到达朝向、松开提交，Shift追加命令；普通新命令替换当前任务并清空队列。多车保留相对队形并拉开间距，拖朝向时展开横队；空地混选分别安排落点，固定翼在目标附近盘旋。停止、不可达、地形准备和路径反馈的完整规则见[总计划G01实施卡](大地图肃清-开发目标与人工验收.md#g01-镜头与空地交互样本)。

镜头先用已有地面车、直升机、固定翼作交互样本，不提前展开空中车型批量开发。最近观察距离以群体和战术操作为依据，不以查看丧尸个体细节为目标。

## 四 载具战斗与表现

既有载具交互重新设计，不把旧参数和旧验收直接套入新系统。保留本策划玩法，操作、武器和弹药机制参考《断箭》，数值适配网页地图。

| 项目 | 规则 |
| --- | --- |
| 武器与弹种 | 均由玩家手动选择；按已核实装配条件允许不同武器同时开火，各自装填，可单独禁用 |
| 地面警戒 | 可开关、默认开启；只用玩家已选武器和弹种攻击可见有效目标，手动目标优先，不自动换武器或弹种 |
| 首批友军规则 | 无友伤，友军不拦截弹丸 |
| 弹药 | 各武器分别记录有限库存；同一武器的不同弹种不能同时发射 |
| 弹丸 | 建筑、墙体拦截弹丸，在实际碰撞处命中或爆炸 |
| 爆炸 | 只按爆点距离计算，允许隔墙受伤；中心高，向边缘逐渐降低 |
| 地面射击 | 支持对地的武器可向指定地面盲射，但不能锁定视野外敌人；纯防空武器不因此获得对地能力 |
| 生存 | 载具有耐久，被摧毁后本局永久损失；维修不能复活已毁单位 |
| 碾压 | 允许重型履带车辆碾压，代价和限制必须另行设计确认 |
| 命中与爆炸特效 | 按弹药类别区分、分级表现，清楚表达威力，避免烟尘长期遮挡指挥 |
| 范围提示 | 选择武器或下达相应命令时显示射程、射界、爆炸范围，平时简化 |
| 毁车残骸 | 保留一段时间后逐步消失，只作视觉表现，不阻挡通行 |
| 飞行特效 | 直升机低空起降、悬停或作业时按地表触发下洗效果，巡航时减弱或关闭；固定翼发动机和尾迹按机型、状态触发，不统一常驻长尾迹 |
| 远近景 | 近景完整、远景简化，不改变伤害和战斗规则 |

每车型和弹药单独列出移速、射程、命中精度、伤害与影响范围、弹量、装填、换弹、制导和移动交战条件。原作值、网页候选值和最终接受值分开记录，不用现实数据或旧试验值冒充原作值。

每车型同时登记动画来源：原作片段、代码驱动及待补动作分别列清。当前首批载具以原作模型／节点配合网页驱动动作，完整机型专属动画未因此完成；丧尸原生骨骼片段另按其GPU运行派生验收。

视听素材先定向核验并提取原作可用内容，再适配网页；缺项或无法适配处制作网页特效、临时合成群声候选，工程师试听／看效果后决定保留。素材提取、规则正确、画面完成、人工通过分别验收；首批已按批准范围进行定向提取，结果仍待对应检查与人工确认。

## 五 侦察 诱饵与后勤经济

| 项目 | 规则 |
| --- | --- |
| 开局情报 | 标明三个任务区和后方站位置，敌情通过侦察获取 |
| 迷雾 | 探索过的地形保留；敌人仅在当前己方视野内显示，失联后保留带时间的最后发现位置，不跟踪隐藏移动 |
| 任务提示 | 显示各区原属尸群剩余数量，不暴露视野外位置 |
| 诱饵 | 直升机运输投放，投放前设置延时，落地后计时启动；限时生效、可被摧毁，启动后不能关闭或回收 |
| 诱饵补装 | 后方消耗补给物资补装，运输直升机携带数量有限 |
| 占区收入 | 首次肃清并占领奖励一次性点数，用于购买部队或补给 |
| 物资 | 统一一种补给物资用于补弹和维修；后方库存有限，购入后仍需运输，不直接补满前线 |
| 前线补给 | 补给车装载后运往前线；双方停稳，受补单位停止开火；按实际交付消耗物资 |
| 回站补给 | 地面作战单位可回后方站，直接消耗库存补弹、维修 |
| 地面增援 | 从后方固定入口进场，再由玩家调往前线；召集价格包含首批弹药 |
| 部队上限 | 在场部队与在途增援共同占名额；毁车后可花点数召集替代部队 |
| 后方安全 | 站点不可被摧毁，但尸群仍可攻击站内车辆 |
| 空中后勤 | 弹药有限，返航补弹；首版不模拟燃油 |

## 六 开发目标顺序

| 编号 | 目标 | 完成标志 |
| --- | --- | --- |
| G00 | 基线与资源问题清单 | 地图、整车／变体／部件、模型音效缺项及旧问题逐项清楚 |
| G01 | 镜头与空地指挥交互 | 在战术演训原型中，地面车、直升机、固定翼能看清、选准并完成移动指挥；分步人工验收 |
| G02 | 尸群轻量化与动画基准 | 近低模、远替身和四类动作可读，形成分档预算 |

| G04 | 最小战斗与基础表现闭环 | 一款已核实武器与普通尸群跑通选武器、弹道、伤害和视听反馈 |
| G05 | 全部地面逐款完成 | 先做M1A2和M548A3目标卡，再逐车型完成已批准能力与人工验收 |
| G06 | 全部空中逐款完成 | 逐机型完成飞行、武器、特效、返航，以及运输诱饵和无人机侦察 |
| G07 | 完整三区任务整合 | 迷雾、诱导、占区、点数、增援、运输补给、损失和胜负贯通 |
| G08 | 全组合复验与首关定版 | 完整环境下通过操作、画面、听感及性能人工验收 |

每项目标的检查项见[开发目标与人工验收](大地图肃清-开发目标与人工验收.md)。G05和G06是逐车型工作队列，每款都有自己的设计卡和验收，不能把整个队列当作一次批量通过。

此前首批G01—G04按已通过的[三线并行任务卡](大地图肃清-首批三线并行任务卡.md)组织制作，A交互、B表现、C规则，主对话集成。**当前安排覆盖旧并行节奏：先集中完成G01并交人工验收，再恢复后续目标；G05全地面仍先于G06全空中。** 任务卡与开工包保留原文追溯，不能用其中“600米独立场景”代替现行统一主场景要求。

样本、候选参数、文件白名单及人工条件见[已批准首批开工包](大地图肃清-首批三线并行开工包.md)，当前制作见[候选模块](../src/大地图肃清/README.md)。首批共通的发射、声源、尸群响应、命中和毁伤流程供后续车型复用，每车型仍须配置核对和独立验收。

防空保留对空用途，先验共通部署与已核实能力，对空战斗待有对应目标后补验；不与空中阶段相互卡住。运兵、工程等专用能力逐车另审。模型参考件、待修件不冒充可玩整车；缺项和待补能力保留在清单中。

## 七 人工审核与交付

**每个目标执行：设计与开工确认 → 在批准的批次内制作及集成 → 技术检查 → 工程师人工试玩验收 → 按依赖进入后续目标。**

- 已确认规则直接沿用；开工前只补齐当前目标的范围、操作、依赖、待定参数、检查条件和已知风险，由工程师确认本目标实施方案与开工。在批准范围内连续推进，范围变化另议。
- 完成后交付一个固定候选入口、简短操作步骤、逐项验收清单和已知问题，标明具体版本及文件身份。
- 当前开发电脑、键鼠，Chrome和Edge均验收；手机暂不纳入。
- 以稳定60帧为目标，近景操作优先，远景可简化表现；性能检查贯穿各阶段，最后复验完整组合。
- 数量、画质、测量口径和测试时长在目标卡中先定再测；分别记录整局、活跃模拟、可见数量及替身使用情况，不拿独立样本成绩代替完整负载。
- 技术通过不代替人工通过。未通过回到当前目标；后续变更影响已通过内容时，列出受影响项复验。

## 八 待定项与首版边界

初始编组、区域点位、数量上限、价格、具体车辆与弹药参数、伤害细则、碾压代价、镜头与高度参数、尸群分级距离、搜索时长、尸体／残骸／音效预算，进入对应目标卡审核，不在总纲中擅自定值。

特殊丧尸能力、步兵装卸、工兵破障、架桥、两栖、牵引等专用系统另立目标；未批准的能力不自动加入首版。已有确认但本文未展开的操作细节，在目标卡中核对并记录，不擅自沿用旧实现或覆盖旧决定。

旧原型、旧卡通载荷和历史试验资料的退役另按项目规则办理；本次文档整理不删除资产、不更改运行入口、不代表任何旧候选完成新规则验收。
