# 靶场实时阴影实施计划

## 已确认范围

工程师确认允许受控性能开销，以100单位60FPS为主验目标；首轮包含载具真实轮廓投影、建筑遮光及模型自阴影；近景清晰、远景自动简化并平滑切换。

## 实施方案

保留一个固定太阳方向光和环境补光，增加2048阴影图及轻度过滤。显示网格接收阴影，按原可动部件建立共享真实几何的投影实例批，使用固定Three.js版本支持的独立阴影相机层，仅在阴影通道绘制。按灯光视锥筛选投影实例，包含画外可能投影的载具；不以缩小阴影相机替代实例筛选。

阴影相机跟随当前视野，覆盖可见接收者、建筑高度及可见空中单位，按阴影像素对齐以降低平移抖动。近景关闭底部假阴影，拉远时真实阴影强度降低、简化阴影逐渐出现；总览停止阴影图更新。摄像机操作、战斗和音频参数不变，原模型及声音只读。

## 执行结果

三型轮廓、建筑遮光、可动部件矩阵、画外投影者、远景渐变、真实键鼠及连续重置通过。六组近景有声60秒采样完成，100单位两浏览器实时模式整帧P95为7.30／7.20毫秒，500探索7.20毫秒。Chrome的100单位GPU P95增量约3.68毫秒，超出最初约2毫秒的参考；Edge约0.76毫秒。保留差异，不承诺零开销或普通设备同样达标。

离线图片切换、链接、390像素窄屏与打印样式通过。实测条件与可玩验收边界见[实时阴影报告](../../reports/载具靶场/实时阴影验证.html)及[完整说明](../../reports/载具靶场/实时阴影验证.md)。当前独立服务入口读取本地阶段身份，不将临时端口写成永久配置；长期可见窗口手感由工程师试玩验收。

## 验收

100单位整帧P95不超过16.67毫秒；新增GPU时间约2毫秒作为调优参考，不作为尚未测量的承诺。总览降级需连续，近景应看见真实实体轮廓及建筑对载具的遮光。验证需覆盖偏移条纹、悬浮、漏影、画外投影者和重置释放。先验证真实网格，预算不足再考虑投影专用减面；本轮不预先降低显示模型质量。

官方参考：[阴影说明](https://threejs.org/manual/pages/shadows.html)、[阴影参数](https://threejs.org/docs/pages/LightShadow.html)。具体层筛选以本地固定0.187.0源码为准。
