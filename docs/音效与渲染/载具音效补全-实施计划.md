# 载具音效补全实施计划

工程师已授权自行判断、实施与测试。本轮保留已通过的镜头、武器规则和城市范围，只调整载具声景。

## 方案与任务

1. [x] 通过正式资料库稳定ID复核M1A2、AH-64D、A-10C机械声及用途；三型均有MoveEvent，没有独立发电机命中。
2. [x] 从三份有限事件渲染派生单声道循环，裁除起止段并交叉淡化；原WAV只读，来源、参数与波形检查保存在本地。
3. [x] 接入坦克待机与行驶、旋翼悬停与飞行、固定翼巡航与攻击状态；平滑增益与转速，八路机械声加四十路事件，距离衰减与预算可观测。
4. [x] 独立Chrome和Edge验证实际素材输出、状态切换、暂停／关闭／复位、循环跨接缝和节点释放；采样100单位有声负载，500单位检查预算。
5. [x] 更新模块、导航、经验和音效报告，准备8768试玩入口。

## 验收边界

- “补全”指当前三型及已实现动作的声音覆盖，不表示所有武器、车辆损毁、起降或独立发电机均已开发。
- 转速和响度变化是原型混音，不能还原FMOD原生RPM多层参数；循环是本地派生，不将其标记为原游戏原生无缝素材。
- 浏览器波形与状态测试能够证明技术输出；扬声器、耳机的主观音色与响度仍由工程师试玩验收。
- 本轮证据单独存入`local-data/原型/载具靶场/验证/音效补全1/`，不覆盖城市阶段历史测量。

## 完成结果

- 三个派生循环均6.38秒，原件摘要不变；16输入与19媒体路由复核通过。
- Chrome与Edge各七组真实音效交互通过；三型各14秒输出连续，关闭与暂停清零，切场景无残留。原交战与固定翼规则各11组通过。
- Chrome的100单位180秒、500单位60秒，以及Edge两档各60秒有声交战均P95为7.20毫秒。本轮最长14.30毫秒，超过33.34毫秒帧为0；抽样总声部最高48、机械声最高8，节点登记与场景数量相等。只适用于本机独立无窗口条件，不承诺500单位长期容量。
- 离线HTML的四样本四指标、声音指标切换、本地链接、390窄屏及打印样式检查通过；8768身份及三份新循环的HTTP Range读取通过。人工设备听感待工程师验收。
