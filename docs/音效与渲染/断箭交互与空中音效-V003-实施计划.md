# 断箭交互与空中音效实施计划

## 任务与当前状态

任务为`空中载具射击命中音效-V003-01a1a2af`，同一轮工程师追加《断箭》的移动、点击UI、攻击判定与可提取效果迁移，统一使用V003候选输出，不另复制多套原型。输出位于`local-data/原型/丧尸防线/V003-01a1a2af/`，旧V001和V002继续保护。当前已完成原事件及原始弹药关系核对，已修改运行源码并按需提取16张GUI原图与两份机炮VFX预设关系；最终浏览器回归通过，8794已打开等待工程师试玩。曾按当时授权启动原游戏，但尚未进行有效实机观察；工程师随后指定改用公开视频，已退出原作并核对进程结束。

## 已确认的音效修正

直升机M230射击沿用原事件；弹药10的正常命中预设指向`SFX_Explosion_20-30mm_FAST_US_HE`。A-10C的GAU-8射击指向`SFX_AIR_PLANEGUN_30mm_GAU8_US`，弹药293指向`SFX_Explosion_20-30mm_SupFAST_HE`。当前原型确实用了这些游戏内事件，而不是自制占位声。

GAU-8在原FMOD元数据中`oneshot=false`，含`Loop_Count_MG`和`To_Release`；当前逐弹重播长事件不符合持续扫射语义。两类命中为一次性事件，但现有约10秒有限渲染有前导空白和长占位，且没有实体／地面／空中终止语义。先核对原参数和波形，再修正持续射击、停火尾音、命中触发与预算。不得只换成名字像血肉的其他事件，也不得把`SurfaceImpactShell`默认值1未经核验解释成某种材质。

## 交互迁移范围

| 层次 | 首批目标 | 依据与验证方式 |
| --- | --- | --- |
| 选择与编组 | 点选、框选、追加选择、同类选择、子选择与编组反馈 | 官方键位、公开视频连续操作与本机构建静态数据逐项核对，已有行为先记录差异 |
| 移动指令 | 鼠标指令光标、落点／朝向／队形预览、路径、排队、取消和不可达反馈 | 不把预制体存在当成原作鼠标语义证明，关键条件需要运行或视频证据 |
| 攻击判定 | 目标适配、射程、射界、视线、目标捕获、瞄准、装填、移动射击与武器选择 | 数据表字段、官方说明与实际行为分别留证；与旧规则冲突的部分待工程师选定 |
| 视听效果 | 原图标、选择标记、指令标记、炮口、曳光、击中、爆炸和原事件声音 | 小范围按需提取；贴图、网格、材质与粒子参数分别核验，在Three.js重建实际效果 |
| 合并验收 | 三车对丧尸完整流程、真实键鼠、原音与播放调度、有声性能 | 保留丧尸玩法与GPU合批，原始参数与网页适配值分别标注 |

Unity预制体、粒子和逻辑不能直接作为Three.js组件运行。可重用的原图、网格和音频保留来源；输入、命令、判定及不兼容的材质／粒子需按已核实行为重写。当前目标仍为载具打丧尸，步兵小队、敌方载具、联机和经济系统不因原作存在而自动加入。

## 已确认范围与最新研究方式

1. 优先核心选择、移动朝向、队列和攻击反馈；镜头保留当前通过版，不重做完整HUD和全部默认键位。
2. 按核实条件接入移动射击、武器择优和视线；未得到原作公式的评分与训练场数值独立标为网页适配。
3. 采用公开视频与只读静态资料；工程师最新要求替代此前的离线启动许可，后续不启动原作测试游玩。

工程师已回答并确认：优先复刻核心选择、移动朝向、队列和攻击反馈，镜头保留已通过参数；按核实的原作条件接入移动射击、武器择优与视线。工程师最新补充指定自行搜索并观看公开视频，避免打开原游戏测试游玩；此指令替代此前的离线启动许可。原作已退出，后续不再启动、不进入任何对局。

公开视频研究采用来源台账、完整时长核对、连续操作片段与解说交叉审阅。顺序解码仅证明文件覆盖，不等于逐帧看懂或真实按键证明。无法在视频中确认的条件标为未核实，不以常见RTS经验补写。视频研究不影响已授权的网页原型开发和浏览器测试。
