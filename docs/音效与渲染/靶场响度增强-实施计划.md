# 靶场响度增强实施计划

工程师已确认开始实施：默认增加6dB输出增益，提供12dB增强档，保留0至100%总音量，并校准压缩与限幅。

## 任务清单

1. [x] 核对100%近处仍偏小的反馈及当前混音链，保存改前源码身份用于同素材对比。
2. [x] 增加原始0dB、默认6dB和12dB三档；初始总音量采用工程师当前使用的100%，切档平滑，不重启声源。
3. [x] 增益在压缩前后分配，固定原生压缩器阈值，后置最多3dB，保留末端限幅；增加平均输出观测。
4. [x] 比较改前与改后的真实素材近处／中距离平均输出、峰值和密集混音；双浏览器核验控件、静音、生命周期及100单位有声负载。
5. [x] 同步模块、导航与经验，生成独立HTML验证报告并准备试玩入口。

## 范围与验收

- 只调整载具靶场混音和相关控制，不修改正式库、原素材、镜头与战斗规则。
- 6dB与12dB是补偿增益设定；受压缩和限幅影响，强音的实际提升可能较小，必须报告实测值。
- 使用同一份真实素材、相同音量和位置比较平均输出；合成信号只用于低电平增益和极端输入检查。
- 新证据在本地`验证/响度增强1/`，不改写音效补全阶段回执。原始0dB档保留改前混音参数，便于A/B对比。
- 系统、浏览器单独音量尚未排除；自动波形检查不等于人工设备听感通过。

## 标定调整

首轮波形证明原生压缩器自带随阈值变化的补偿，直接调整阈值并叠加后置增益，会使低电平实际提升偏离档位，密集混音12dB档约28.8%的样本接近限幅上沿。排障数据独立保留。修订为固定−8dB阈值、增强前置3／9dB加后置3dB，低电平总提升6／12dB；强音由原压缩器控制。原始0dB档保留改前参数与单位增益。

依据：[Web Audio压缩器处理及自动补偿规范](https://www.w3.org/TR/webaudio-1.0/#computing-the-makeup-gain)。

## 完成结果

- Chrome与Edge各六组本轮响度／控件检查、各七组既有生命周期检查通过，控制台错误0。13素材在两距离、同音量下的平均输出实际提升：6dB档4.55至6.00dB，12dB档6.75至12.00dB；机械底声约6／12dB。
- 原始0dB与改前混音平均输出等价，低电平增益6／12dB准确；48路集中混音输出峰值小于0.951，非有限值0，接近0.94上沿样本占比6dB档约2.46%、12dB档约4.46%。这不是音色无失真结论。
- 两浏览器各完成100单位、100%音量、6／12dB各60秒交战，预热10秒。两档P95分别7.20／7.30毫秒，本轮最长14.20毫秒，超过33.34毫秒帧0；总声部不超过48，机械声不超过8，节点登记与场景相等。
- 报告双浏览器双距离13素材图、四样本四指标、链接脱敏、390窄屏及打印样式通过；正式输入与派生19媒体摘要通过。设备听感仍待工程师试玩。
