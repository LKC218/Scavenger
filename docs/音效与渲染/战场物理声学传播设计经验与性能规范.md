## 一、核心拓扑架构（面向 9km 战场与 60fps 稳态）

全战场严守**「单上下文 + 单共享卷积 + 静态分桶与静态声像池 + 连续声源独立动态链」**架构：

```text
[引擎循环 PositionalAudio (≤8)] ──► engineDuckBus (重爆超压闪避) ───────────────┐
[GAU-8 连续机炮干声]             ──► gunDryInput ────────────────────────────────┤
[重爆 Sub-Punch 次声冲击锤]       ──► subPunchInput (纯干声，不入混响) ───────────┤
                                                                                  ├──► mixInput ──► drive ──► Compressor ──► makeup ──► WaveShaper软限幅 ──► masterGain ──► destination
[瞬态武器/爆炸 1 Src + 1 Gain]   ──► Near/Mid/Far 5档静态StereoPanner ──► LPF ───┤
                                        └─► wetSend (14%/36%/58%) ──► thunderSend ──► 唯一3.6s ConvolverNode ──► thunderOut ──┘
[GAU-8 连续机炮湿声]             ──► wetLpf ──────────────────────► thunderSend ──┘
```

### 不可打破的 5 条拓扑铁律
1. **全局唯一 `AudioContext` 与唯一 `ConvolverNode`**：严禁在单次射击、单颗爆炸或单个单位声源内新建 `ConvolverNode`。3.6s 时变低通滚雷 IR 全局共享 1 份，保证卷积算力恒定（约 `0.8%–1.8%` 单核），不随同屏炮火数量膨胀。
2. **普通瞬态事件严格 `1 BufferSource + 1 GainNode`**：通过 Near (`<260m`, LPF `8000Hz`, Wet `14%`) / Mid (`260–680m`, LPF `2400Hz`, Wet `36%`) / Far (`>680m`, LPF `520Hz` + LowShelf `+3.5dB`, Wet `58%`) 三档静态分桶，每桶预建 5 档静态 `StereoPannerNode`（`[-0.68, -0.34, 0, +0.34, +0.68]`，远距宽度按 `1.0 / 0.80 / 0.55` 收拢），运行期实现 **0 Filter / 0 Convolver / 0 StereoPanner** 分配。
3. **重爆次声冲击锤（Sub-Punch）直入干声母线**：`62Hz → 38Hz` 指数扫频次声锤接 `subPunchInput → mixInput`，绝不送入 Far 桶 58% 混响，保持爆炸瞬间胸腔重击紧实不糊。
4. **超压背景音闪避（`engineDuckBus`）仅压背景不压武器**：引擎循环音经 `engineDuckBus` 汇入母线；`heavy / massive` 爆炸在 `<650m` 内**声波抵达监听点瞬间**（`startAt = ctx.currentTime + delayMs`）触发 `25ms` 压低 `-4 ~ -6dB` → `180ms` 保持 → `0.45s` 回弹，零削波放大重量反差。
5. **统一并发保护与零削波母线**：同类事件 `40ms` 防抖、`±5%` 随机音高去机械感、`350ms` 环形窗口 `1/√n` 能量缩放，末端软限幅保底全程峰值 `<= 1.0`。

## 二、已验证可复用的现实物理声学规则

| 声学维度 | 设计要点与推荐参数 | 对应实现 |
| --- | --- | --- |
| **RTS 虚拟监听点** | 在相机 3D 真实位置与地面注视中心之间向地面下沉 `35%`（保底 `gy + 18m`），避免常规俯视视距把屏幕中心爆炸直接推入 Far 桶 | `computeVirtualListenerPos` |
| **相机右向量声像** | 严禁用世界 X 轴做左右声道；必须以 `(worldPos - listenerPos) · camRight` 投影，旋转视角 180° 严格翻转且远距自动收窄 | `computeCameraPan` |
| **四档声压无断崖衰减** | 区分 `small (780m)` / `medium (1550m)` / `heavy (2400m)` / `massive (3200m)`，采用 `pow(ref/d, 0.78) * endFade` 末端 smoothstep 平滑归零并剔除超距不可听发声 | `ACOUSTIC_POWER_TIERS`、`computeAcousticAttenuation` |
| **物理声速与超远延展** | 严禁给空战事件写死固定 `delayMs`；`0–560m` 严格按 `340 m/s` 线性延迟（`0–1650ms`），`heavy/massive` 超过 `560m` 按指数渐近平滑延展至 `2600ms`；二级错峰事件使用 `delayOffsetMs` | `computeAudioDelayMs` |
| **超音速机炮四层混合** | 参数化 N-Wave 激波脉冲列（支持 `rpm / caliberMm / barrelCount`）+ 实采火药纹理（GSH30/GAU12 交叉淡化无缝切片）+ 地面弹着与马赫锥裂响先行 + 停火真实尾音与共享 3.6s 滚雷 | `createContinuousGunAcousticVoice` |
| **高速战机多普勒与指向性** | 利用帧位移低通估算固定翼速度，零新增节点复用引擎 `playbackRate` 与 `filter`：迎头高亢（最高 `1.24×`、LPF `~5800Hz`），掠过尾喷朝向时音高滑落（`~0.83×`）+ 低频喷流轰鸣（LPF `~2350Hz`、增益 `+26%`） | `computeJetEngineAeroacoustics` |
| **弹体与坠机动态追踪** | 坠机 `BigTurbine_Falling` 与重磅航弹 `BA_Whistle_Bomb_Big`（同屏并发 `≤ 4`）随弹体逐帧更新多普勒音高、距离衰减与相机声像，触地按声波抵达时刻干脆截断衔接重爆 | `updateFallingLoop`、`updateOrdnanceWhistle` |

## 三、性能实测红线与未来大混战扩展约束

- **当前实测开销（V3 满特性）**：
  - JS 主线程：常态 `< 0.10 ms/帧`，密集空战峰值 `0.15 – 0.30 ms/帧`（占 60fps 预算 `1%–2%`）；
  - WebAudio 独立音频线程：常态 `2%–3%` 单核，密集峰值 `5%–8%` 单核；
  - 解码 PCM 内存：`~15–28 MiB`（`64 MiB` LRU 上限内）；GPU 开销 `0%`。
- **刻意不做的低性价比仿真**：不做 3D 地形/建筑实时声学遮挡射线、不做实时音频延迟线重采样。
- **后续接入地面主炮 / 防空 / 旋翼 / 500 丧尸大混战时的扩容预案**：
  1. 复用通用别名 `BattlefieldEventAudioEngine` 与四档声压表，按兵种按需懒加载音轨；
  2. 为瞬态事件补一层**全局同时发声硬上限（建议 `MAX_TRANSIENT_VOICES = 28`）+ 声压优先级抢占**（`massive > heavy > medium > small`）；
  3. 仅在开启调试遥测时每帧采样 `sampleAnalyserPeak()`，正式运行态按需调用；
  4. 多架高射速转管机炮同帧扫射时，可将机炮饱和器 `oversample` 由 `'2x'` 降为 `'none'` 立省一半单声源 DSP。
