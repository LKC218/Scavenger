## 二 历史8810样本操作步骤

选择“G01交互”，本轮有M1A2、AH-64D、A-10C各一个。

1. 左键选机身、拖框、点标签和卡片；切换地面／空中筛选。近、中、远景及旋转后都应选准，标签不遮住其他单位机身。
2. 用WASD或中键平移，Q／E旋转，滚轮缩放。地面落点尽量保持鼠标锚定，点击界面不向战场下令。
3. 选固定翼按F聚焦；再开“跟随”。飞机持续飞行，手动平移立即退出跟随，聚焦与跟随分开。
4. 选直升机右键移动，切换巡航／作业高度；观察机身、地面标记及关联线。固定翼移动到点后盘旋。
5. 在坡台、墙边、未加载／无支撑测试区下令，提示应明确，不把未知高度当平地。

- [ ] 镜头与缩放手感可接受。
- [ ] 机身、标签、卡片、点框选与筛选结果一致。
- [ ] 聚焦／跟随及空中高度、地面落点交互正确。

本节保留旧独立样本的步骤，旧框不因部分认可自动勾选。下一轮请按总计划验收具体演训候选，并注明版本；问题按“操作→预期→实际”记录。
