# 大地图肃清表现与性能说明

## 范围与入口

本模块落实已批准首批V001的B表现、群尸合批、原作视听定向提取及网页适配。入口为`src/大地图肃清/表现.mjs`的`createPresentation`，只读规则快照；镜头、渲染器、主循环、场景墙坡和服务由主入口持有。原作输入来自本机忽略配置，游戏目录始终只读，未启动游戏。

`原作合批适配.mjs`有限复用`src/原作群尸/合批.mjs`的材质、96Hz姿态纹理烘焙和片段采样。原文件SHA-256为`3283abd9753e644c944e66dac4246d69297a47526a42deb648bbcf2faa6e7f76`，本轮不修改旧模块。新适配按稳定个体ID绑定模型、真实高度、原生待机、移动、攻击和死亡动作，循环使用规则相位与状态起始时刻；没有数组序号重分配和`sim.setProfiles`反写。

## 画面与交互数据

载具与尸群读取规则`previousPosition`和`position`，按根主循环提供的`alpha`插值画面位置，规则当前位置继续用于命中与玩法。机身选择取实际插值Object3D和机身包围盒中心；空中单位使用真实高度，`projectUnit`返回画布CSS像素。表现不把相机位置、裁剪和声音预算写入规则。

尸群按逻辑ID保留分级状态：超过160米或低于内部渲染5像素转为远群替身；返回100米内且达到6.5内部像素才恢复个体，中间区域维持原档。阈值以drawingBuffer宽度和镜头世界宽度计算，与CSS显示缩放分开。中距离姿态采样量化至10Hz；共享GPU姿态无需逐只运行AnimationMixer。

远群轮廓在载入时直接用原作GLB待机、走姿烘焙4朝向×2姿态的透明RGBA图集，每模型512×256，两款合计约1MiB。运行时每个远处成员使用两三角形朝相机平面，按真实坐标、方向和动作选择原作轮廓；每款模型合批一次，不逐只求CPU骨骼。逻辑成员仍按12米格保留分组ID映射，不以少量土丘替代可见尸群。500全个体构型强制禁用替身，画外个体仍保留绘制实例。

实际视锥逐帧统计`offscreenAlive`、`offscreenCombat`、`onScreenIndividuals`和`onScreenProxyMembers`。这些字段是当前相机的画外与同屏计数，规则`hidden`直接读`C.counts.hidden`并属于战争迷雾，二者不等价。初始构型的画外分布也不代替当前视锥统计。`identityPreserved`核对当帧可见活体及保留尸体能否被实例和替身成员完整计数。

尸体保留20秒，末2秒淡出，上限200；残骸30秒，末3秒淡出，上限20；瞬时透明特效上限16。死亡时刻来自规则，尸体姿态到片段末帧后保持。远景、视锥和透明预算均只改变表现。超过预算的装饰特效不产生额外命中、声音引诱或伤害。

近100米内的原作个体实际绘制共享实例脚底阴影：每个圆片两三角形，着色器计算软边与23%峰值透明度，全体仅增加一次绘制。位置读取真实支撑高度，朝向由支撑面差分法线确定；未知支撑样本不补零。远群轮廓省略该装饰圆片，符合距离简化口径。尸群不逐只加入实时阴影贴图。`footShadows`、`footShadowCalls`和`footShadowMethod`明确记录当前启用数量及成本，正式性能样本必须保留此配置。

## M1A2真实节点与限制

当前M1A2运行GLB的SHA-256为`2232103474c1d04f3c4c67854cfb6e7427f34e97bea40cacad001933fbcdeb94`。模型上轴为+Y、车头为−Z，根缩放约0.89。主炮使用`turret_0`、`weapon_0_1_2`及`shell_spawn_0_0`，M2使用`turret_0_0`、`weapon_0`及`shell_spawn_0`；已将完整节点父链、局部变换和根系坐标存入本轮本地核对JSON。主炮和M2炮口不同，禁止使用车体中心回退。

主炮塔偏航围绕真实轴重挂烘焙静态炮塔网格，M2偏航使用相对主炮塔补偿，M2俯仰使用实际武器节点。主炮管原本包含在静态炮塔网格中，现已在载入时按冻结源白名单做一次局部运行派生：5个完整独立炮管分量、810三角形，剩余炮塔7690三角形，二者并集等于原8500三角形。材质及position、normal、uv、uv1属性精确复用，不新增面、不裁切三角形，不修改源GLB。派生炮管在父偏航链下绕真实`pitchPivot`的+X轴读取`C.gunPitch`，并继承载具阴影、unitId与机身选择层级。独立110三角形防盾及附件保持，未猜测原作机械绑定。源Weapons表的主炮−10°至20°、M2−20°至60°由根配置维护。

炮管选择来自原始索引位置焊接后的完整连接分量，完全重合及1e-6、1e-5、1e-4米四档核对均得到同一810三角集合；与余部共享重合位置为0，108条边界均在源分量中已存在，没有新增切口，非流形边为0。CPU双视图和完整分量序号保存在本轮本地拓扑凭证。零姿态全部引用顶点与原网格最大误差约3.3e-19米；主炮−10°、0°、20°与车体、炮塔偏航组成的12个组合，实际显示层级炮口与规则炮口最大误差约3.8e-15米。该CPU变换证据不代替重冻后的浏览器画面复验。

## 原作素材与网页适配

定向核对脚本为`scripts/大地图肃清/核对视听素材.py`。主提取读取已核VFX包及AP256、HEAT253和弹19的真实`FXPreset → AmmunitionCollection`链，核对3种预设、609个可达对象，并在32张贴图安全上限内导出候选；超出预算的5项继续列缺项。另一次独立毁伤补充读取`Ground_Unit_Death`和弹药殉爆命名候选，得到121个可达对象及19张贴图。这些毁伤候选没有冒充当前M1A2已证实的运行调用链。原包、Steam构建26273833、UnityFS版本、FMOD库、脚本和UnityPy版本均写入本地来源凭证。

`派生视听素材.py`输出固定网页清单，包含8种音频角色、3种贴图角色，共12条媒体记录、11份唯一内容。Walker、Runner及共同死亡的3个真实FMOD事件已使用游戏随附2.01.11独立库离线渲染；未连接声卡，未启动游戏。Walker与Runner两个事件在本轮默认参数下得到相同PCM摘要，保留各自GUID但不宣称取到了两种不同的群声。网页群声为原事件截取与100毫秒交叉淡化派生，保留原件与事件GUID；不声称原生无缝循环或原游戏的群体混音。M256、M2、两类命中、载具毁伤和引擎循环复用已核正式库媒体的精确副本，保留M1A2字段绑定。

网页已使用原作炮口贴图和爆炸序列帧，按本轮受控大小、透明度与时序播放。Unity HDRP及VFX Graph没有直接移植；原生光照、扭曲、粒子曲线、精确序列时序和外部引用未复现，贴图布局由原名称与画面适配。血液在本次包名称及三种弹药实际InfantryImpact链中未找到独立血液贴图，暂用网页深红碎粒反馈；该有限结论不表示全游戏没有血液资产。残骸使用当前载具网格深色适配，未确证独立原作残骸网格。

## 声音接口与规则隔离

`setAudioEnabled`、`setAudioVolume`和`getAudioState`由表现导出给交互层。开始时关闭声音，玩家手势启用后创建或恢复AudioContext。总音量默认25%，群声最多8声部，战斗声最多16声部；较安静声部可让位。一次性声音使用原技术检查的首尾非静音范围播放，减少原离线事件容器首部静音。

可见且存活的尸群按32米空间格做只读声音聚合，每0.2秒更新一次格内中心、数量与待机、移动、攻击的温和强弱；音量和左右声像逐帧平滑。聚合复用已提取原作群声，属于网页混音适配，不为每只创建声部。可见聚合与不可见粗方位共用8个群声声部，按可听强弱选取，`visibleGroupVoices`与`hiddenGroupVoices`分别记录实际播放数量。音频关闭时跳过表现聚合，规则听觉持续运行。

战争迷雾群声只读规则`heardGroups`的`listenerId`和8方位`bearing`，以听者为中心构造80米粗声像；不读取隐藏尸群真实坐标。关闭声音或裁剪声部不会关闭规则听觉、武器噪声或诱饵。声音引擎移动声只用于低音量装饰，飞行战斗音效与G06没有扩展。

左右声像按声源与听者的平面差向量点乘相机世界矩阵右方向列计算，镜头水平旋转后仍与画面左右一致。不可见事件若没有可发布位置，不从原点补造声音位置。音量、左右声像与裁剪始终不回写规则。

## 诱饵装置反馈

`snapshot.baits`中的已部署声源显示为共享几何、共享材质的简洁装置与地面状态圈，来源明确标记为网页受控样本。`startsAt`之前显示琥珀等待状态，开始后改为浅绿装置与扩散脉冲；`endsAt`到达、`alive=false`或耐久归零后退出。脉冲是状态反馈，不表示实际引诱半径。延时、持续时间、受损和声音噪声规则均由C持有；本模块不新增投放流程、不回收玩法资源。`baitVisuals`、`activeBaitVisuals`及`baits`状态摘要用于核对画面是否实际接入，文字倒计时与耐久由交互层显示。
