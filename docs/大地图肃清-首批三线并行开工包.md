## 一 建议批准的首批范围

- 一个主对话统筹，A交互、B表现、C规则三个子Agent，执行时使用GPT-6.1 Sol／极高。
- 在600米×600米独立受控场景制作：平地、20米高差坡台、实体墙、三个尸群归属区与视野测试区。用于验证机制；Airbase r14／源码r17保留为地图基线，全图接入及性能后续验。
- G01用M1A2、AH-64D、A-10C；G02／G03用Walker、Runner；G04只实装M1A2主炮与M2机枪，不提前开发空中武器。
- 先定向查找并提取原作视听素材，缺项或无法适配处再制作网页特效、临时合成群声，逐项人工看图／试听。
- 在同一工作区采用新目录、文件独占；不初始化Git，不覆盖现有源码、素材库或运行入口。
- 先汇总小样，再完成G01—G04逐目标验收与组合复验；随后进入G05全地面逐车。

本轮已新增确认：地面警戒可开关、默认开启，只使用玩家已选武器和弹种，手动目标优先；首批无友伤，友军不拦截弹丸。

## 三 操作与参数建议

### 镜头与移动

| 项目 | 候选值或操作 |
| --- | --- |
| 镜头 | 正交投影，俯角相对地面55度，水平旋转；可视地面宽120—900米，默认360米 |
| 平移／旋转／缩放 | WASD或中键拖动平移；Q／E旋转；滚轮围绕鼠标地面落点缩放；界面获焦时不触发战场快捷键 |
| 选择 | 左键点选、左拖框选；Shift增减；Tab循环重叠单位；地面／空中／全部筛选；机身投影、标签和卡片一致 |
| 命令 | 右键移动／攻击可见目标；界面选“攻击地面”后左键落点，Esc取消；点击界面不穿透到战场 |
| 聚焦／跟随 | F聚焦一次，界面“跟随”开关持续追踪；手动平移当帧退出，缩放／旋转保留跟随 |
| M1A2样本 | 移速8米／秒，加速度4米／秒²，转向60度／秒，到点误差不超过1.5米 |
| 直升机样本 | 移速18米／秒，升降6米／秒；巡航离地35米、作业12米，沿途障碍净空至少10米；作业只在合法空地样本触发 |
| 固定翼样本 | 45米／秒、盘旋半径80米；高度为样本场景最高障碍以上80米，持续飞行，不悬停 |

机身选取使用屏幕中的可见位置；移动命令命中地面支撑，显示地面标记和高度关联线。无支撑、未加载与不可通行分别提示，不能把未知高度当作0。空中整套飞行玩法留给G06。

### 尸群行为与表现

| 项目 | 候选值或边界 |
| --- | --- |
| 普通尸群 | 生命100，移速1.8米／秒；Walker／Runner只换外观，不分速度能力 |
| 游荡与搜索 | 原属区内20米游荡半径；最后声源附近搜索12秒，再返原区；近处30米且无遮挡的地面目标优先 |
| 玩法声源 | M1A2移动发动机半径90米、怠速40米；M2开火120米、主炮200米；受控诱饵220米 |
| 声源节奏 | 开火每次实际发射产生1秒声源，发动机随运行状态持续；多个声源按强度和距离选取，同等条件保持当前目标；声音过墙可听，通行仍绕墙 |
| 诱饵样本 | 人工放到地面后的5秒延时、发声30秒、耐久50；用于G03受控诱导，不算直升机投放／补装完成 |
| 近身伤害 | 到载具碰撞外缘1米内攻击，每只每秒2点，按实际接触者结算，不用整群总数隔空扣血 |
| 分级 | 镜头指向地面附近100米内优先低模个体，160米外可用分块群体替身；中间保留当前档避免跳变；拉远到个体不足5个内部渲染像素时允许进一步简化 |
| 分级约束 | 距离与屏幕尺度只管表现；不能达到数量阈值就隐藏近处单位，不改逻辑人数、归属、命中或画外战斗 |
| 动画 | 待机、行走、攻击、死亡；独立相位。评估复用现有96Hz共享姿态，96Hz不是每只CPU模拟频率 |
| 遗留物 | 尸体20秒、末2秒淡出，全局最多200具；残骸30秒、末3秒淡出，最多20具；均不阻挡通行 |
| 视听预算 | 同时最多16组爆炸／命中特效、8个群声音源、16个战斗声音源；超额仅简化播放，不取消伤害或玩法声源；血液不过量，无断肢／尸体物理 |

音频由玩家点击开启，总音量候选25%，可独立静音；玩法声源始终按规则工作。

### M1A2战斗

| 弹种 | 射程／弹速 | 伤害和范围 | 弹量与节奏 |
| --- | --- | --- | --- |
| AP256 | 90米／85米每秒 | 单体120，无范围、无穿透连杀 | 4发；主炮装填3.2秒 |
| HEAT253 | 90米／85米每秒 | 内圈2米伤害180，向7米边缘线性降到45，圈外0；允许隔墙受伤 | 8发；与AP共用主炮装填 |
| M2弹19 | 60米／150米每秒 | 单体18，无范围 | 总120发含当前箱；每箱30发，每组5发、弹间0.1秒、组间0.6秒、换箱6秒 |

M1A2样本耐久1200，无自动恢复。主炮瞄准0.45秒，M2瞄准0.25秒；两者独立条件满足才开火。首批采用确定性中心瞄准、不加随机散布，用于核对规则；并非原作精度结论。炮口、射界、转动轴和对地合法性核对后才接真实模型。

每次实际发射扣弹，换弹种不补弹、不重置正在进行的装填；弹药耗尽不自动换弹种。AP／HEAT共用炮身，M2独立装填；直击与爆炸不能给同一目标重复叠加两次完整伤害。射前目标失去视野则取消锁定，已射出的普通弹继续飞行；坐标盲射仍可命中未知敌人，但不因此暴露其位置。

首场不替玩家自动选武器／弹种，选定并启用后才参与警戒；切换界面焦点不禁用另一件已启用武器。范围伤害按爆点至目标逻辑受击中心的三维距离计算，测试摆位显示实际距离。

G04视野使用载具周围120米、实体墙遮挡的受控样本，检验可见锁定和坐标盲射。飞行样本不自动充当已完成的侦察系统；全图迷雾、占区、补给、碾压与胜负均在后续目标。

### 后续新增载具怎样复用

共通流程为：**手动选武器／弹种→真实发射与扣弹→产生玩法声源→尸群响应→弹丸碰撞→伤害／死亡→视听反馈**。新增车型填写型号、武器与弹种、弹量／节奏、炮口与射界、移动／瞄准条件、噪声及表现映射，沿用这条流程；不为每款车另写一套尸群AI。

配置缺少弹量、声源或命中规则等必填项时提示缺项，不套用隐式默认值冒充完成。每车仍须实测炮口、射界、移动开火、耗尽、引怪和毁伤；导弹制导、航空投弹、运输及工程能力在对应目标单独扩展。M1A2小样通过不代表所有武器类型均已覆盖。

## 六 制作与集成次序

1. **公共约定和素材清点。** 主对话冻结上述契约／候选参数；B定向核对原作素材，A准备交互样本，C先提供移动／高度状态；可用标明身份的受控数据并行推进。
2. **G01／G02／G03并行。** A完成镜头与选取，B完成共享动画、远替身和视听，C完成尸群规则。素材未就绪不拦住独立逻辑制作，但相关视听保持待验。
3. **G04分两次接入。** 先一车、一款主炮弹与普通尸群跑通，再补齐AP／HEAT切换、M2独立装填及并行、视听和下表边界，不能把第一次小样当全项通过。
4. **逐项与组合人工验。** 修复影响当前范围的阻塞，通过后进入G05；新增素材或逻辑影响已验内容时标明复验项。

三线每次交付文件列表、SHA、短说明、技术结果及待验项，主对话按文件核对并集成，禁止整目录覆盖。候选冻结到`local-data/大地图肃清/首批/V001-01a1ac6a/集成/`，大媒体按冻结身份共享只读，不复制整库；服务读取冻结候选及明确白名单。

未来固定候选入口建议`http://127.0.0.1:8810/`，本轮未探测或占用该端口。开工后若被其他程序使用，只报告并改候选端口，不接管、结束或重绑其他服务。新三线、集成和服务分别登记独立任务与读写依赖，交接后才结束各自保护。
