# Scavenger 操作交互系统接入正式入口-实施计划

> 本文档面向**新开独立开发会话**编写，旨在将仓库内已验证成熟的 RTS/RTT 战术操作交互能力（移动指挥闭环、高度与镜头手感、贴身名牌与防叠字、CQS 命令-快照分离与作战投影）正式收拢为独立模块 `src/交互系统/`，并接入唯一正式主入口 `http://127.0.0.1:8800`（`/play`、`/editor` 及 `/armory` 编队联动）。

## 0. 新开对话开工须知（必读红线）

新会话接手本计划执行前，必须严格遵守以下工程与跨会话协作纪律：

1. **先读规则并登记任务保护**：
   - 重读 [AGENTS.md](../AGENTS.md)、[版本退役与缓存清理规则.md](版本退役与缓存清理规则.md) 与 [清理工具说明](../scripts/维护清理/README.md)。
   - 运行 `python -X utf8 -B scripts/维护清理/清理工具.py status` 查看当前状态，并以包含新会话标识的独立任务名（如 `Scavenger操作交互系统接入-V001-<新会话ID前8位>`）运行 `protect` 登记读写范围（`src/交互系统`、`src/程序化地图`、`src/主入口`、`src/界面规范`、`scripts/交互系统`、`scripts/检查项目结构.py`、`docs/` 与独立验证输出目录 `local-data/交互系统/V001-<新会话ID前8位>`）。
   - **严禁修改或关闭其他会话的任务登记**，亦不得对未获工程师明确人工通过的版本执行 `accept`。
2. **唯一正式端口与源码目录边界**：
   - 唯一正式服务锁定 `127.0.0.1:8800`（唯一启动器 [启动Scavenger.cmd](../启动Scavenger.cmd) → [启动主服务.py](../scripts/启动主服务.py)）。**严禁新开独立业务端口或复制平行试验 `src/` 目录**。
   - **严禁触碰并行会话资产**：完整保留 [src/程序化地图/](../src/程序化地图/README.md) 中并行会话维护的 `过渡动画管线.mjs`、`程序化地形.mjs`、`立体植被与草丛.mjs`、`平滑过渡与加载.mjs`、`地图编辑器.mjs` 及 [预览入口.html](../src/程序化地图/预览入口.html) 内的 `LODTransitionPipeline` / `transition-haze-veil` / `getTransitionPipelineState()`；保留 [界面预览目录](界面预览/README.md) 与 `local-data/` 底层大包零删改。
3. **UI 与渲染硬基线**：
   - 全局 3D 视口唯一锁定 `680p + 复古微缩 Stylized`（[渲染风格与分辨率基线规范.md](渲染风格与分辨率基线规范.md)，`16:9` `1208×680` / `21:9` `1588×680` Hor+，3D `<canvas>` 带暖滤镜，HUD/标绘层独立原生高清无滤镜）。
   - 全局 UI 遵循 **Code SSOT V2.2**（[全局UI-UX规范.md](全局UI-UX规范.md)，`/ui/*` 单源）：零原生 `<select>`、常驻 HUD 零 `backdrop-filter`、零容器 `transform: scale()`、禁止业务模块私自复写通道色或载具剪影路径。
4. **开工前确认项与推荐默认值**：
   若工程师直接回复“按推荐方案实施”，即自动锁定以下 3 项默认决策，无需反复停顿：
   - **键鼠主映射（推荐方案 A）**：左键点选/拖框多选、中键拖动平移、`Q/E` 及 `Alt+中键/左键` 旋转、滚轮以鼠标有效地面为锚缩放、右键按住预览/拖动设朝向/松开移动（后续兼索敌攻击）；兼容无中键设备支持 `WASD`/方向键平移与可选边缘滚屏。
   - **编组与快选键（推荐方案）**：数字 `1~6` 直接快选当前出击编队槽位（兼容默认 3 车 `1/2/3` 回归）；自定义战术编组沿用 [src/战术演训/输入.mjs](../src/战术演训/输入.mjs) 避坑约定——`Shift+1~9` 保存编组、`Alt+1~9` 召回编组（彻底避开浏览器劫持 `Ctrl+1~9` 切标签页）。
   - **4B → 4C 编队打通（推荐在 Phase 1 同步实施）**：`/play` 初始化时读取 `/armory` 持久化的 `localStorage['scavenger.roster.v1']`（最多 6 槽，无自定义时沿用默认 `['US_M1A2', 'US_AH64D', 'US_A10']`），确保主入口编队真正进场。

## 三、 正式键鼠映射、LIFO 撤退链与模式隔离规范

### 1. 全局键鼠映射表（避免浏览器冲突与零按键撞车）

| 分类 | 输入操作 | `play`（作战指挥态） | `editor`（编辑笔刷激活态） |
| :--- | :--- | :--- | :--- |
| **选择** | 左键单击 | 点选真实机身/名牌；点空地清空选区 | 落点放置建筑 / 刷地形 |
| **选择** | 左键拖动（> 5px） | 屏幕矩形框选多车（`Shift` 追加） | 连续地形笔刷（建筑放置仅单击） |
| **选择** | 左键双击（< 350ms） | 选中视口内全部同兵种单位 | 无 |
| **选择** | `Tab` / `Shift+Tab` | 在指针附近重叠单位间循环切换 | 忽略 |
| **指挥** | 右键按住 + 拖动 + 松开 | 预览多车相对队形；拖动 > 8px 展开横队设朝向；松开提交（`Shift` 追加队列） | 立即取消当前编辑笔刷并返回 `play` 态 |
| **指挥** | `X` / 指令槽「停止」 | 清空选中单位移动队列：地停 / 旋悬 / 固盘 | 忽略 |
| **指挥** | `Space`（短按）或轮盘按钮 | 打开/关闭 V2.2 8 槽战术轮盘（死区取消） | 退出笔刷 |
| **指挥** | `A`（Phase 4） | 进入强制攻地/攻击移动落点预览（`targeting` 态） | 忽略 |
| **镜头** | `WASD` / 方向键 | 平面平移镜头（自动退出持续跟随） | 同左 |
| **镜头** | 中键拖动 | 拖曳平移镜头（阻断浏览器中键默认自动滚屏；自动退出跟随） | 同左 |
| **镜头** | `Q` / `E` 或 `Alt+中键/左键` | 水平旋转镜头（保留持续跟随） | 同左 |
| **镜头** | 滚轮 | 以鼠标有效地面为锚平滑缩放 `65m ~ 9000m`（保留持续跟随） | 同左 |
| **镜头** | 小地图左键单击/按住拖动 | 即时跳转/连续平移镜头（自动退出持续跟随） | 同左 |
| **镜头** | `F` / `G`（或跟随钮）/ `R` | `F` 一次聚焦选区；独立「跟随」键/钮开关单车持续跟随；`R` 复位主跑道基准 | 同左 |
| **编队** | `1`~`6` | 快选当前出击队列第 1~6 槽单位（双击居中） | 同左 |
| **编队** | `Shift+1~9` / `Alt+1~9` | 保存当前选区到自定义编组 / 召回对应自定义编组 | 忽略 |
| **系统** | `U` / `P` / `F5` / `6` | 切 16:9 ↔ 21:9 / 开关演训与地图编辑抽屉 / 显隐 HUD / 展开空中编队条 | 同左 |

### 2. 统一 5 级 LIFO `ESC` 撤退优先级（`createEscStack`）

每次按下 `Esc` **只撤销最顶层 1 级**，严禁跨级误触发暂停：
1. 取消进行中的右键移动预览 / 框选拖曳（不取消已提交执行中的任务）；
2. 退出 `targeting`（强制攻地/技能落点）或 `editor` 激活中的建筑/地形笔刷；
3. 关闭已展开的 8 槽战术轮盘或定制战术下拉（如 ROE 下拉）；
4. 收起右侧演训与地图编辑抽屉；
5. 打开或关闭 4A 二分暂停菜单。

## 六、 已知风险与防踩坑提示

1. **兼容现有 [验证实战HUD.py](../scripts/程序化地图/验证实战HUD.py)**：原脚本第 3~5 项检查依赖 `/play` 快捷键 `1/2/3/F/X/R/P/U/F5/ESC`、雷达点击跳镜与 100 混编建楼物理派生。接入 `src/交互系统/` 时必须保留上述键位与公开 `window.__SCV_HUD__` 行为兼容，避免破坏既有回归。
2. **高清标绘层与 `680p` 画布严格同框**：2D 战术标绘 `<canvas>` 必须挂载在居中视口容器内，尺寸按 `host.clientWidth × dpr` / `host.clientHeight × dpr` 实时同步（随 `16:9` / `21:9` 切换和 `resize` 重建），严禁受 3D `<canvas>` 的 `pixelated` 或暖色调滤镜影响。
3. **固定翼 234m 高度的屏幕拾取与投影**：高空固定翼在正交镜头下的机身中心与地面投影偏离较大；拾取必须基于机身实际 3D 中心投影（`bodyProjection`）而非地面投影，同时绘制脚下投影虚线表达空地位置关系。
4. **4B 任意 129 车进场的显存与尺寸归一化**：从 `ProceduralVehicleLoader` 加载的非默认载具需检查资源释放（切编队或重开时 `dispose` 旧几何体与材质），并按车型分类统一设置碰撞/拾取半径，避免超大型运输机与小型侦察车拾取框失调。
5. **并行会话隔离与退避**：编辑 [预览入口.html](../src/程序化地图/预览入口.html) 前必须先重新读取最新文件全文，严禁覆写并行会话新增的过渡动效、外围沙盘或植被代码。
6. **跨会话清理与验收红线**：新会话交付时须按 [AGENTS.md](../AGENTS.md) 报告任务名、新版与技术验证状态、保留依赖，保持本轮任务 `active` 等待工程师前台人工确认，严禁提前 `accept` 或关闭其他会话保护。
