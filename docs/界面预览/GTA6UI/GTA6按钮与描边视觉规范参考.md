## 一、核心视觉基因：为什么 GTA6 的无底框按键如此清晰？

在充满草地、强光跑道、烟雾和霓虹的高复杂 3D 战场背景上，传统半透明黑底胶囊按钮堆太多会导致屏幕“长满黑疙瘩”。Rockstar 在《GTA 6》实机（见图 10、图 12 右下与特写图 14 `重新居中 L3`）中采用了一套极高可读性的**“零底框硬描边”**方案：

1. **去底框（Frameless Prompt）**：战场提示项与边缘快捷操作按钮不加黑色底盒，直接悬浮在 3D 画面上，最大程度释放战场通透度。
2. **硬边粗黑外描边纯白字**：不是发虚的黑色高斯模糊投影，而是紧贴字形外缘的**等宽实心纯黑外轮廓**，确保白字在任何亮暗背景下都不丢边。
3. **高反差黑框纯白实心按键徽章**：操作键标（如 `L3`、`A/B/X/Y` 或 PC 映射 `C / F / TAB / 右键`）采用**纯白填充＋纯黑粗字＋外圈 `2px` 纯黑描边**的极简几何块，一眼区分“指令文字”与“触发键位”。

## 二、Web CSS 精确实现配方（像素级复刻图 14）

### 1. 硬边粗黑外描边文字（避坑铁律）

- **踩坑警告**：
  - 仅写 `-webkit-text-stroke: 2px #000` 时，浏览器默认居中描边，会向内啃掉一半白字笔画导致文字变瘦发黑；
  - 仅写多方向 `text-shadow` 在高缩放比下会出现转角缺口和毛刺。
- **推荐标准写法（Chromium / Edge / 现代浏览器原生支持 `paint-order`）**：

```css
.gta-outlined-text {
  color: #ffffff;
  font-weight: 800;
  letter-spacing: 0.03em;
  /* 先画外扩纯黑描边，再铺满纯白字形填充，绝不啃细笔画 */
  paint-order: stroke fill;
  -webkit-text-stroke: 3.4px #090a0f;
  text-shadow: 0 2px 3px rgba(0, 0, 0, 0.48);
}
```

### 2. 按键徽章（手柄 `L3` → PC 键鼠规范映射）

> **隔离铁律**：徽章内部**必须显式重置 `-webkit-text-stroke: 0; text-shadow: none;`**，严禁继承父级 `.gta-outlined-text` 的黑描边，否则黑字四周套黑边会瞬间糊成黑团！

| 键位类型 | 适用场景 | 几何形态 | 关键 CSS 参数 |
| :--- | :--- | :--- | :--- |
| **单字符键（圆形）** | `F`、`G`、`X`、`C`、`Q`、`E`、`1~9` | 复刻图 14 `L3` 正圆白徽章 | `width: 22px; height: 22px; border-radius: 50%; background: #ffffff; color: #090a0f; border: 2px solid #090a0f;` |
| **多字符 / 鼠标键（圆角胶囊）** | `TAB`、`Shift`、`ESC`、`右键`、`F5` | 同源黑框白底横向胶囊 | `min-width: 28px; height: 22px; padding: 0 7px; border-radius: 999px; background: #ffffff; color: #090a0f; border: 2px solid #090a0f;` |
| **暗态 / 禁用键** | 暂不可用、G02 锁定槽位 | 低饱和暗白描边 | `background: rgba(20,21,28,0.88); color: rgba(255,255,255,0.62); border: 1.8px solid rgba(255,255,255,0.35);` |

### 3. 三档按钮分层（何时用无底框 vs 何时用毛玻璃）

1. **L1 · 无底框描边快捷按钮（复刻图 14）**：适用于贴在 3D 场景边缘的高频微操提示、状态切换快捷词、浮卡外下方键位引导（如 `重新居中 (C)`、`隐藏 HUD (F5)`、`视角聚焦 (F)`）。
   - **默认态**：纯白硬描边字 ＋ 白底黑框键标；
   - **悬停态**：文字切换为香槟奶油金 `#F3D97D`（保持黑外描边），键标微放大 `1.06`；
   - **激活 / 开启态**：键标背景切换为香槟奶油金 `#F3D97D`（仍保留 `2px` 黑框与黑字），状态一眼可辨。
2. **L2 · 暗夜暖金毛玻璃微卡按钮（V002 基底）**：适用于有结构矩阵边界的区域（如右下 `4×3` 命令矩阵、左上兵种分类窄轨、右上实验抽屉开关）。
3. **L3 · 香槟金全圆角主 CTA 胶囊（对齐图 16）**：仅用于极少数最高优先级确认动作（如模态确认、启动演训/部署确认）。
