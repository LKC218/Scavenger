1 外扩硬黑描边纯白字（paint-order: stroke fill）

先绘 3.4px 外扩实心黑边，再填纯白字形，杜绝默认居中描边啃瘦白字；在亮水泥、草地与暗夜背景均清晰不丢边。

2 描边隔离键位徽章（单字正圆 / 多字胶囊）

内部强制声明 `-webkit-text-stroke: 0; text-shadow: none`，单字采用正圆黑框白底键帽，多字自动延展为 2px 黑框胶囊；激活切为主黄底。

3 L3 主行动 CTA（每屏限唯一主焦点）

采用主金/主黄实心填充配深墨黑字（对比度 > 10:1），仅用于最高优先级确认动作，严禁满屏堆砌多个黄色按钮。

4 动词文案 ＋ 即时加载防连点状态

按钮文案以清晰动词开头（确认、部署、取消）；提交中自动切为旋转指示器并锁定点击，避免重复触发。

5 斜切平行四边形 Tab ＋ 纯白渐隐扫光行

容器 `skewX(-13deg)` 配内文反向 `skewX(13deg)` 保持字体端正；列表选中采用左白右渐隐扫光＋44px 呼吸行高，彻底淘汰左侧硬黄竖条。

07

正反红线与防“AI 味儿”守则 Do / Don't · Anti-Patterns

借鉴 VibeHub「防止 AI 味儿」模块：提前锁死后续搭建整套界面时的视觉雷区
✗ 禁止：居中描边啃字 ＋ 键标继承黑描边糊团
重新居中 C

缺少 `paint-order: stroke fill` 会把白字笔画向内啃细；键帽未重置 `-webkit-text-stroke: 0` 会让黑字瞬间糊成黑块。

✓ 规范：外扩黑描边 ＋ 键标描边隔离

严格先画外扩实心黑边再填纯白字形，键帽内显式隔离重置描边，任意亮暗 3D 场景下都锐利如刀。

✗ 禁止：框里再套框 ＋ 无语义混用多种圆角
套娃按钮

粗黄外框套圆角内框再套散乱圆角按钮，造成典型“廉价模板感”和视觉噪音。

✓ 规范：单层轻界表面 ＋ 两级倒角令牌
单层面板

所有容器严格归入 `--r-surface`，所有交互控件严格归入 `--r-control`，用明度层级而非多层粗框区分结构。

✗ 禁止：满屏荧光黄 CTA 互抢焦点 ＋ 低对比死灰字
取消 详情 确认 暗灰辅助说明 1.9:1

所有按钮同等高饱和黄会导致焦点失效；深底配过暗灰字在战斗扫视中完全不可读。

✓ 规范：单屏唯一 L3 主 CTA ＋ 达标对比度

主次分层一眼明确：幽灵退让 → 常规承托 → 单一主行动 CTA 聚焦；次文字对比度始终守住 4.5:1 以上。
