## 现状基线与三套候选方案说明

1. **`0` 现状基线（旧离散按钮环）**
   - 复现当前 [指令与标绘层.mjs](../../../src/交互系统/指令与标绘层.mjs) 的 8 枚分离式矩形按钮：含 3 项未接入占位、缺少图标与扇区分隔线、无按住甩选、不区分兵种且与右下命令栏状态口径不一致。
2. **`1` 方案 A（推荐）：连续八扇区军工仪表盘**
   - 真实 8 等分 SVG 环形扇区（外径 `272px`、中心死区 `R38px`），以 `2.0°` 暗色径向缝隙明确 45° 方向边界；
   - 已激活指令用内弧安全绿标识，与香槟金悬停高亮完全分离；空槽退隐为低对比暗弧避免误触；中心盘集中显示兵种、悬停指令、禁用原因与实时冷却读秒。
3. **`2` 方案 B：悬浮环轨低遮挡胶囊**
   - 极细暗色战术环轨 + 8 枚紧凑微舱，空槽收缩为静默刻度胶囊，约 45% 内部面积直接透出 680p 战场；
   - 悬停时由中心发射方向导引虚线并点亮 45° 环轨弧段，视野遮挡最低，适合密集尸群微操时保持视野通透。
4. **`3` 方案 C：双环军用航电罗盘**
   - 内环（`R52–74`）专职承载快捷键帽与颜色编码状态弧，外环（`R77–142`）专职承载 19px 矢量图标、指令名与弹药/模式角标，外沿附 45° 方位刻度与物理锁定括弧；
   - 满配 8 槽（如固定翼 A-10C）下仍保持最高信息清晰度与零元素碰撞，代价是外径略大（`296px`）。

## 操作快捷键

- `0` / `1` / `2` / `3`：切换现状基线与 3 套候选方案
- `C`：开关左右同步对比（左固定现状基线，右显示当前候选方案）
- `Space`：随时体验 Q12-A 实战交互——**按住**在光标处呼出并向任意方向无限外延甩选，松开执行；**轻按**不越死区保留展开进入单击模式；甩回中心死区或 `Esc` / 窗口失焦取消
