# 界面设计预览总索引

本目录存放正式接入游戏源码之前的**交互与界面设计离线 HTML 预览沙盒**，用于在实装前直观审阅视觉风格、层级穿插、动效响应与键鼠操作手势。已实施并产出验证数据／性能采样的阶段性报告统一放入 [reports/](../../reports/报告维护说明.md)，两者职责分开。

## 强制分类与维护规范

1. **强制分类落点**：`docs/` 下所有 `.html` 界面预览文件**必须**放入 `docs/界面预览/<分类目录>/` 二级分类目录，严禁直接散落在 `docs/` 根目录、`docs/界面预览/` 根目录或其他文档专题目录。
2. **命名要求**：分类目录名与 HTML 预览文件名统一使用无空格中文，词组之间可使用连字符 `-`（例如 `地面载具名牌与跟随预览-V001.html`）。
3. **README 功能登记**：每个 `<分类目录>/` 必须包含一份 `README.md`，逐一登记该目录下各预览 HTML 的入口链接、关联开发目标、核心功能与交互说明、设计状态（`待审阅`／`已确认`／`已实装`）及版本演进；新增分类目录须同步登记在本总索引下方导航表中。
4. **离线自包含**：预览 HTML 必须声明 `<html lang="zh-CN">`，页面样式与脚本全部离线自包含，不得依赖外部网络 CDN 资源，不得包含本机绝对路径或引用 `local-data/`、`tmp/`。
5. **自动校验**：上述分类层级、无空格命名、`README.md` 登记及离线自包含规则已纳入 [检查项目结构.py](../../scripts/检查项目结构.py) 自动强制校验，并在 [项目结构与开发约定](../项目结构与开发约定.md) 与 [AGENTS.md](../../AGENTS.md) 生效。
