## 空地载具全贴地与幽灵路线预览-V002 详细说明

- **空间五层秩序**：地面与地面路径(`z:1`) → 地面落点双环(`z:2`) → 地面载具立体模型(`z:3`) → 全贴地地面文字(`z:4`) → 空中高度虚线、空中 1:1 飞机幽灵与高空盘旋轨道及空中实体(`z:5`)。空中单位的地面名牌全程贴地不飘浮遮挡，同时机身实体掠过地面要素上方。
- **方案 2 空中扩展表现**：
  - **地面载具**：沿用底盘外缘起笔斜切箭链 ＋ 1:1 坦克/补给车地面幽灵轮廓，机库障碍自动标红拒收。
  - **旋翼直升机（`游隼 01/02`）**：保留地面落点双环 ＋ 地面投影着陆圈 ＋ 垂直虚线向上托起 `30m` 空中 1:1 直升机线框幽灵（含旋翼外圆与机头前向箭头），可飞越地面静态障碍。
  - **固定翼攻击机（`雷霆 01`）**：移除机身正下方双环与地面虚线盘旋圈，仅保留地面十字落点锚点、贴地名牌与垂直高度虚线，并将 `40m` 半径盘旋圆轨与切入航点 1:1 A-10C 线框幽灵仅绘制在 `100m` 真实高空；选中或悬停时触发高空机身外发光、战术四角框高亮及加粗垂直虚线。
- **实心军事剪影图标**：地面名牌与远景战略圆点统一采用 `fill="currentColor"` ＋ `fill-rule="evenodd"` 负空间剪影 SVG（主战坦克带炮塔炮管与负重轮镂空、补给车带驾驶室与医疗十字镂空、武装直升机带主尾旋翼与座舱镂空、固定翼攻击机带平直主翼双垂尾与座舱镂空）。
- **层筛选与空地混选**：支持 `1` 地面 / `2` 空中 / `3` 全部层筛选；左键可点选空中机身或正下方地面落点名牌；混选右键拖动时地面车列横队停稳、直升机 30m 悬停、固定翼到达后进入盘旋；按 `X` 地面停车、直升机悬停、固定翼原地盘旋。

## 地面载具名牌与跟随预览-V001 详细功能说明

- **精简后保留的 C 全贴地载具 UI**：
  1. **贴地双层同心圆环（车底之下）**：正交投影椭圆双环，后半弧被车体自然遮挡。
  2. **贴地透视文字（车底正下方）**：近景显呼号，悬浮或选中展开 `[图标] 铁砧 01 · 状态 车速`，中景缩为短标，远景缩为兵种战略圆点；始终水平正向可读。
- **三套军事硬派路线预览方案（顶部切换）**：
  1. **1 航路标绘（默认）**：深色防撞描边 ＋ 青绿/黄绿高亮航路 ＋ 沿线慢速流动方向 V 形箭标 ＋ 菱形队列节点 ＋ 终点双圈与 56° 前甲朝向楔角。
  2. **2 线框幽灵**：拐点带斜切倒角的分段箭链 ＋ 终点按载具真实尺寸投影 1:1 半透明线框幽灵车体（含主炮前向箭头），行进态收缩为紧凑四角着陆标记。
  3. **3 履带标尺**：双平行履带虚线轨 ＋ 每隔 20 米横向测距标尺刻度 ＋ 十字战棋准星靶环 ＋ 粗实前甲护盾弧线。
- **公共硬派结构升级**：
  - 路线首段从**底盘外环边缘切点（约 5.1 米外）起笔**，永远画在车身与文字下方，彻底避免穿过车底或压住贴地文字。
  - **平时克制 vs 悬浮/拖拽高亮**：已下达行进态低亮克制，鼠标悬浮或右键拖动时全量点亮并显示总距离与预计耗时（如 `84m · 7s`），多车横队带横队基线；拖入北侧红色机库障碍区即时变红报错 `不可达`。
