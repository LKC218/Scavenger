# 玩法与载具图谱预览

## 版本演进

- **V002**：根据工程师反馈“减少无用信息量、优化配色和 UI 布局”大幅重构。砍掉无意义统计胶囊、重复文字卡片、多余搜索/排序控件和占高的底栏诊断条；将配色从 12 色收敛为 4 组低饱和莫兰迪军图语义色，采用“默认静默蓝图灰线 → 悬停/点击彩色亮起”的克制层次；右侧改为零重复的“剧本驱动 + 按需焦点检查器（带依赖/支撑可跳转芯片）”。
- **V001**：基于现行《大地图肃清正式策划书 V002》搭建首版双栏交互原型，验证“左拓扑 + 右卡片墙 + 剧本流”的表达方向。
