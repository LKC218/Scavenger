# Scavenger 全局系统界面原型预览目录（阶段 4A）

返回 [界面设计预览总索引](../README.md)。本目录归档基于 [全局UI-UX规范 V2.0](../../全局UI-UX规范.md)（`A3 烟炭双金 × B2 微描边 × C4 外柔内锐`）与 [全局UI-UX规范化-实施计划](../../全局UI-UX规范化-实施计划.md) 阶段 4A 打造的**游戏全局系统外壳可交互原型**，包含主菜单、行动/关卡选择、二分景深暂停菜单与 4 分类系统设置面板。

> 当前处于离线 HTML 实装前审阅阶段，**尚未修改游戏业务运行源码**；审阅通过后将直接挂载 `/ui/*` 单源接入正式主程序。
