## 现状基线与三套候选方案说明

1. **`0` 现状基线（截图痛点复现）**
   - 复现当前 `/play` 左下雷达顶盖的 `252px` 窄竖详情卡：680p 下直接撞穿左上角顶栏遥测，被迫隐藏左上增援轨；重复标题与立绘占高，地面误显“作战高度 0m”与航速，武器列表被截断产生内滚动条。
2. **`1` 方案 A（推荐）：右下舱上浮宽体卡**
   - 将详情卡移至右下主选舱正上方（与右下舱同宽 `356–432px`），入口 `[详情 I]` 并入右下检视舱右上角；
   - 内部采用紧凑头部 + 核心状态条（固定翼去血量改燃油条与动态 Bingo 刻度）+ 单行 4 列分兵种 KPI + 单行能力微条 + 2 列武器卡片网格 + 底部低频参数折叠区，总高约 `210–225px`，零碰撞、零滚动、左半屏彻底清爽。
3. **`2` 方案 B：左下雷达右侧矮宽浮卡**
   - 保留左下雷达旁触发习惯，但脱离雷达顶盖向右外扩（宽 `344–404px` × 高 `~215px`），彻底避免撞穿左上顶栏和隐藏左上增援轨；与底中兵牌展开及 `×N` 单机弹卡互斥收起。
4. **`3` 方案 C：右缘同构窄抽屉**
   - 在右下主选舱上方靠右展开 `308px` 窄栏，与 `/armory` 武器库右侧参数栏 1:1 像素同宽同构，跨页组件复用率最高；但 4 把武器需单列排列，垂直高度相对紧凑。

## 操作快捷键

- `0` / `1` / `2` / `3`：切换现状基线与方案 A / B / C
- `I`：展开或收起详情卡
- `Esc`：逐层收起聚合单机弹卡或详情卡
- 鼠标悬停底部任意兵牌（单机或 `×3` 聚合卡）：`180ms` 后自动弹出共享精简悬停浮卡
