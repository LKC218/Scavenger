## 三套候选方案对照说明

1. **`1` 方案 1（推荐）：时间缓动 + 高空微雾 + 原型就绪锁**
   - 每帧同步相机跨度与中心坐标；建筑远景包络带**就绪锁**，未加载完精细 GLB 前绝对不提前隐退（0 真空闪灭）；
   - 以统一 0.22s 时间缓动与极克制的高空轻雾柔和融接体块色调，树木树影渐隐取代 385m 一刀切开关，3D 草团固定滑窗消除 115m 全体洗牌瞬移。
2. **`2` 方案 2：单分界线战略/战术整体交叉转场**
   - 废除复杂的中景局部替换，仅在 `620m` 设唯一分界线：`<620m` 全战术实景、`>620m` 全战略沙盘；
   - 跨越时触发 0.25s 全局交叉淡融与轻柔战略网格脉冲，完全消除建筑半边撕裂；代价是 `460m–620m` 维持近景细节多占约 25% 面数。
3. **`3` 方案 3：复古微缩波纹生长 / 收拢动效**
   - 以镜头中心为圆心按径向波纹用 0.18s 轻柔微缩拔起（或收拢）精细屋檐、小道具、单棵树冠与草团（无夸张回弹）；
   - 契合 `680p 复古微缩` 桌面沙盘观感，切换干净克制。

## 操作快捷键

- `0` / `1` / `2` / `3`：切换对照组与 3 套候选方案
- `C`：开关左右同步双屏对比（左固定现状问题基线，右显示当前候选方案）
- `Space`：开关自动往返巡航（持续穿透 `960m ↔ 100m` 过渡带）
- 鼠标滚轮：光标无级缩放；左键拖拽：平移画布；底部芯片：一键跳转 `720m` / `580m` / `385m` / `115m` 高危临界点
