材质性能分级与 Z-Index 视距架构 Material Performance Budget & Z-Index Layers

明确实时战斗与静态菜单的性能红线，统一全局层级顺序防止弹窗/名牌/抽屉互抢遮挡

4.1 战斗 HUD 实底 vs 菜单毛玻璃同屏视觉衔接

同一色相体系，按实时帧率预算严格切分材质
实时战斗常驻 HUD 材质 60FPS 零模糊

使用 --bg-hud-solid 高透深色实底（91% 不透明）＋ 1px 细描边＋顶部 1px 内高光。零 backdrop-filter GPU 采样开销，适用于小地图、编队卡、命令栏。

暂停 / 设置 / 模态毛玻璃材质 景深质感

使用 --bg-overlay-glass ＋ blur(22px)。仅在暂停、设置面板或模态确认等低频全屏浮层启用，透出背景光影散景拉升高级映画感。
