## 候选方案要点汇总

1. **`1` 方案 A：烟炭全息等高线战术沙盘**
   - 借鉴 *WARNO* / *Broken Arrow* 与美军 ARES 沙盘，外围山体沉入深烟炭暗色（`#101518`），实时绘制抗锯齿地形等高线与 MGRS 坐标网，每 6 秒由战区边界向外推开克制的青绿/香槟金高程扫描波。
2. **`2` 方案 B：实体剖面沙盘底座 + 指挥桌面**
   - 借鉴 *R.U.S.E.* 战情室桌面模型，为 9km 战区加上 3D 地层切面（表土→岩层→深炭金属底）与枪灰金属包框及桌面 AO 落影，外围指挥桌铺极淡蓝图与慢速雷达扇扫。
3. **`3` 方案 C：暗调雾化远丘 + 叠加等高网**
   - 移除杂乱彩色镜像纹，保留暗橄榄灰自然延展远山渐入雾色，上方轻叠等高线与流动警戒斜纹带。
4. **`4` 方案 A+B 混搭（强烈推荐）**
   - 用方案 B 的“3D 地层剖面边沿 + 金属刻度边框”干净利落收住战场界线，外围继续用方案 A 的深烟炭地形等高线、MGRS 网格与向外扩散的高程扫描波，兼顾微缩桌面感与全息战情纵深。

## 操作快捷键

- `0` / `1` / `2` / `3` / `4`：切换现状对照与 4 套候选方案
- `V`：一键切换 **边界特写（东北角）** / **9km 全景总览**
- `C`：开关左右同步双屏对比（左侧固定现状漩涡，右侧当前方案）
- `F`：循环调节动效强度（`克制` / `标准` / `演示`）；鼠标在外围滑动可联动提亮局部等高线
