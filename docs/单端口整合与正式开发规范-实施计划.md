# Scavenger 单端口整合与正式开发规范实施计划

> 本文档确立 Scavenger 从多端口原型探索迈入**正式项目工程化开发**的唯一标准架构：**唯一端口 `127.0.0.1:8800` + 唯一启动入口 `启动Scavenger.cmd` + 唯一 UI/UX 代码单源（Code SSOT V2.2）+ 唯一渲染基线（`stylized-680p-v1`）+ Git 版本兜底与全仓防漂移门禁**。

---

## 一、 核心架构目标

1. **全项目唯一回环端口：`127.0.0.1:8800`**
   - 根目录只保留唯一启动脚本 [启动Scavenger.cmd](../启动Scavenger.cmd)，后台唯一服务入口为 [启动主服务.py](../scripts/启动主服务.py)。
   - 支持 `HTTP 206 Partial Content Range`、`ETag (304)`、文本类资源 `Gzip` 压缩与安全边界校验（`safe_under`），底层 `local-data/` 资产原位不动、按白名单路由只读分发。
   - 双击默认以**前台常驻留窗模式**绑定 `127.0.0.1:8800` 并打开主入口，展示简洁中文状态面板（**关闭控制台窗口或按 `Ctrl+C` 即立即停服释放端口**），自动平滑接管无窗后台或代码更新旧实例并保护已有前台窗口；命令行兼容 `start / open / stop / restart / status / menu / logs` 与快捷模块子命令（`play / editor / armory / settings / ui-spec` 等），外部占口只诊断不强杀，运行状态元数据与滚动日志（`512 KiB` 上限）统一存放于 `local-data/主服务/运行状态/`。
2. **正式源码分层主干（禁止按试验/原型名复制新目录）**
   - [src/主入口/](../src/主入口/README.md)：正式游戏前端总壳（`/` 4A 主菜单大厅 ↔ `/armory` 4B 129 车 680p 3D 武器库 ↔ `/settings` 系统与渲染偏好设置）。
   - [src/界面规范/](../src/界面规范/README.md)：全局唯一 UI/UX 代码单源 **Code SSOT V2.2**（`/ui/*` 与 `/ui-spec`）。
   - [src/程序化地图/](../src/程序化地图/README.md)：`680p + 复古微缩 Stylized` 渲染基线配置源、9km 大地图实战运行与地图编辑器（`/play` 与 `/editor`）。
   - [src/程序化载具/](../src/程序化载具/README.md)：129 辆美军空地载具 `.scvveh` 流式加载器、实例池与 `/dev/*` 研发展台。
   - [src/音效索引/](../src/音效索引/README.md) 与 [src/资料库/](../src/资料库/README.md)：音频运行时与前线资产索引（挂于 `/dev/audio/` 与 `/dev/library/`）。
3. **跨会话与并行变更零冲突保护**
   - 严禁触碰并完整继承并行会话正在迭代的 9km 过渡管线（[过渡动画管线.mjs](../src/程序化地图/过渡动画管线.mjs) / `LODTransitionPipeline`）与外围沙盘/过渡预览目录；
   - 严禁删除或修改 `local-data/` 中的底层大包、正式库 `revision 7` 与工具链缓存。

## 四、 正式开发纪律与自动化防漂移门禁

1. **解冻并禁止新增分散端口**：废除早期各试验分支端口的“永久冻结”约定；所有新增研发能力必须接入 [启动主服务.py](../scripts/启动主服务.py) 子路由。
2. **全仓静态门禁**：[检查项目结构.py](../scripts/检查项目结构.py) 将 `UI_SPEC_ADOPTED_MODULES` 扩大为 `src/界面规范`、`src/主入口`、`src/程序化地图`、`src/程序化载具`，自动拦截裸 `<select>`、`--ui-ch-*`/`--ui-state-*` 私自重定义、硬编码载具剪影、`640px` 旧基线回流与无效文档链接。
3. **双浏览器端到端回归门槛**：
   - 全链路综合验收：[验证主服务全链路.py](../scripts/验证主服务全链路.py)（Chrome + Edge 串行验 `/` → `/settings` → `/armory` 129 车真 3D 流式 → `/play` 680p 与过渡管线 → `/editor` 物理派生 → `/ui-spec` V2.2 → `/dev/*`）。
   - 专项复核：[验证界面规范.py](../scripts/界面规范/验证界面规范.py)（`--base-url http://127.0.0.1:8800`）与 [验证实战HUD.py](../scripts/程序化地图/验证实战HUD.py)（`--port 8800 --path /play`）。
