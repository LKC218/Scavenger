# 丧尸群体模拟分享包实施说明

## 目标

把当前十三款群体模拟整理成其他开发者可以直接运行和继续研究的版本。发布不改变资源、统一库、运行实验或现有性能证据，只新增可移植导出层。

## 两个交付物

运行研究版包含：

- 群体源码与共享模型加载器。
- 十三款256／512 GLB。
- 固定Three.js 0.187.0必要运行文件及许可。
- 不依赖原统一库的发布服务。
- 离线技术报告、性能报告和研究摘要。
- 运行说明、离线`使用指南.html`、开发者阅读说明书、已知限制与许可说明。
- 文件摘要、Node规则检查和可选浏览器冒烟入口。

完整研究版在同一运行基础上包含：

- 原始角色GLB。
- 十三款制作与回读资料。
- Blender可编辑工程和完整双档派生。
- 完整性能样本、日志与源码快照。
- 生成冻结交付时的统一库元数据。
- 完整Three.js源码、相关制作与报告脚本。

## 可移植运行

原8769启动器依赖统一资源库指针和带本机绝对路径的当前交付。发布版通过`data/发布资源清单.json`保存十三款稳定ID、相对路径、字节、SHA-256、骨骼、材质、三角形、动作和坐标信息。

`scripts/发布服务.py`只提供白名单源码、固定Three.js、十三款模型和采样API。默认读取256档，可通过`--resolution 512`切换。服务只绑定`127.0.0.1`，不对局域网或公网开放。

## 继续开发

运行包提供`scripts/刷新发布身份.py`。源码或角色文件变化后重算对应摘要并标记包为“局部修改”；角色变化还会建立局部交付身份。运行中的服务发现源码变化会拒绝新样本，重启和刷新后才继续。

Node规则检查不依赖Three.js或浏览器。`核验发布包.py`可进一步启动包内服务并检查十三款HTTP资源；`--resolution 256`为默认档，`--resolution 512`会选择并核对512档；带`--browser-channel`参数时使用无窗口Chrome或Edge完成真实WebGL冒烟。

生成器要求显式使用`--package-id`指定新候选批次并拒绝覆盖已有目录。工程师确认`ZOM-SHARE-261104-006`后，[固化正式版本](../../scripts/丧尸群体发布/固化正式版本.py)复核来源回执、SHA-256、ZIP CRC、归档条目、使用指南和截图身份，再生成`丧尸群体模拟-正式版-V1.0`。正式目录只保存稳定命名的运行包与完整研究包、离线指南、预览、发布说明、核验报告、摘要清单及小型迁移证据；迭代旧载荷按[版本退役规则](../版本退役与缓存清理规则.md)清理，不以直接删除替代核验与依赖审查。

## WorkBuddy 接入

包根`使用指南.html`采用离线 HTML/CSS/JavaScript，不加载外部字体、图片或脚本。指南按“解压到固定目录、WorkBuddy新建任务、选择工作空间、打开本地文件夹”的顺序说明项目接入，并显示工程师提供的 WorkBuddy 截图及其红色操作箭头。截图随包保存在`assets/WorkBuddy操作截图.png`，通过相对路径加载。

核验器检查关键步骤、中文本地页面声明、截图路径与 PNG 身份、外部依赖及本机绝对路径；桌面和移动端预览另行核对布局、流程可读性、图片加载与复制开场指令功能。该指南只说明如何把开发项目加入 WorkBuddy，不代替项目启动、资源身份或性能验收。

## 状态边界

分享包可以引用现有内置浏览器十五组矩阵和500只双场景180秒报告。独立Chrome／Edge原生前台矩阵、人工外观与动作观感及目标设备性能仍保持待验。

完整研究版中的本地日志和技术回执可能包含制作电脑路径，只供受控研究追溯。运行研究版只使用生成后的相对路径清单。
