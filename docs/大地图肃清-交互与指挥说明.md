# 大地图肃清交互与指挥说明

## 当前实施安排

G01及后续所有目标统一在战术演训原型Airbase内搭建和人工验收。G01的镜头、地空筛选、聚焦／跟随、高度与落点已获部分人工认可；高度辅助线方向通过待优化，载具交互未过，G01整体未过。当前只完善G01，G02及后续目标暂缓。

“第一步：移动指挥闭环”已获准实施，完整规则见[总计划G01章节](大地图肃清-开发目标与人工验收.md#g01-镜头与空地交互样本)，新演训代码和候选状态见[战术演训模块](../src/战术演训/README.md)及[验收页](地图与载具/战术演训-G01移动指挥验收.md)。下面仅描述旧8810样本，不把它视为已经具备移动预览、队列和编队的新版本。

## 旧独立候选的实现事实

以下按首批开工包V001描述现有独立源码和8810验证方式，供后续适配与回归；不作为新演训候选已接入的证明。技术检查、Chrome／Edge前台操作和工程师人工验收分别记录。

## 文件与职责

| 文件 | 职责 |
| --- | --- |
| `src/大地图肃清/交互.mjs` | 镜头、选择、中文面板、指挥意图、射程和范围投影；只读规则快照 |
| `src/大地图肃清/界面.css` | 战术面板、机身标签、框选和命令落点的布局与反馈 |
| `scripts/大地图肃清/验证交互.py` | 连接固定8810候选做浏览器交互回归，不启停服务 |

公共参数和状态约定由`配置.mjs`与`契约.mjs`维护。A不直接修改单位位置、高度、生命、武器、弹药或尸群状态；命令包含当前`runId`、递增`commandId`、稳定单位ID和意图字段，交给规则唯一结算。

## 接入

入口调用`createInteraction({canvas,camera,world,config,getSnapshot,dispatch,presentation,ui})`，返回`update(dt)`、`getState()`、`setSelection(ids)`、`focusSelection()`和`dispose()`。镜头须为正交镜头。根HTML提供相对定位的`#stage`、画布`#viewport`、界面根`#ui`和文本`#status`，引入本模块CSS。

主循环先推进规则并更新表现，再调用交互`update(dt)`。表现提供`getPickables()`和`projectUnit(id)`；后者使用画布CSS像素、实际机身中心及可见性。界面通过`setAudioEnabled(bool)`、`setAudioVolume(number)`和`getAudioState()`调用表现声音模块；启声必须来自玩家点击，默认关闭、总音量25%。

根入口采用本帧表现更新后交互更新，DOM标签读取本帧机身中心。交互提示另以4.5秒短消息显示，避免根入口周期刷新性能状态时盖掉落点和命令结果。根入口统一签发全局`commandId`时，A本地序号仅作意图生成，直接重复命令验证应调用`sim.dispatch`。

返回对象额外提供只供复现检验使用的`setView({focus,viewWidth,yaw})`，不接入正常玩家界面。字段可分别省略；焦点给出时须完整包含有限的`x/y/z`，宽度与弧度须为有限数值。宽度钳制到120至900米，焦点XZ钳制到场景边界，Y钳制到0至场景最高障碍加固定翼净空，偏航归一到正负π。调用立即退出跟随、清除持续按键与拖动，刷新镜头、标签和范围提示，返回实际焦点、宽度与偏航；`getState()`也包含实际`yaw`。正式性能构型可设置`{focus:{x:0,y:0,z:0},viewWidth:600,yaw:0}`并记录实际返回值，默认交互仍为360米。

场景下拉和重置按钮向`ui`派发冒泡的`scenario-request`事件，`detail`为`{preset,seed}`。根入口持有`Simulation.reset`并处理请求。交互观察`runId`变化后清空选择、跟随、旧命令序号、落点模式与旧标记，不直接重置玩法对象。验证入口由根提供`window.scavenger`的`sim`、`interaction`、`presentation`、`camera`、`world`、`config`、`ready`和`reset()`。

## 旧独立候选操作

- 左键点机身或标签选择，拖动按机身投影框选；Shift对候选增减，Tab在鼠标附近重叠单位间循环。地面、空中、全部筛选同时约束机身、标签与卡片。
- WASD及中键拖动平移；Q和E水平旋转。正交俯角固定55度，可视宽度120至900米、默认360米。滚轮以鼠标有效地面落点为锚点；没有支撑时只改视野宽度，不伪造高度。
- F或“聚焦”只定位一次；“跟随”单独启用。聚焦、开启跟随和持续跟随都优先读取表现层`getPickables()`的实际插值机身中心，缺少有效中心时才回退规则位置，避免45米每秒固定翼与30Hz规则步之间的屏幕抖动。手动平移立即退出，缩放和旋转保留跟随；跟随缩放产生的观察偏移持续保留。静态检验用`setView`仍使用显式输入。
- 右键可见目标发出攻击，其他有效地面发出移动。地面车拒绝不可通行点；空地混选时有效空中单位可继续接收落点，界面说明部分下令。无支撑与尚未加载分别提示，不补零。
- “攻击地面”进入左键落点模式，Esc取消；界面点击由DOM处理，不穿透至画布。空中单位不接本批地面武器指令。
- 主炮AP与HEAT手动选弹后独立启用，M2手动选择12.7毫米后启用；两件武器可同时启用，面板聚焦不关闭另一件。主炮切弹与M2库存、装填均来自规则快照。警戒默认开启并可关闭，仅作用于已选地面单位。
- 受控诱饵属于G03检验工具，显示5秒延时和30秒发声；按钮附近最多列出最近三枚诱饵的等待启动、正在发声、时限结束或已损毁，以及剩余秒数和耐久。状态只读`baits`的`startsAt/endsAt/alive/hp`与规则时刻，不提供关闭或回收，不称为直升机投放或后勤补装。

顶部存活总数下方以单行显示“原属A/B/C剩余／初始”，只读`counts.byHome`或`counts.byZone`中的`alive/total`，用于核对尸群跨区后归属不变；不代表区域内数量、占领或奖励。诱饵状态和原属统计均保留在既有侧面板，不占用中央机身输入区。

选中空中单位时显示机身至实际地面的关联线和离地高度。武器名称按钮可切换射程预览；攻击地面时显示已选弹种的爆炸内外圈与当前炮口方向线。线圈是地面投影，实际伤害仍由规则按三维距离判定；不凭展示图形决定命中或敌情权限。隐藏尸群不会成为右键锁定候选。

机身标签在屏幕中避让全部可见友军机身拾取区域，再避让已经放置的标签；远景中地车标签不得盖到更高处的直升机机身。优先尝试机身上、右、左、下等位置，没有安全位置时暂隐标签，卡片仍可选择。验证保持`elementFromPoint`命中画布的条件，标签选择不计作真实机身选择通过；失败回执附命中标签的单位ID。

## 验证与限制

先由根启动当前冻结候选，再串行执行：

```powershell
python -X utf8 -B scripts/大地图肃清/验证交互.py --channel chrome
python -X utf8 -B scripts/大地图肃清/验证交互.py --channel msedge
```

可选`--output`保存JSON回执，运行负责方须先保护该输出路径；`--headless`仅表示无窗口冒烟。脚本使用绝对时刻计算耗时，不启动或终止旧服务。每条结果记录输入来源和实际焦点、可视宽度、偏航、筛选，整份报告附候选revision、源码摘要及验证脚本摘要。

真实机身输入与卡片按钮验证分开记录：

- M1A2、AH-64D、A-10C分别在120、360、900米和0、正120度、负120度共27个视角中，以公开`setView`居中、公开暂停固定样本。每格先用`projectUnit`及`elementFromPoint`核对机身中心未被面板或标签截获，再执行真实鼠标点击、16个CSS像素拖框，并读取实际`selectedIds`。清空选择只作为前置状态，不能作为选择通过证据。
- 恢复固定翼持续飞行并开启跟随，在按绝对时刻排定的8个采样点重取当前机身中心、真实点击；同时确认选中和跟随身份保留，以及实际XZ位移超过20米。插值复验由根在内置浏览器记录连续显示帧的机身CSS位置范围，确认镜头与实际插值机身同步，不出现规则30Hz步长引起的周期跳动，再复跑8次机身点击、54项真实点框与180秒采样。屏幕稳定证据、点击证据、性能与人工60秒跟随分别记录，此短回归不替代连续60秒跟随人工项。
- 单独重开G01样本，通过正常直升机`move`命令校准地空机身投影到5个CSS像素以内，最多5次修正，不写规则内部字段。随后用真实鼠标点击及两次Tab核对循环、20个CSS像素框选同时选中、地面和空中筛选下分别点击机身。相关命令、落点、投影间距与选择结果保存在回执。
- 原有手动选弹、独立开关、界面焦点、Esc、筛选、跟随退出、缩放锚点与重开隔离继续执行。未知支撑反馈、四方向完整人工操作、连续60秒固定翼跟随、视听观感和正式性能矩阵仍由根与工程师按开工包逐项检查。

本模块没有旧载荷替换或新增缓存。任务`肃清A交互-V001-01a1ac6a`保持保护，等待集成与人工验收后完成消费者交接；不得在当前源码检查后登记人工通过或自动解除保护。

使用技能：`threejs-interaction`、`frontend-design`；已按`vibehub`检查术语，本批已明确使用点选、框选、投影和跟随等准确名称，无需另加术语教学。
