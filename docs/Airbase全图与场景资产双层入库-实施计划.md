## 二、实施计划

### 标准一：完整范围与还原验收

交付名称为**Airbase全图静态场景V001**。“完整”指冻结有效范围内、指定正常白天状态的静态视觉内容和可追溯布局完整；下表为必需范围。源中不存在的类别以来源证据标记“不适用”。源中存在却未能恢复的必需类别，必须阻止全图完整验收。

| 类别 | 必须恢复的内容 | 验收依据 |
| --- | --- | --- |
| 地形 | 实际显示的地表网格、原始高度及源图层；明确有效地面、空洞和外围背景 | 源范围、网格覆盖、分块边界与独立高度回读 |
| 道路与交通结构 | 道路、跑道、滑行道、标线及实际存在的桥梁、铁路等静态结构 | 正式源网格与材质关联，路口、边界和桥面连续性 |
| 建筑与装饰 | 实际启用的建筑、机库组合、固定飞机布景、车辆布景、围栏、路灯和其他静态道具 | 全量来源条目与输出实例逐条对账，组合关系不丢失 |
| 植被与地表细节 | 实际存在的树木、灌木、石块、草地或细节实例；记录网格、面片和分布数据来源 | 单独追踪植被与细节渲染路径，不能以建筑Bank代替 |
| 水面与静态效果 | 实际存在的水面、贴花和影响地貌辨识的静态表现 | 源几何／掩码及参数可追溯；运行简化另作对照 |

运行时允许按距离简化植被、小装饰和材质，但来源母版与清单保留完整记录；细节裁剪不能被统计成源物体不存在。原Shader完整高度混合、微纹理、天气、动态水体效果、破坏、建筑内部交互、原任务／联机逻辑、原导航系统和飞机起降不在V001的还原承诺内。近似材质必须标明，不能宣称与原游戏画面等价。

**范围冻结方式：** 从地图设置、启用的场景对象、真实地表包围盒和通行相关来源共同确定`playBounds`、`renderBounds`与`backgroundBounds`。保留当前米制转换原点`(4425,136,4850)`及方向，除非源证据要求修正；允许不对称边界，不把旧2公里居中假设扩充成全图。范围相交物体保留完整形体并记录跨界，源背景与有效地面分层管理。边界结论写入带摘要的配置，不根据预览画面猜定。

| 必需检查 | 通过标准 |
| --- | --- |
| 条目完整性 | 冻结范围内必需源条目100%有输出关联；排除条目逐项有源证据；遗漏、失联依赖和意外重复为0 |
| 米制和摆放 | 比例为1；分离地标、实例包围盒和锚点独立核对，位置误差不超过0.02米；组合和镜像节点单独验证 |
| 地表高度 | 每个有效块至少9个分层抽样点，追加道路／桥梁交接特征点；精细查询对独立网格回读P95误差≤0.05米、最大≤0.10米 |
| 接缝与支撑 | 同源地形接缝高差≤0.001米；无非源空洞、错位或悬浮。原有空洞、水域、陡坡与多层支撑明确标记 |
| 画面 | 每种原型四向检查；全图按1公里审图格逐格俯视及斜视；路口、桥梁、密集装饰、植被与旧2公里区域补近景，无缺材质、反面、黑块或组合缺件；匹配旧2公里视点，不降低已认可的标线、轮廓和地表辨识度 |

接缝检查只比较同一连续表面，不把桥面与桥下地面强行连接。高度抽样包含每个非空块，不能只挑机场平地；失败点细化后保留原输入和前后证据。没有原游戏实际截图时，画面验收比较源数据重建、独立GLB和网页结果，不冒称完成原游戏截图一致性验证。

### 标准二：模块化交付与数据契约

| 层次 | 正式交付 | 约束 |
| --- | --- | --- |
| 可编辑母版 | 全图总装配Blender工程、按实际需要拆分的分区／原型工程及依赖清单 | 集合实例或链接保留作者摆放；新进程可重开。单一超大GLB不是必交条件 |
| 独立资产 | 建筑、装饰、植被及组合资源的模型、材质、预览、来源与版本 | 可独立定位和收集依赖；保留作者原点，并记录便于放置的建议锚点，不能静默改轴心 |
| 场景装配 | 场景身份、边界、坐标变换、分块索引、分区实例表和源关联 | 清单引用确定版本的资源ID和摘要；实例表按空间分页，跨块实体只渲染一次 |
| 运行数据 | 总览与细节层、125米显示块、精细高度、碰撞、通行数据和媒体依赖 | 模拟读取数据接口；运行时不读取研究文档、Blender文件或原游戏包 |

125米沿用现有组织；若有效范围恰为9公里方区，理论为72×72、5184个格位，实际只输出有内容的块，并登记空格位。特殊大物体按完整包围盒参与空间查询，使用唯一所有者和邻块引用，不按中心点判定可见或通行影响。

独立原型采用稳定来源键及不可变版本ID，建议形式为`model:BA_SCENE_来源键_v001`；场景采用`scene:BA_Airbase_v001`。同一逻辑对象的后续修订通过来源键关联，新内容生成新版本ID，复用未变资源，不覆盖旧ID。组合机库保留部件与装配关系；同坐标、同名称不能作为去重依据。物理文件以SHA256去重，来源身份和语义关系分别保留。

碰撞按源Collider和类别冻结策略：建筑、围栏、岩石、植被及细小装饰各自记录阻挡与弹道规则；缺少原碰撞时明确标记派生轮廓，不能把全部装饰统一处理成大型实心方盒。地表、桥面与水域规则在范围关口确定后复用。

基础层保留源几何，优先无损几何编码；近／中／远细节层按实际屏幕占用生成，总览使用粗地形和建筑／植被聚合表示。几何轮廓相对基础层的投影误差不超过2个内部渲染像素，并在切换距离两侧检查；透明、标线、围栏和识别性结构另外审图。2公里已有视点保持可对照，不能只按固定减面比例证明画面合格。

**必要接口与加载规则：**

1. 继续提供`bounds`、`heightAt`、碰撞查询、显示根节点与`dispose()`；现有平地与2公里配置通过兼容适配器运行。
2. 增加区域就绪接口与请求状态，用于准备镜头、单位、射击和路径所需数据。未就绪或未知区域返回明确状态，命令进入待准备状态；不得填0高度、把未知判可走或静默丢弃命令。
3. 全局只保留受预算约束的粗层与区块连接信息；精细高度、碰撞、摆放按区域加载。远途路径采用区块连接加局部现有寻路，避免首屏建立全图高精度网格。
4. 若存在桥上／桥下等多层通行，记录支撑层及连接关系并传递支撑提示，不能用最高表面覆盖所有单位。水域、坡度和车体余量继续有明确规则。
5. 单位和有效命令为模拟数据保留引用；相机移走只改变显示驻留。重置、取消命令、地图切换时释放各自引用、加载请求和资源。

当前全图若继续按1米单层float32高度存储，9001²采样约309 MiB，仅用于说明全量预载成本，不是已提取结果。优先使用分块量化高度、空洞掩码与局部细化；量化后必须满足高度标准。原始精度数据保留在来源层。新道路仍是作者布局资源；可任意拼接的道路套件与编辑器不属于本阶段功能。

| --- | --- |
| 首屏下载 | 地图≤20 MiB；全部必要依赖≤25 MiB。并列报告实际传输字节、响应体字节与唯一内容字节，不混用压缩口径 |
| 限速冷启动 | 下行20 Mbps、上行5 Mbps、RTT80毫秒；新浏览器上下文清缓存，连续3次均≤15秒可操作；总览或加载反馈≤3秒出现 |
| 温启动 | 同版本保留HTTP缓存、重建页面上下文，3次均≤3秒可操作；区分HTTP缓存与进程内缓存 |
| 跨区显示 | 低精度总览始终提供有效画面；高精度区域就绪再切换，无空白地表、材质闪黑、旧请求覆盖新位置或实体重复 |
| 请求与错误 | 数据请求最大并发4、转码作业最大并发2；过期任务可取消；必需请求无404／摘要不符，错误可定位且不假报就绪 |

**帧时间与驻留预算：**

| 项目 | 必需标准 |
| --- | --- |
| 稳态帧时间 | 每个主验样本平均FPS≥60、P95≤16.67毫秒、P99≤25毫秒；超过33.3毫秒帧比例＜0.1%；预热外最长帧≤100毫秒 |
| 可见复杂度 | 局部及全图总览分别记录实际绘制、三角形、实例数、影子开销和细节层；局部预警为350次绘制／200万三角形，最终以帧时间和画面双通过判断 |
| 显示资源 | 高精度可见地表≤49块；所有预取和过渡资源计入内存。GPU纹理含Mip与阴影估算≤256 MiB，几何与实例缓冲估算≤192 MiB |
| CPU数据 | 地图可归因解码数据含几何、实例和转码缓存合计≤256 MiB，其中高度／碰撞／通行≤64 MiB；下载缓存≤64 MiB；整页JS已用堆≤512 MiB，ArrayBuffer等另列 |
| 反复回访 | 闭合路线180秒一圈，共5圈；在同一位置、相同待请求为0状态比较第2与第5圈，存活资源数及解码内存增长≤5%，相同回收条件下JS堆增量≤max(16 MiB,10%) |

显存数值为可归因资源估算，不冒称驱动实测显存；浏览器进程内存单独记录。堆、ArrayBuffer、解码数据等统计存在重叠，不直接相加作为总进程内存，也不能只查堆就宣称总内存达标。显存与解码缓存分别限额，不能因同一贴图URL相同就假设GPU对象已经共享。几何、材质、纹理、ImageBitmap与转码缓存按引用计数和最近使用策略释放，不能把现有整页无限文件缓存直接扩到全图。

**必需验证矩阵：**

1. 默认30单位做点选、框选、移动、停止、暂停、声音解锁、镜头操作与五次地图切换；保留城市、小靶场和2公里区域的回归。
2. 在冻结的最密静态区分别测试空场60秒、10辆坦克移动60秒、100混编连续移动交战180秒，各预热10秒。100混编沿用80坦克／16旋翼／4固定翼，记录实际可见、移动和发声数量。
3. 补100单位全部进入视锥的180秒镜头，记录实际提交与细节层并满足同一帧时间标准；不能引用旧2公里“100在场、仅6至8入画”的成绩代替。
4. 全图总览60秒；跨地图长路线及稀疏、密集、植被、坡面／桥梁区域的5圈回访，逐秒检查实际可见地表支撑，非源空洞为0。
5. 断开一项非当前区域资源、快速转移镜头、取消命令和重置，验证总览回退、重试与请求释放。故障样本独立记录，不混入正式帧时间样本。

网络启动样本、稳态样本、首次流式遍历和故障恢复分别归档。任何源码、资源摘要、清单、镜头、分辨率或声音配置变化，重跑受影响样本；不能只换服务版本号就继承性能通过。运行媒体全集、编辑母版与来源总体积完整报告，但不以全图总量代替首屏和驻留预算，也不在来源未盘点时承诺总包大小。
