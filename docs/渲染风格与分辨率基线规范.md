# 渲染风格与分辨率基线规范（`680p + 复古微缩 Stylized`）

本规范由工程师正式拍板锁定，确立为本项目 **程序化大地图及今后全部新开发、测试与实战 3D 场景模块** 的**唯一渲染分辨率与风格化呈现基线**，用于统一后续美术资产精度、模型粒度、光照色调、UI 比例尺与性能验收口径。

> [!IMPORTANT]
> 唯一代码配置源位于 [渲染基线.mjs](../src/程序化地图/渲染基线.mjs)，与本文档由 [检查项目结构.py](../scripts/检查项目结构.py) 自动校验同步性；任何新开发、测试或实战页面严禁私自切换为 1080p/720p/640×364 或内联复制不同参数。

## 一、冻结渲染输出参数（唯一标准）

| 参数项 | 冻结标准值 | 说明与目的 |
| --- | --- | --- |
| 基线标识 | `stylized-680p-v1` | 全项目统一渲染基线版本标识 |
| 固定垂直渲染高度 | **`680`**（`680p`） | 唯一 3D 场景渲染高度，前端不向玩家提供多分辨率画质选项 |
| `16:9` 标准输出 | **`1208 × 680`**（相对 1080p 像素 `39.6%`） | 主流宽屏标准画幅与 UI 安全区基准 |
| `21:9` 标准输出 | **`1588 × 680`**（`Hor+` 垂直一致，横向视野拓展约 `31%`） | 带鱼屏标准画幅；相机锁定与 `16:9` 相同的垂直视野高度，上下不裁切 |
| `full` 全屏自适应输出 | **`round_even(680 × clamp(vw/vh, 1.2, 3.5)) × 680`** | 全屏自适应铺满视口零黑边（`ASPECT_CYCLE`: `16:9 → 21:9 → full → 16:9`），同样死锁 `680p` 垂直高度与 `Hor+` 视锥 |
| WebGL 抗锯齿 | **`antialias: true`** | 保留硬件 MSAA，抑制 680p 下镜头平移/缩放时草叶、围栏与标线的高频闪烁 |
| 设备像素比 | **`pixelRatio: 1`** | 严禁按高分屏 `DPR=1.5~2.0` 放大内部分辨率，锁死像素填充率成本 |
| 色调映射与曝光 | **`ACESFilmic` / `exposure: 1.18`** | 保证写实微缩军事场景高光柔和、暗部不死黑 |
| 自发光后期辉光 (HDR Bloom) | **`bloomThreshold: 1.35` / `strength: 0.46` / `radius: 0.36` / `HalfFloat + MSAA 4x`** | `EffectComposer` + `UnrealBloomPass` + `OutputPass` 仅对高能爆炸核、枪口焰、30mm 曳光弹与固体火箭尾焰溢光；普通白天地形/建筑/载具零误泛光；支持 `/settings` 与暂停菜单一键开关（默认开启 `bloomEnabledByDefault: true`） |
| 680p 仅远景 3D 深度自然景深 (`tiltShiftDof`) | **Far-Only 3D 深度隔离半分辨率 2-Pass · `dofMode`: `off (0px)` / `soft (3.6px · 3.5%远景薄雾，默认)` / `standard (6.2px · 5.5%远景薄雾)` · 高度衰减 `360m → 1200m`** | 仅对正交线性深度大于焦平面的远景（`farStartRatio` `0.22`/`0.14` → `farEndRatio` `1.08`/`0.88`）执行深度加权防渗色半分辨率 2-Pass 柔化与轻空气透视薄雾；前景、底部战区与所有高空固定翼/直升机天然 `CoC = 0` 100% 锐利且零前景溢晕，同栋高楼不再被屏幕横带腰斩；拉高至战略视角自动降至 `0%` 零开销旁路；仅作用于 3D `<canvas>` 绝不模糊 2D 名牌与 HUD；在 `/settings` 与暂停菜单持久化切换 |
| 3D 画布上采样 | **`image-rendering: pixelated`** | 最近邻锐利像素上采样，塑造硬朗现代微缩沙盘质感，避免双线性插值软糊 |
| 3D 复古微缩调色 | **`contrast(1.08) saturate(1.10) sepia(0.06)`** | 仅作用于 3D `<canvas>` 的轻度暖调微缩提纯滤镜，零额外离屏显存开销 |

## 二、双层分离与 `16:9 / 21:9` 比例 UI 原则

1. **严格双层分离（3D 风格化 + UI 原生高清）**：
   - `image-rendering: pixelated` 与 `filter: contrast(1.08) saturate(1.10) sepia(0.06)` **仅允许作用于 3D `<canvas>`**；
   - 所有 HUD 面板、按钮、文字、缩略图与贴身载具名牌 DOM 必须位于独立高清叠加层，**始终保持显示器 100% 原生锐利清晰且不叠加泛黄滤镜**（与 [全局UI-UX规范](全局UI-UX规范.md) 的双层高清渲染原则完全一致）。
2. **`16:9` 与 `21:9` 双画幅比例 UI 设计**：
   - 渲染输出高度死锁 `680px`，前端画幅比例与 UI 布局严格按 **`16:9`（`1208×680`）** 与 **`21:9`（`1588×680`）** 两套标准比例框设计；
   - 所有 HUD 与贴身名牌必须锚定在标准画幅框安全区内，切 `21:9` 时不得发生拉伸变形或左右边缘裁剪；
   - 场景裁剪半径（如 G4 草地滑窗与近景树木动态视距）必须以 `21:9` 横向视野为包络基准，确保 `21:9` 四角零露边。

## 三、测试、验收与适用范围边界

1. **唯一测试与实战基线**：
   - 后续所有自动化性能测试、视觉自测与人工验收（包括 [验证B5全矩阵.py](../scripts/程序化地图/验证B5全矩阵.py)）统一以 **`680p (16:9: 1208×680)`** 与 **`680p (21:9: 1588×680)`** + **`复古微缩 Stylized`** 为唯一标准，不再以旧 `640×364` 或原生 `1080p` 作为主验基线；早先历史选型归档对比台已完成使命移除。
2. **历史冻结端口保护边界**：
   - 本规范仅约束 [src/程序化地图/](../src/程序化地图/README.md) 及今后全部新开发、测试与实战 3D 模块；
   - 既有历史冻结端口（`8767`、`8768`、`8769`、`8780`、`8781`、`8784`、`8811`–`8814`）及正式资产库 `revision 7` 保持原样，不回溯改造。
3. **强制同步校验**：
   - 修改本基线任何参数时，必须同步修改 [渲染基线.mjs](../src/程序化地图/渲染基线.mjs) 与本文档，并通过 `python -X utf8 -B scripts/检查项目结构.py` 自动校验。
