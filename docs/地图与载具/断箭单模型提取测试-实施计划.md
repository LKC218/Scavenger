来源与核验范围见 [目录核验](../../research/断箭/目录核验.json)、[来源台账](../../research/断箭/来源台账.json) 和 [观察记录](../../research/断箭/观察记录.md)。本机程序绝对路径保存在 `local-data/断箭/本地配置.json`。

### 主要不确定项

- 包头为标准 UnityFS，仅证明可识别格式特征；AssetRipper 对内部序列化数据的兼容性尚未实测。
- 资源解析可能需要加载整个单位包。磁盘包大小无法直接推算内存峰值，需要先测加载与对象索引。
- 载具可能由多个网格、挂载与共享材质组成，需要沿实际引用收集完整静态外观。
- 颜色、法线与组合贴图可能采用虚拟纹理。必须根据引用和实际图层确认用途，通道含义保留证据与待定状态。
- 现有工具的帮助检查未证明单模型导出接口可用。编排采用当前版本实际暴露的界面或接口，不预设未验证的命令参数。

计划编制阶段未应用专用建模技能。执行阶段使用 VibeHub 编码工作流及 blender-reference-modeling 的多视角、保存重开验证原则；任务为既有资源提取，不涉及参考图建模或补建几何体。

## 二、实施计划

### 阶段一：建立测试批次与输入清单

1. 读取本地配置，核对游戏目录、Steam 构建号、单位包头及工具程序。构建号变化时更新核验并使用新批次。
2. 重新读取可用内存和磁盘，在输入清单中明确本批次允许的占用预算；根据实际环境决定可执行的加载范围。
3. 选择未使用的批次编号，首个建议为 `BA-26273833-001`；校验输出位于 `local-data/断箭/批次/` 内，已有批次不覆盖。
4. 记录输入相对路径、大小、修改时间及文件头摘要。对需要固定的单位包记录 SHA-256；大型 GTP 以实际读取范围与元数据登记，未做全文件摘要时如实标明。
5. 所有源文件以只读方式访问。工具需要写入输入附近时，仅复制所需文件到本批次，并登记副本的来源与摘要。

### 阶段二：验证资源解析并选择一个载具

1. 先用一个小型 UnityFS 包检查工具是否能够解析当前版本，再加载单位候选包及实际需要的依赖。
2. 记录解析耗时、内存占用、警告和错误。耗时由系统时间戳差值计算，不采用累计休眠计时。
3. 保存对象索引中与候选载具相关的名称、类型、层级、材质和依赖关系。按最新授权选用可独立识别的 A-10 飞机作为样本。
4. 若出现解析不兼容、内存预算不足或引用缺失，记录具体失败条件，先调整加载方式或补齐已知依赖；方法需要扩大范围时提交补充方案。

阶段产物：对象选择记录、依赖清单、解析日志。资源包中包含多个对象时，记录实际解析范围。

### 阶段三：导出几何体与对应纹理

1. 使用工具实际支持的导出方式，保留所选载具的必要网格、局部变换、层级、UV、法线和材质槽。只输出所选载具及其必要依赖。
2. 依据材质引用确定对应纹理。普通贴图直接导出；GTS/GTP 纹理按当前版本工具帮助，选择相关条目与图层提取。
3. 保存模型对象、材质、原始纹理名称和导出文件之间的映射。保留原始贴图，对预览需要的通道转换生成独立派生文件。
4. 逐项记录缺少的贴图、部件和未确认通道；保持未知项可追溯。
5. 若现有工具无法输出 Blender 可读取的格式，先保留可验证的中间产物与失败日志，再评估最小转换步骤。

阶段产物：批次 `场景数据/` 中的几何体与映射、`原始贴图/` 及派生贴图、问题清单。

### 阶段四：Blender 检查与 Eevee 预览

1. 使用独立 Blender 进程和新工程导入结果，记录导入器、对象数、网格数、三角形数、包围盒与材质数量。
2. 检查车体、炮塔或武器、轮组或履带等实际存在部件的相对位置，核对重复 LOD、碰撞网格与外观网格。
3. 检查 UV、法线、材质槽、颜色空间、法线方向和透明部分；依据可确认的纹理引用连接材质。
4. 将尺度标为导入尺度；没有可靠实车尺寸依据时，不宣称真实尺寸或擅自缩放到某个长度。
5. 将 `.blend`、嵌入贴图、GLB 与检查图保存到批次的 `导出结果/` 或 `默认装配导出/`，关闭后在另一个进程重开，检查贴图与对象是否完整。
6. 使用 Eevee 输出整体与关键细节预览。截图中的缺件、材质问题及无法确认项与检查记录对应。

阶段产物：可重开的 Blender 工程、依赖贴图、Eevee 预览和模型检查记录。

### 阶段五：整理结果与结论

1. 在本地批次保留原始日志、输入清单、派生产物与程序版本；在 `research/断箭/` 保存精简、可追溯的正式测试记录。
2. 实际生成报告时建立 `reports/断箭/`，给出预览、各验收项状态、耗时、问题及复现入口。
3. 更新来源、观察记录、脚本说明及文件导航。按已追加授权继续美军空中和地面载具批量导出，逐项审核后选择交付版本。
