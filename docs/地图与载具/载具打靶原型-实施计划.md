编制日期：2026-11-03。当前状态：已获自动实施授权，首轮原型、派生资源、11组规则检查及Chrome／Edge浏览器操作检查已完成。短时无窗口性能样本通过帧预算；长时可见窗口、听感与操作手感仍待工程师试玩。实际结果见[实现与验证报告](../../reports/载具靶场/原型实现与验证.md)。

需求依据见[断箭交互设计经验与原型约定](断箭交互设计经验与原型约定.md)，项目边界见[项目结构与开发约定](../项目结构与开发约定.md)。本文不改变正式模型库、音效库和其他资料库任务的状态。

镜头后续调整已按工程师确认实施：平滑启停、鼠标位置缩放、中键减敏、默认局部视野和主动聚焦；选择与下令保持视角，不自动跟随。实现参数与本轮验证见[镜头交互优化验证](../../reports/载具靶场/镜头交互优化验证.md)，主观手感仍待试玩。

## 一、目标与交付

交付一个本机可运行、使用现有模型与音效的单机Three.js载具靶场。最终场内5辆M1A2与5架AH-64D，电脑键鼠操作，Chrome与Edge分别验证；采用俯视缩放镜头、低分辨率三维画面和清晰UI，当前开发电脑目标60 FPS。

完整操作流程为：选择单位 → 下达移动或攻击命令 → 观察路径及执行状态 → 接近、停稳、瞄准和发射 → 命中或显示受阻原因 → 重新选位或取消 → 重置靶场。

| 交付项 | 完成条件 |
| --- | --- |
| 独立可玩入口 | 本机启动说明、资源加载状态、暂停和重置入口可用 |
| 两款可用载具 | 尺度、可动结构、炮口与发射挂点有检查依据；派生动作标明来源 |
| 指挥与战斗 | 选择、移动、指定攻击和攻击移动遵守已确认规则，状态与实际接收者一致 |
| 声音与画面 | 使用确证音效关系，移动、发射、命中按实际事件触发；低分辨率不影响UI与拾取判断 |
| 验收记录 | 浏览器、设备、负载、分辨率与帧时间可追溯；未通过项保持未通过 |

首轮范围不包含步兵、固定翼、敌群、穿甲与部位损伤、联机、手机触控或完整战役胜负系统。

## 四、参数与资产处理原则

1. 世界尺度与游戏参数分开：模型保持相对比例，射程、移速、转向、瞄准和装填按原型手感可调，不声明真实装备数值。
2. 原件只读：动作、挂点与优化写入派生资源；程序制作动作不称为提取到的原游戏动画。
3. 先两款样本再推广：观察加载、帧时间和战术镜头外观，分别决定几何、材质、纹理与文件压缩；不提前固定全库减面比例。
4. 友军规则覆盖全部武器：友军不进入弹丸拦截和伤害对象集合，地形、障碍与靶标继续检查；行驶避让不随此规则关闭。
5. 暂停与恢复使用明确游戏时间基准，计时不累计休眠；视觉反馈、武器调度和声音避免因切出或重置重复触发。
