### 1.3 通用底座 JS 契约与 `src/程序化地图/` 接入约束

未来在 `src/程序化地图/固定翼底座.mjs` 落地的核心导出契约如下：

3. **`weaponsSpec[]` 数据契约（强制含 `canTargetAir`）**：
   ```js
   {
     id: string,                // 'gau8_30mm' | 'agm65_maverick' | 'gbu31_jdam' | 'hydra70_rocket' | 'alq131_ecm'
     name: string,              // 显示名称

     ammo: number,              // 当前余弹
     maxAmmo: number,           // 满载弹药

     canTargetGround: boolean,  // 对地有效标志

     fireAudioKey: string,
     impactAudioKey: string,
     explosionTier: 'light' | 'medium' | 'heavy' | 'none',
     cooldownSec: number
   }
   ```
4. **`FixedWingBaseController`**：

### 2.1 维度 1：动画与坐标系基准

1. **模型与槽位事实**：

2. **`rigBodyGroup` 坐标系转换基准（关键）**：
   - 原始 GLB 与 `US_A10.json` 空间：**`-Z` 为机鼻前向、`+Z` 为机尾、`+Y` 为上方、`-X` 为左翼、`+X` 为右翼**。
   - 经 [载具动效控制.mjs](../../src/程序化地图/载具动效控制.mjs)（`buildVehicleRigHierarchy`）建立：`rigBodyGroup`（`rotation.order = 'YXZ'`）→ `modelAlignGroup`（`rotation.y = Math.PI`）。
   - 绕 Y 轴旋转 $\pi$ 后，在 `rigBodyGroup` 及世界航向空间中：**`+Z` 为机头前向、`-Z` 为机尾、`+Y` 为上、`+X` 为左翼（port）、`-X` 为右翼（starboard）**。
   - 任意原生坐标 $(x, y, z)$ 到 `rigBodyGroup` 局部坐标的精确映射为：
     $$(x_{\text{rig}},\, y_{\text{rig}},\, z_{\text{rig}}) = (-x,\, y,\, -z)$$
3. **姿态与挂架外挂动画**：
   - **压坡度滚转**：盘旋与转向时按向心角速度与目标航向差平滑插值 `rigBodyGroup.rotation.z`（盘旋 `24°–36°`，急转/脱离最大 `±52°`）。
   - **俯冲与拉起**：扫射进入 `-24° ~ -30°` 俯冲，投弹采用 `-12° ~ -18°` 浅俯冲或水平突防，脱离阶段 `egress` 拉起至 `+22° ~ +28°` 爬升角。
   - **挂架实装弹药可见消耗**：挂载于 `rigBodyGroup` 下（随 `unit.node` 同步，可合法进入 Live PiP 小窗观察），与 `weaponsSpec[].pylonIndices` 绑定，每次发射/投弹按挂架索引逐发切换可见状态为隐藏（`visible = false`）；`reset` 时整套挂架恢复可见。
   - **底座动画联动预留**：为 `supersonic_multirole` 预留发动机喷口 `exhausts` 跟随节流阀比例缩放 16 面/引擎交叉蓝橙加力锥片；A-10C 仅保留微弱热流呼吸（可选 0 DC 或跳过锥片），与热诱弹抛洒点、左右翼尖涡流严格锚定至 `rigBodyGroup` 转换坐标。

#### 2.2.3 前导静音裁切、GAU-8 纠偏切片与服务/运行期规则

1. **`.flac` 服务支撑（M2 必改项）**：

2. **`trimAudioBuffer` 前导与尾部静音裁切**：
   - 全部 11+11 条 `event_render` 存在 **168.7ms–368.7ms** 头部静音及 5–9s 纯零尾段。`AirEventAudioEngine`（挂载于 [载具空间音效.mjs](../../src/程序化地图/载具空间音效.mjs) 的 `listener.context` 与 `mix.mixInput` 软限幅母线）解码后必须执行：

   - 同步将 `VehicleAudioRuntime` 的缓存预算从 `32 MiB` 扩至 **`64 MiB`**，全局并发声部 `global_max_voices` 从 `16` 扩至 **`32`**。
3. **纠偏后的正式库 GAU-8 切片参数（关键纠偏）**：
   - **严禁**沿用 `scripts/预览丧尸防线.py` 对特制 4s WAV 设定的 `loopStart=1.0 / loopEnd=3.6`！正式库 `SFX_AIR_PLANEGUN_30mm_GAU8_US` 为 10.240s 单次长尾渲染，实测稳态高频连射震鸣集中于 `0.345s–0.685s`（`1.06s` 后单调衰减至尾音）。

     - `attackStart = 0.205s`（切除前 209.5ms 静音，保留 `0.205s–0.345s` 起枪爆裂瞬态）；
     - `sustainBuffer = slice(0.205s, 0.720s)`，其内部循环区间设为 **`[0.14s, 0.48s]`**（对应原轨 `0.345s–0.685s` 稳态连射），并在 `0.48s` 前施加 **20ms 等功率交叉淡化**，实现任意扫射时长的连续无缝 “BRRRT”；
     - `releaseBuffer = slice(0.68s, 3.20s)`（头部 12ms 淡入），扫射结束时无缝抢占/交叉切出 `sustain` 声部并播放自然枪声回响。
4. **60–180ms 音画延迟队列、近中景阻尼微震与音爆双响**：
   - **延迟队列**：利用 `AudioBufferSourceNode.start(ctx.currentTime + delayMs * 0.001)` 实现零 GC 精确调度。`delayMs = clamp(60, 180, 60 + dist3DToCamera / 340 * 1000 * 0.25)`（近距机炮开火约 `60–90ms`，中距炸点约 `90–130ms`，远景重型航弹约 `130–180ms`）。

2. **全局特效池架构与严格 DrawCall ≤ 6 预算（零运行期 GC）**：
   所有世界特效统一挂载在 `scene` 顶层 `VfxRoot` 组（**严禁包含 `PointLight`、严禁挂在飞机节点下导致污染 Live PiP 小窗**），预分配固定容量 typed array 池，运行时零 `new THREE.Vector3` / `Mesh`：
   1. `ordnancePool`（`InstancedMesh`）：飞行中低模弹体（炸弹/导弹/火箭/机炮曳光）+ 热诱弹本体；
   2. `blastShellPool`（`InstancedMesh` + 共享 Shader）：层 1 爆闪/贴地假光晕 + 层 2 气压冲击波穹顶/尘环；

3. **视锥裁剪与三档视距自动减负**：
