## 先试玩这几项

1. 选一辆地面车，右键按住预览，拖动改变到达朝向，松开执行；Esc能撤销未提交预览。
2. 多选车辆，普通移动保持相对队形，拖朝向展开横队；对照预览与实际落点。
3. 按Shift连续安排三个地点，观察路径、顺序和当前状态；普通新命令替换任务并清空旧队列。
4. 地面、直升机和固定翼混选后前往同一区域；地面与旋翼分别落点，固定翼在附近盘旋。X或停止按钮清队列，飞机不能停在空中。
5. 在建筑、地图边缘或尚未加载的区域下令，观察红色原因与“准备路径”；不得悄悄换终点，其他可达单位继续。
6. 回归镜头、点框选、地空筛选、F聚焦、独立跟随、高度与地面落点；手动平移退出跟随，点面板不向战场误发令。
