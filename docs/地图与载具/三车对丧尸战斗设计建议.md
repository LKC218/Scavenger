# 三车对丧尸战斗设计建议

当前入口为8794的已通过V003。下文8792接入描述为历史V001阶段；8792和8793现已停服，有用资料归档到V003历史资料（本机路径：`local-data/原型/丧尸防线/V003-01a1a2af/历史资料/README.md`），原版本及研究数值保留，见[整合退役验证](../../reports/载具靶场/旧版整合与退役验证-V003.md)。

## 已确认方向

工程师已明确当前开发方向为载具打丧尸；原型采用Three.js、单机RTS指挥、战术镜头和低分辨率三维显示。首轮研究固定M1A2、AH-64D、A-10C各一套既有配装。普通丧尸暂以100生命值调参，不强制爆头；丧尸冲击基地或防线目标形成失败压力。当前没有敌方载具，载具受损机制后续讨论。

Hydra原始数据保留，作为后续清群候选；首轮仍以已有主炮、机炮、导弹和普通炸弹验证。坦克副机枪属于后续功能候选，不因原始配装存在就写成已实现。

工程师在接入讨论中追加确认：丧尸模式新增可开关警戒、默认开启，自动攻击射程内有效目标且手动指定优先；丧尸越过防线每只扣1点耐久，归零失败。工程师已授权按推荐方案实施，现已接入8792独立模式；实现顺序、固定翼警戒边界、三波初值与验收范围见[原型实施计划](载具丧尸战斗原型-第一版-01a1a2af-实施计划.md)，实际操作和测试入口见[靶场说明](../../src/载具靶场/README.md)。

## 推荐的实现顺序

1. 先建立丧尸受击接口和简化碰撞体，验证单体直击、唯一死亡事件和100生命基准。保留当前指定攻击和攻击移动的命令边界。
2. 接入范围伤害的空间查询、三维距离衰减和实心建筑遮挡；直击与范围不重复叠加，特效显示上限不影响伤害。
3. 验证旋翼机炮连发组、导弹目标死亡边界、固定翼扫射和离机炸弹；完整攻击周期包含进场与脱离。
4. 接入防守目标的生命与失败条件后，才评估清群速度是否满足波次压力。普通群体、稀疏群体和移动群体使用相同种子对照。
5. 合并载具、群体、伤害、死亡和表现后逐档测浏览器性能；不把独立载具或独立群体成绩外推为合并结果。

## 设计边界

本轮无装甲对抗，因此不让穿甲、方向装甲和现实弹药名称驱动普通丧尸伤害量表。原生方法签名和源字段保留为研究证据，公式、运行顺序、距离换算及枚举未验证处明确留空。

既有无限储备、装填、无友伤和手选旋翼武器继续作为已确认规则；有限弹药、补给、燃料、自动守区或自动切武器需要后续定案。保留空中单位前飞、进场与重定位成本，基地压力用于检验清群选择。丧尸不攻击空中载具时，出动成本与波次必须联合评估，不能只比较单发伤害。

当前靶场的弹丸撞建筑与爆炸伤害遮挡是两件事：前者已存在，后者未实现。单纯缩小爆炸半径不能解决隔墙受伤。当前靶场使用固定55%范围伤害，建议改成独立配置的内圈、外圈和边缘倍率，详见研究对照表。
