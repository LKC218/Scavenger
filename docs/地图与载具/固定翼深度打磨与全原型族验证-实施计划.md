## 二、第一批实施内容（Stage M1–M3，已落地待人工试飞验收）

### Stage M1：P0 体验断档收口
1. **引擎声学工况联动与加力声层（M1.1）**：
   - [载具空间音效.mjs](../../src/程序化地图/载具空间音效.mjs) `computeEngineMotionState` 优先消费 `unit.flightAttitude`（`flightState` / `throttleLevel` / `pitchDeg` / `afterburnerActive`），在巡航 `0.55` / 入航 `0.70` / 俯冲突击 `0.85` / 满推拉升 `1.0` / 加力全推间平滑切换声压、倍速与低通；
   - `AirEventAudioEngine` 新增 `syncAfterburnerAudio` / `stopAfterburnerAudio`（复用 `SFX_Afterburner` 与共享分桶，180ms 防抖 + 250ms 淡入淡出），`getDebugState()` 暴露 `engineThrottleLevel` 与 `afterburnerAudioActive`（A-10C 恒不触发）。
2. **固定翼 1 DrawCall 贴地投影软影层（M1.2）**：
   - [场景运行.mjs](../../src/程序化地图/场景运行.mjs) 新增直接挂于 `scene` 的 `airShadowRoot` + `fixed_wing_ground_shadow_1dc`（`InstancedMesh(16)` + `InstancedBufferAttribute('aAlpha')` + 高斯柔化十字轮廓 Canvas 贴图），按实时太阳方向水平投影，随 `agl (50→420m)` 缩放 `1.0×→1.45×` 与透明度 `0.42→0.12`，随 `|bankDeg|` 压窄横投影，天然隔离 Live PiP 与 VFX 6 池。
3. **Hydra 70 火箭巢空巢保留与三挂点真实发射口（M1.3）**：
   - [固定翼底座.mjs](../../src/程序化地图/固定翼底座.mjs) `hydra70_rocket` 启用 `keepPylonWhenEmpty: true`，`pylons 10/11/12`（`turret_5 / turret_6 / turret_8`）打空后保留 3 具空巢外观，并按真实挂点坐标 `+0.95m` 巢口前缘轮流发射。
4. **`air-lab` 控制台避让顶栏 & `focusCamera('plane')` 高空投影补偿（M1.4）**：
   - [实战HUD.css](../../src/程序化地图/实战HUD.css) `.scv-airlab-debug-panel` 移至 `top: 108px; right: 16px; max-height: calc(100vh - 356px)` 彻底避让顶栏与右下命令盘；
   - [固定翼调试模式.mjs](../../src/程序化地图/固定翼调试模式.mjs) `focusCamera('plane')` 接入 `projectAnchorToGround` + 动态 `focusFn` 跟踪，居中聚焦 215m 空中战机。

### Stage M2：P1 飞行物理手感与微缩写实临场感
1. **统一 L1 前视连续盘旋与轻量能量机动（M2.1）**：
   - [固定翼底座.mjs](../../src/程序化地图/固定翼底座.mjs) 新增 `computeL1OrbitCommand` 取代双段位置硬吸附，经协调转弯反推稳态坡度 `~30°`；新增 `computeEnergyManeuverDeltaMps` 实现俯冲加速与拉起爬升掉速。
2. **双发脉冲热诱弹 + 坠毁渐进失速/弹射短弧/撞地拖痕（M2.2）**：
   - `_queueFlareBurst` 升级为 `2+2+2` 双发脉冲扇面（`egress` 延迟 `0.22s` 起每 `0.18s` 抛一对）；
   - `crashing` 滚转速率由 `55°/s` 渐增至 `185°/s` + 不对称失速偏航抖振 + `agl > 45m` 触发 1 次 `spawnEjectionArc` 弹射座椅白烟弧 + 撞地调用 `spawnCrashSkidTrail` 在 `+14m / +26m` 落下递减焦痕弹坑与碎泥喷溅（0 新增 DC）。
3. **Live PiP 军工光电姿态仪 + 扫射微振（M2.3）**：
   - [实时实况镜头.mjs](../../src/程序化地图/实时实况镜头.mjs) 在固定翼非静态模式下叠加 2D 俯仰/滚转分段人工地平线、左速度右高度微标，并在 `strafeRecoilActive` 时施加轻量小窗相机微振。
4. **Air-Lab 靶区受击反馈升级（M2.4）**：
   - [固定翼调试模式.mjs](../../src/程序化地图/固定翼调试模式.mjs) 为受击致死模拟尸群增加 `0.45s` 径向击飞翻滚倒地淡出（维持 1 DrawCall），为损毁静态靶车增加 `<= 18s` 残骸余烟。
