# 载具丧尸战斗原型实施计划

版本：V001。工程师已明确授权按推荐方案实施并自行验证、完成后打开试玩。制作任务为`丧尸防线原型-V001-01a1a2af`，独立输出为`local-data/原型/丧尸防线/V001-01a1a2af/`；8792使用冻结运行源码。长驻消费者独立登记为`丧尸防线试玩服务-V001-01a1a2af`。原讨论与研究记录不代替本轮技术或人工验收。

## 已确认规则

- 载具打丧尸，单机RTS；首批M1A2、AH-64D、A-10C。
- 普通丧尸暂按100生命，不强制爆头。无敌方载具，地面载具受损后续讨论，Hydra后置。
- 新增可开关的警戒。丧尸模式默认开启，自动攻击射程内有效目标；玩家指定目标优先。
- 丧尸越过防线，每只扣1点耐久，耐久归零失败。
- 保留无限储备、装填、无友伤、旋翼手选机炮或导弹，以及固定翼单次攻击后脱离盘旋。

## 建议范围

在现有原型增加独立的丧尸防线测试模式，复用既有镜头、选择、指挥、三车模型和声音；角色与动画使用已准备资源。原始研究JSON保持研究用途，运行配置显式录入已经确认采用的建议值，不从research目录加载游戏规则。

主试玩默认各1辆或架、100只普通丧尸。场地建议在现有1200米飞行空间内设置约300×200米平地战斗区、两条通道和少量简模墙体；保留固定翼进场与转弯空间。以单款校准命中，再切换十三款混合测试，不改动冻结群体实验的历史样本。

防线耐久建议初值30；三波数量建议100、150、200，上一波清空后间隔10秒，第三波结束且耐久大于0为胜利。数量、波间隔、耐久、速度和随机种子面板可调。这些是待验证初值，不作为已通过的平衡参数。

## 新增警戒的边界

1. 对已开启的当前武器，自动选取射程内、视线有效、尚存活的丧尸。旋翼导弹必须由玩家切换，不自动替代机炮。
2. 警戒不主动追出射程；指定攻击的超程接近仍沿既有命令处理。默认不让多辆车因追逐残余丧尸离开防线。
3. 普通移动不因警戒擅自停止，地面或旋翼到达后才自动交战；明确的手动命令优先。关闭警戒不回收在途弹丸。
4. 固定翼的警戒不自动生成进场或攻击航线；继续由玩家指定目标或拖线执行扫射、轰炸，避免自动出动掩盖操作测试。
5. 指定目标死亡后结束该目标命令；恢复警戒时只在本地有效射程内重新选择，不让已发射导弹自动换活靶。

## 接入重点

当前`群体.mjs`固定58×44米及1米网格，不能直接套用1200米城市或简单缩放角色坐标。需要参数化战斗区及障碍，复用流场与局部分离思路；导航、弹丸、角色和镜头统一世界坐标。当前`health()`为运行状态统计，不是生命系统，须建立独立生命、活体、死亡与越线结算状态。

弹丸使用扫掠与简化碰撞体，按角色实际身高及缩放配置受击尺寸；十三款体型不同，不全部硬套1.8米。范围伤害使用空间查询、三维距离和实心墙遮挡，同弹同目标去重，直击与范围不重复叠加。特效数量限制不能截断伤害目标。

角色现有片段只有待机和移动，死亡先采用程序倒地，建议保留3秒后淡出；停止死亡角色的导航和活动动画，记录尸体预算，及时回收角色及统计。没有新提取的死亡动画，不把程序动作称为原生动画或布娃娃。

建议参数来源见[研究建议表](../../research/断箭/三车对丧尸研究/第一版-01a1a2af/网页原型建议参数.json)。先完整验证命中、连发组、装填、导弹目标失效及普通炸弹弹道，再凭试玩数据调数值；不为获得清群效果让飞机对整条航线直接扣血。

## 验收顺序

先验证1辆坦克加100只的闭环，再完成三车加100只的主试玩。压力档建议10车加300只、30车加500只，均独立测量，不继承单独靶场或单独群体实验的性能成绩。

测试覆盖直击与范围边界、实心墙前后、高速弹穿过小目标、双弹同帧击杀、导弹目标提前死亡、取消后的在途弹、警戒与手动命令冲突、暂停、越线一次扣分、三波结束和重复重开。保持相同种子与尸群密度对比，记录存活／死亡／越线总数守恒。

主验目标为当前开发电脑、Chrome和Edge、640像素内部渲染、有声战斗，预热后180秒整帧P95不超过16.67毫秒；同时记录P99、最长帧、模拟CPU、查询候选、弹丸、动画和尸体计数。技术通过与工程师操作、声音、节奏验收分开，不宣称其他硬件或更高档位通过。

## 本轮技术结果

16组规则、Chrome和Edge各7组真实UI操作、Chrome的K／B真实拖线发射与命中通过。主档两浏览器各180秒有声交战P95均约7.3毫秒；Chrome的10车首波300只60秒P95为13.5毫秒，30车首波500只为20.5毫秒、未达60帧预算。数量随1／1.5／2倍循环，分别保留实际存活范围，不能宣传为全程固定数量同屏。

原始长帧保留：主档最长约104毫秒，高档约201毫秒；高档模拟欠时增量约0.0013秒。换波仍有短暂峰值。完整条件、通过与未通过项见[验证报告](../../reports/载具靶场/丧尸防线原型验证-V001.md)。旧研究报告检查通过；全项目结构检查存在并行地图任务6份脚本缺导航，本轮新增项已登记，不代改其他会话职责。
