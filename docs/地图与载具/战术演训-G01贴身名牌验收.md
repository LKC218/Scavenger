## 设计与实现

1. 以车体／机身主体投影定位名牌；旋翼完整转动范围继续用于原有职责，不再推远名称。真实拾取仍使用原实例几何。
2. 局部八个槽位，默认轮廓外8个CSS像素；名牌边缘到主体矩形距离上限30个CSS像素。保留可用槽位，无全屏寻找空位的后备。
3. 未选中仅显示兵种图标和名称；选中／悬停展开状态。布局拥挤或单位在远景很小时降级为兵种图标；局部仍无空间时隐藏低优先级名牌，侧栏保持选择入口。极密集场景尚未做单独人工验收。
4. 每辆载具保留一张主名牌，直升机高度和状态并入主名牌；脚下保留投影标记及蓝色虚线，不重复姓名。
5. 名牌与主体以短实线连接，选中／悬停显示主体四角标记。标签悬停与真实机身悬停共用同一单位ID；引线和角标不接收鼠标事件。
6. 沿用原绿灰战术色、浅黄绿选中态，紧凑无衬线文字；未新增血量、弹药或其他尚未接入规则的数据。

`载具名牌.mjs`负责符号、局部布局及引线端点，`场景.mjs`负责主体投影和呈现，`输入.mjs`负责悬停归属。均在战术演训模块内；共享地图、模拟、寻路、飞行、高度及景别过渡规则未修改。

## 人工复测

1. 用Edge打开8814，确认页面标注G01 V004。
2. 先看坦克和直升机：能否快速判断每张名牌属于哪辆载具；比较8813原版。
3. 鼠标移到机身和名牌，核对高亮对象；点击两者，检查选择是否一致。
4. 选中直升机，查看一处名称与离地高度，并辨认脚下投影虚线。
5. 旋转、缩放、下令移动，观察是否无故跳边、标签挡住邻车或引线指错。
6. 拉到总览再返回，检查图标降级、选择和状态恢复。
