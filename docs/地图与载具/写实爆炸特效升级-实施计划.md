## 二、P1 阶段：去风格化重塑与动力学重构

### 2.1 池 2（`blastShellPool`）去科幻化与非发光贴地扬尘

1. **移除层**：删除 `layerKind=1`（菲涅尔能量半球）与 `layerKind=2`（规则格子双圆环）全部着色器分支与 `spawnExplosion` 发射代码；
2. **保留与重塑层**：
   - `layerKind=0`：**瞬时暖白高温爆闪核**（生命期 `45–95ms`，快速膨胀并在 `0.08s` 内衰灭，HDR `4.0–6.0` 仅在瞬间激发 `UnrealBloomPass` 1.35 阈值）；
   - `layerKind=3`：**贴地假光晕圆盘**（`0` `PointLight` 成本，仅在爆轰初期与爆心余烬期照亮地面接触区域，生命曲线前陡后缓）；
   - `layerKind=4`（池 2 新增贴地气浪或迁移至池 3 非发光卷曲气浪）：采用非发光（线性亮度 `< 0.35`）贴地外卷扬尘，通过贴图噪声驱动径向卷舒与柔边消散，彻底摆脱“发亮同心圆”的科幻观感。
3. **混合模式协同**：若池 2 需要同时承接高热爆闪（需激发 Bloom）与非发光外卷扬尘，将池 2 材质统一为 **Premultiplied Alpha**（`CustomBlending`, `AddEquation`, `OneFactor`, `OneMinusSrcAlphaFactor`）：高热核以低 Alpha 或高预乘 HDR `col * alpha` 写入达到累加致盲效果，非发光扬尘则按标准预乘遮挡 `dustLit * alpha` 混合，完美兼容且不增加 DrawCall。

### 2.2 池 6 破片烟丝 / 极细拉丝火花解耦与池 3 泥块纯化

1. **池 3 `layerKind=1` 碎块纯化**：
   - 彻底移除第 `477` 行的 `isSpark = step(0.68, fract(vSeed * 19.3))` 发光分支，池 3 仅保留**非发光深褐泥土与碎石块**（采用深棕黑泥土色、方向性太阳受光与低饱和度漫反射，完全不进入 Bloom）；
   - 重型/中型爆炸飞溅的暗色泥块可配合池 3 Billboard 泥尘/碎石子图块或紧凑低面暗块，严禁出现高亮橘色多面体方块。
2. **池 6 `kind=5`（细长冷白/灰白破片烟丝）**：
   - 保留 12 面拉长锥带几何，将其半径从 `0.55–1.55m` 大幅收窄至 `0.14–0.32m`，长度保持 `22–58m`（重型）/ `12–26m`（中型）；
   - 着色改写为**细长冷白/灰白高压凝结破片烟丝**（线性色 `0.36–0.72`，绝不超 `1.35` 阈值误触 Bloom，头段略亮尾段沿气流迅速化为缕丝淡出），搭配暗色小碎点破片，复刻《Defilade》高压破片高速撕裂空气留下的白烟射流。
3. **池 6 `kind=6`（新增极细 HDR 拉丝火花带，带防闪烁最小像素宽）**：
   - 专门承接金属穿甲（`light_api`）、高爆破片（`light`/`medium`/`heavy`）与受击飞溅的灼热细长拉丝火花；
   - 真实物理半径极细（`0.05–0.11m`），为防止在 `680p`（`pixelRatio = 1`）高空拉远时因亚像素光栅化丢失而严重闪烁，顶点着色器根据正交投影矩阵推算当前世界单位像素尺寸（或传入 `uMeterPerPixel = spanMeters / 680.0`），对侧向视觉半径施加物理钳位：`effectiveRadius = max(baseRadius, 0.75 * uMeterPerPixel)`，同时在片元着色器按 `clamp(baseRadius / effectiveRadius, 0.15, 1.0)` 反向缩放能量，实现**既不亚像素闪烁又保持极细丝质感**的能量守恒拉丝火花。

### 2.3 非对称簇状发射与三段式爆炸动力学

1. **2–4 主喷射瓣非对称簇状发射**：
   - 在 `spawnExplosion` 中根据确定性伪随机（基于坐标与 `simNowSec`）生成 `2–4` 个主方位喷射瓣中心角 `lobeAngles[]`（主瓣角偏差非均匀分布，其中一个主瓣能量较强、方向略倾角，另外 `1–3` 瓣形成错落高度与侧向喷射）；
   - 泥块、破片烟丝、爆心火团与翻滚黑烟按高斯/幂次聚集分布于这 `2–4` 个主喷射瓣内，并叠加大中小三阶随机尺度差异，彻底消除 V2.4 等角均匀对称圆环感。
2. **三段式真实物理动力学节奏**：
   - **第一阶段（`0 – 80ms`，极快爆轰）**：高初速外推、尺度从初始核急速冲击张开，爆闪核与强暖白内焰释放峰值能量；
   - **第二阶段（`80 – 300ms`，急剧膨胀骤停）**：在极强空气阻力 `drag = 6.5–11.0` 下速度在 `220ms` 内呈指数骤降，尺度曲线采用快速收敛包络 `easeOutExpo(norm, 6.0)`，还原高压气团撞击静止空气后“轰然顶开并猛然刹住”的厚重空气感；
   - **第三阶段（`0.3s+`，缓慢浮升飘散）**：热空气浮力主导（负重力 `vy` 缓慢抬升 + 微弱斜向战场风漂移），体积缓慢膨松化并随 Erode 通道逐步镂空消散。
3. **热路径零运行期 GC 彻底整改**：
   - 用固定容量 `MAX_FLARES = 64` 的 `_flareSlots` 预分配对象池替换 `this._flares` 数组与每帧 `aliveFlares = []`；
   - 将 `_syncRibbons` 内的 `pushV` 与 `_syncConeFx` 内的 `writeConeMatrix` 提升为实例私有方法（直接读写 `this` 字段与预分配 `_mat4`/`_pos`/`_quat`/`_scale`），消灭每帧闭包创建；
   - 将 `_pushFrameCone(obj)` 改为扁平数值签名 `_pushFrameCone(kind, x, y, z, dx, dy, dz, sx, sy, sz, ageNorm, seed)`，消除每发弹丸每帧的对象字面量分配。

### 3.1 离线 8×8（1024×1024）图集通道与生成规范

- **三段式图集帧演化**：

  - `Frames 44..63`：丝状撕裂消散期（奇偶瓣差异萎缩与渐增腐蚀，保留絮状余烟轮廓）。
- **双图集通道定义**：
  1. [smoke_vol_normal_alpha.png](../../public/assets/vfx-explosion/smoke_vol_normal_alpha.png)（8-bit RGBA PNG，`< 5 MB`）：
     - `R, G, B`：Front-to-Back 体积加权解析 3D 梯度法线 `N * 0.5 + 0.5`（X 右、Y 上、Z 朝向相机）；
     - `A`：平滑体积透射不透明度 `Alpha ∈ [0, 1]`。
  2. [smoke_vol_heat_thick.png](../../public/assets/vfx-explosion/smoke_vol_heat_thick.png)（8-bit RGBA PNG，`A = 255`，`< 5 MB`）：

### 3.2 Three.js 纹理加载、UV 映射与同步 `DataTexture` 兜底

1. **构造期同步 `DataTexture` 兜底**：
   - 在 `RealisticVfxEngine` 构造函数中同步生成 2 张 `64×64` 程序化 `THREE.DataTexture` 占位图（保证冷启动首帧渲染零黑块、零未绑定纹理警告）；
   - 随后通过 `THREE.TextureLoader` 异步加载 `/public/assets/vfx-explosion/smoke_vol_normal_alpha.png` 与 `.../smoke_vol_heat_thick.png`（支持构造 options 传入自定义 `atlasBaseUrl`，默认 `'/public/assets/vfx-explosion'`）；加载完成后原地更新材质 uniform 纹理引用。
2. **强制线性与无 Mipmap 配置**：
   - `tex.flipY = true`（显式保持默认）；
   - `tex.colorSpace = THREE.NoColorSpace`（**严禁使用 `SRGBColorSpace`**，避免硬件 Gamma 扭曲法线中点 `0.5 → 0.214` 与破坏黑体曲线）；
   - `tex.premultiplyAlpha = false`（避免清零透明区中性法线 `(128,128,255)`）；
   - `tex.generateMipmaps = false`、`tex.minFilter = THREE.LinearFilter`、`tex.magFilter = THREE.LinearFilter`、`tex.wrapS = THREE.ClampToEdgeWrapping`、`tex.wrapT = THREE.ClampToEdgeWrapping`。
3. **`flipY = true` 精确双帧混合 UV 公式**：
   ```glsl
   vec2 computeAtlasUV(float frameIdx, vec2 localUv) {
     float f = clamp(floor(frameIdx + 0.5), 0.0, 63.0);
     float col = mod(f, 8.0);
     float row = floor(f / 8.0); // 0 = PNG 顶行, 7 = PNG 底行
     return vec2((col + localUv.x) / 8.0, ((7.0 - row) + localUv.y) / 8.0);
   }
   ```
   支持按 `frameF = clamp(ageNorm * 63.0, 0.0, 63.0)` 对 `f0 = floor(frameF)` 与 `f1 = min(63.0, f0 + 1.0)` 进行线性插值 `mix(..., fract(frameF))`，彻底消除慢速黑烟跳帧。

### 3.3 池 3 Billboard 重构、Premultiplied Alpha 与黑体辐射照亮外烟缝隙

1. **几何与正交基 Billboard**：
   - 池 3 几何体从 `DodecahedronGeometry` 改为 `THREE.PlaneGeometry(1.0, 1.0)`，消除一切低模棱角；
   - 顶点着色器从 `viewMatrix` 提取 `camRight / camUp / camFwd`，按实例属性 `rot`（旋转角）与 `flipX`（依据 `seed` 镜像 X 以倍增形态变化，并同步对切线法线 `nTan.x *= vFlipX`）构造 Billboard 世界空间正交基，同时完美适配 `OrthographicCamera` 与 `PerspectiveCamera`。
2. **Premultiplied Alpha 单池统一混合与直渲色调映射防坑**：
   - 材质启用 `THREE.CustomBlending`（`AddEquation`, `OneFactor`, `OneMinusSrcAlphaFactor`, `depthWrite: false`, `transparent: true`）；
   - `outPremul = smokeLit * alpha + blackbody * fireMask * alpha * vFireBoost`；
   - 当 `fireMask = 0`（纯黑烟/扬尘/炮烟）时等价于标准 `NormalBlending` 遮挡，且线性色严格 `< 0.45` 绝不误触发 `1.35` Bloom；当爆心/凹陷缝隙处于高温阶段时，`blackbody` 飙升至 `1.15 ~ 5.60` 激发出真实选择性 HDR Bloom，且同一 DrawCall 内无缝过渡，不增加任何渲染池；
   - **新增 `finalizeVfxPremulColor(vec3 premulLinCol, float alpha, float linearOut)` 辅助函数**：在 `linearOut <= 0.5`（关闭 Bloom 直渲 sRGB）分支下，**必须先按 `premulLinCol / max(alpha, 1e-4)` 还原直色执行 `vfxAcesFilm` + sRGB Gamma（`pow(..., 1/2.2)`）后再乘回 `alpha`**，杜绝直接对预乘色执行非线性色调映射导致半透明边缘出现暗灰偏亮光晕。
3. **黑体辐射（900K–4200K）与外烟缝隙照明公式**：
   - 方向性受光：`wrapNdl = clamp(dot(N, uSunDir) * 0.52 + 0.48, 0.0, 1.0)`，耦合厚度自遮蔽 `sunLit`、`skyAO` 与宏观高度梯度 `macroGrad`；
   - 黑体冷却与缝隙透光：`coolThreshold = mix(0.08, 0.88, clamp(vAge * 1.18, 0.0, 1.0))`，`creviceTrans = mix(0.25, 1.0, pow(1.0 - thick, 1.55))`，`fireMask = clamp(smoothstep(coolThreshold, 1.0, heat + (1.0 - vAge) * 0.22) * creviceTrans * vHeatGain, 0.0, 1.0)`；
   - 色温分段映射：`900K–1600K` 深炭红暗烬 `(1.15, 0.16, 0.02)` → `1800K–2800K` 炽橘焰 `(3.40, 1.05, 0.14)` → `3200K–4200K` 过曝白炽核心 `(5.60, 4.10, 2.15)`；
   - **柔边溶解**：取代硬 `discard`，加入年龄混入权重：`erodeFade = mix(1.0, smoothstep(cut - 0.12, cut + 0.12, erode), smoothstep(0.50, 0.62, vAge))`，杜绝中早期 `cut = 0` 时在烟团上误挖出半透明硬洞，并在末期实现丝缕平滑消散。

## 四、P2 阶段：深度分离管线、Soft Particles、宏观受光、FBM 弹坑与斜风残烟

### 4.1 `预览入口.html` 正交相机分离深度通道设计（零双倍地形绘制）

由于地形（[程序化地形.mjs](../../src/程序化地图/程序化地形.mjs)）与植被（[立体植被与草丛.mjs](../../src/程序化地图/立体植被与草丛.mjs)）均依赖自定义顶点着色器采样高度与风动偏移，不能使用 `scene.overrideMaterial = MeshDepthMaterial` 重绘深度。故在 [预览入口.html](../../src/程序化地图/预览入口.html) 引入 **`OpaqueScenePass → depthCopyTarget Blit → VfxOverlayPass → UnrealBloomPass(1.35) → OutputPass`** 分离管线：

1. **Pass 链与资源初始化**：
   - 导入 `Pass`（`three/addons/postprocessing/Pass.js`）；
   - 为 `mainRenderTarget`（`HalfFloatType`, `samples: 4`）附加 `depthBuffer: true, stencilBuffer: false` 与 `depthTexture = createSceneDepthTexture(w, h)`（`THREE.DepthTexture(w, h, THREE.UnsignedIntType)`，`format = THREE.DepthFormat`, `NearestFilter`）；
   - 建立单采样 `depthCopyTarget`（`samples: 0, depthBuffer: true, stencilBuffer: false, depthTexture: createSceneDepthTexture(w, h)`）及状态旗标 `depthCopyInitialized = false`；
   - **`OpaqueScenePass extends Pass`**（`clear = true, needsSwap = false`）：隐藏 `vfxEngine.vfxRoot`，调用 `vfxEngine.setSunDirection(sunDirNormalized)` 同步主太阳方向，正常渲染不透明场景至 `readBuffer`；随后若 `!depthCopyInitialized` 先 `renderer.setRenderTarget(depthCopyTarget)` 初始化目标 FBO 并触发 MSAA resolve，再调用 `renderer.copyTextureToTexture(readBuffer.depthTexture, depthCopyTarget.depthTexture)` 将只读场景深度安全拷贝至 `depthCopyTarget.depthTexture`，避免 WebGL2 Feedback Loop；在 `finally` 还原 `vfxRoot.visible`；
   - **`VfxOverlayPass extends Pass`**（`clear = false, needsSwap = false`）：若 6 池全空则早退；否则绑定 `vfxEngine.setSceneDepth(depthCopyTarget.depthTexture, camera, state.internalWidth, state.internalHeight)`，暂存并隐藏非 `vfxRoot` / 非光源 / 非 `sun.target` 节点，置 `scene.background = null`、`renderer.shadowMap.enabled = false`、`renderer.autoClear = false`，在保留硬件深度缓冲测试的 `readBuffer` 上叠加渲染 `ScavengerVfxRoot`（零地形重绘、零阴影贴图重算），并在 **`try / finally`** 中原子恢复 `renderer.autoClear`、`renderer.shadowMap.enabled`、全部节点可见性与 `scene.background` 并调用 `vfxEngine.setSceneDepth(null)`。
2. **修复 Three.js `0.187.0` `RenderTarget.setSize()` 不缩放 `depthTexture` 及 `clone()` 共享引用陷阱**：
   - 实证 Three.js `0.187.0`（`three.core.js:9480-9513` & `three.module.js:18830-18838`）中 `RenderTarget.setSize()` 仅更新颜色纹理宽高而不更新 `depthTexture.image`，在窗口变化、`setAspectProfile`、`setResolution` 或 `captureAtResolution` 时将直接抛出 `Attached DepthTexture is initialized to the incorrect size` 异常；此外 `EffectComposer` 内部 `renderTarget2 = renderTarget1.clone()` 会令两张 RenderTarget 默认共享同一 `depthTexture` 引用；
   - 在 `resizeComposer(w, h)` 中封装 `resizeDepthTargets(rw, rh)`：先通过 `new Set` 对既有 `composer.renderTarget1.depthTexture`、`composer.renderTarget2.depthTexture` 与 `depthCopyTarget.depthTexture` 去重后安全 `dispose()`，随后**为 `composer.renderTarget1`、`composer.renderTarget2` 与 `depthCopyTarget` 各自创建独立 `DepthTexture` 实例**至精确 `(rw, rh)`，再调用 `setSize`，并置 `depthCopyInitialized = false`。
3. **兼容 `bloomEnabled = false`（零重复阴影绘制）与 `实时实况镜头.mjs` Live PiP**：
   - 当 `state.bloomEnabled === false`（直渲路径）且存在活跃 VFX 时，先隐藏 `vfxRoot` 将不透明场景渲染至 `depthCopyTarget` 获取只读深度；随后还原 `vfxRoot` 并绑定 `setSceneDepth`，**在第二遍 `renderer.render(scene, camera)` 前临时置 `renderer.shadowMap.autoUpdate = false` 并在 `try / finally` 中原子还原**，避免双遍直渲重复绘制阴影贴图，结束后清空 `setSceneDepth(null)`；
   - `renderPipWindow()` 调用 `pipCamCtrl.renderBeforeMainFrame(...)` 前强制 `vfxEngine?.setSceneDepth?.(null)`（且 `实时实况镜头.mjs` 本身通过 `isolateUnitBranchInScene` 自动隐藏 `ScavengerVfxRoot`），确保 Live PiP 零跨相机深度污染；
   - `beforeunload` 销毁 `depthCopyTarget` 及所有 `depthTexture`。

### 4.2 正交线性深度 Soft Particles 与宏观/地形融合

1. **正交线性深度 Soft Particles 公式**：
   - 在片元着色器中按 `screenUv = gl_FragCoord.xy / uResolution` 采样 `sceneDepth = texture2D(uSceneDepthTex, screenUv).r`；
   - 对 `OrthographicCamera`（`near = 0.1, far = 30000`），深度缓冲严格线性：`depthDiffMeters = (sceneDepth - gl_FragCoord.z) * (uCamFar - uCamNear)`；
   - 软粒子衰减：`softParticleFade = mix(1.0, smoothstep(0.0, uSoftFeatherMeters, depthDiffMeters), uHasSceneDepth)`（依据粒子尺度取 `uSoftFeatherMeters ≈ 0.35 * particleScale`，无深度时 `uHasSceneDepth = 0.0` 自动平滑退化为 `1.0`），彻底消除烟云与地面/建筑交界处的刀切硬线。
2. **主太阳方向同步与宏观云团受光梯度**：
   - 新增 `setSunDirection(vec3)`，每帧由 [预览入口.html](../../src/程序化地图/预览入口.html) 传入与 [镜头控制.mjs](../../src/交互系统/镜头控制.mjs) 一致的 `(-0.85, +1.45, +0.55)` 归一化矢量 `(-0.4806, +0.8199, +0.3110)`；
   - 新增实例属性 `aClusterHeightNorm`（记录烟团在当前爆炸/烟柱垂直包络中的归一化高度 `0..1`），片元着色器结合 `macroGrad = mix(0.55, 1.18, vClusterHeightNorm)` 形成蘑菇云顶伞高光迎阳、底部茎干背阴压暗的宏观 3D 体积纵深感。
3. **FBM 非规则焦坑翻土与余烬弹坑（池 4）**：
   - 升级 `craterPool` 片元着色器：采用 2D 多倍频梯度噪声 / FBM 扭曲径向边缘（取代规则 `sin(ang * 14.0)`），构造不规则撕裂焦坑边界、基于假高程差分的定向受光翻土隆起边缘（`dot(craterRimNormal, uSunDir)`），并在新建弹坑初期叠加随时间指数衰减的微弱爆心余烬热点（`aAge` 属性）。
4. **长时斜风黑烟柱与底层明火（受损/坠毁载具）**：
   - 扩展 `spawnDamageSmokePuff(worldPos, withSpark = true, options = null)`：当传入 `{ windVec, flameIntensity, scale, isCrashWreck }` 时，在地面残骸与坠落轨迹生成持续斜向随风（如 `windVec = { x: 4.5, z: 1.8 }`）飘升的浓黑烟柱（`layerKind=2` 体积烟团持续浮升与顺风平流），并在残骸底部叠加跳跃明火瓣（高热 `vHeatGain` + 柔和橙红跳动黑体辐射），与 [固定翼底座.mjs](../../src/程序化地图/固定翼底座.mjs) 第 `1787` 行坠毁残骸无缝对接。

1. 图集资产校验：`python -X utf8 -B scripts/程序化地图/烘焙爆炸体积云图集.py --verify-only`
2. 项目结构校验：`python -X utf8 -B scripts/检查项目结构.py`（退出码 `0`）
3. 固定翼规则校验：`node scripts/验证城市固定翼规则.mjs`（退出码 `0`）
4. 基线未改校验：`git diff -- src/程序化地图/渲染基线.mjs` 为空
5. 清理登记与缓存：`tmp/vfx-explosion-v001-7e8ac44c/` 下所有可再生验证截图在 M4 通过后按 `Scavenger写实爆炸特效升级-V001-7e8ac44c` 执行 `enroll --kind cache` 并核对 `status --task`。
