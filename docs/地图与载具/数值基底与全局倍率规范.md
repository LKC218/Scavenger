# 数值基底与全局倍率规范（`ba-source-ssot-v1`）

本文档与 [数值基底与倍率规范.mjs](../../src/程序化地图/数值基底与倍率规范.mjs) 共同构成全项目唯一的战斗数值基底与倍率配置规范，由 [检查项目结构.py](../../scripts/检查项目结构.py) 自动校验同源性。

---

## 一、唯一数据基底来源

- 单位与武器原值（`sourceRef`）统一采集自 **`https://brokenarrowstats.com/arsenal/?country=2&cat=6&lang=zh`**。
- 1 号样板机 **A-10C Thunderbolt II**：`https://brokenarrowstats.com/unit/a-10c-thunderbolt-ii-282/?lang=zh`。
- 9km 大地图采用真实 `1:1` 米制坐标，当前默认直接以原站 **`1.0×`** 数值作为唯一基底运行；未来如需对全军做加速、增伤或射程缩微，一律只调 `GLOBAL_BALANCE_SCALES`，禁止在各个单位、特效或 UI 文件里私自手编硬编码倍率。

## 二、`GLOBAL_BALANCE_SCALES` 冻结配置表

唯一定义位置：[数值基底与倍率规范.mjs](../../src/程序化地图/数值基底与倍率规范.mjs)（协议版本 `ba-source-ssot-v1`）。

| 倍率字段 | 当前默认值 | 作用范围 | 说明 |
|---|---:|---|---|
| `hpScale` | `1.0` | 所有载具/固定翼 `HP` | 原站步兵约 `1`、A-10C `30`、主战坦克 `18–24` |
| `damageScale` | `1.0` | 所有武器单发伤害 `damage` | 按原站单发/脉冲伤害直接放大或缩小 |
| `weaponRangeScale` | `1.0` | 武器对地最大与最小开火距离 | 统一缩放各武器 `groundRangeM` 与俯冲防撞下限 |
| `projectileSpeedScale` | `1.0` | 弹药、火箭弹与导弹飞行速度 | 统一经 `deriveWeaponStatsFromSourceRef` 缩放 `sourceRef.projectileSpeedMps` |
| `airSpeedScale` | `1.0` | 固定翼突击航速 `attackSpeedMps` | 原站 `speedKmh / 3.6 * airSpeedScale` |
| `orbitSpeedFactor` | `0.78` | 固定翼常规盘旋速度 `cruiseSpeedMps` | 仅限盘旋圈内相对突击速度系数，兼顾鼠标点选与观感 |
| `opticsScale` | `1.0` | 载具光学/侦察视野半径 `visionRangeM` | 按原站 `opticsM * opticsScale` 派生 |
| `costScale` | `1.0` | 单位部署造价 `cost` | 保持原站配队造价比例 |
| `fuelDurationScale` | `1.0` | 固定翼留空基准燃油时长 `fuelMaxSec` | 全系列 32 架固定翼取消实战血量结算，改用战术燃油限制（保留 `sourceRef.hp` 留底） |
| `rearmCooldownScale` | `1.0` | 固定翼离场后机场整备冷却 `rearmCooldownSec` | 返航离场后按原型族自动补油补弹（30–45 秒）恢复可呼叫状态 |

## 四、丧尸与试验靶标同量纲规范（`ZOMBIE_TARGET_BASE_STATS`）

为了避免旧手编 `HP 100` / `单发伤害 420` 与原站基底 `1.0×` 错位：
- **调试静态靶车**：`staticTargetHp = 18`（对应原站中轻装甲靶标量纲：GAU-8 需集中扫中多发，AGM-65 `22.0` 与 JDAM `56.0` 可直接摧毁）。
- **模拟丧尸群**：`zombieHp = 1.5`（对齐原站步兵 `~1 HP` 量纲：GAU-8 单发 `2.25` 扫过即成片清空，Hydra `7.5` 与 JDAM `56.0` 按两段爆破半径递减结算）。

## 五、研发强制红线

1. **禁止手写覆写派生值**：所有新建或重构载具、固定翼、武器、丧尸预设只在注册表填写原站 `sourceRef`（及物理半径/杀伤盒等 3D 补充字段），必须调用 `deriveAircraftStatsFromSourceRef` / `deriveWeaponStatsFromSourceRef` 生成运行值。
2. **禁止分散倍率**：如需全局平衡微调，只允许修改 `src/程序化地图/数值基底与倍率规范.mjs` 内的 `GLOBAL_BALANCE_SCALES`。
3. **自动门禁检查**：[检查项目结构.py](../../scripts/检查项目结构.py) 内 `check_balance_scales_sync` 会在每次校验时强制检查 `数值基底与倍率规范.mjs`、`数值基底与全局倍率规范.md`、`固定翼底座.mjs`、`AGENTS.md` 与 `apps-code-map.md` 的同步性。
