## 0. 已确认设计口径、分轨总览与全局红线

### 0.1 已由工程师确认的 4 项产品口径

1. **多高度载具战术图标（近景不显示）**：采用 **4 级视距 `span` 自适应分层**（`≤260m` 近景零图标、`260~650m` 紧凑 12 类剪影徽章、`650~2200m` 标准战术筹码 + `≥3` 辆密集簇聚合、`>2200m` 极简战略点标），全部绘制在原生 DPR 高清 2D 标绘层并同步点选/框选热区。
2. **固定翼地面范围圈重设计**：取消 `y = 234m` 空中整圈以消除 48° 正交俯视产生的 `~211m` 地面视差错位，改为 **“贴地主范围圈（起伏高程采样 + 淡紫微填充 + 双层描边与方向箭头）+ 垂足虚线与地面圆周实时滑动跟踪点 + 机头极短 35° 转向弧”**。
3. **载具动画两步演进**：
   - 先做**纯前端运行时动画**（129 车通用刚体姿态 + 接入已有 37 车旋翼/炮塔/雷达旋转驱动）；
   - 后按需单开离线重编译对话，补拆 2 架倾转旋翼与剩余地面主力带炮塔/发射架车型。
4. **载具 3D 空间引擎音效**：对去重后的 **36 条唯一 `MoveEvent` 原音** 离线批量派生无缝循环 OGG、补齐 5 车映射入库，再复用 8 声部空间混音底座接入 `/play`（随视距 `span` 平滑淡出、`/settings` 独立开关），**永久保持点击/框选/下令零 UI 提示音**。

#### 2) 关键算法与数据结构要求

- **同源剪影离屏缓存**（落点：[src/界面规范/图标与标绘.mjs](../src/界面规范/图标与标绘.mjs) 新增纯函数，并由 [src/交互系统/指令与标绘层.mjs](../src/交互系统/指令与标绘层.mjs) 调用）：
  - 启动时将 `VEHICLE_SILHOUETTES` 的 12 类 SVG path 预编译为离屏 `Path2D` 或按色板缓存的离屏 Canvas（避免每帧重复解析 SVG 或新建 DOM 节点），保证 100 混编同屏绘制耗时 `< 0.5ms`。
  - 导出纯规则函数 `resolveZoomIconTier(span)` 返回 `'none' | 'compact' | 'chip' | 'overview'`，以及纯规则函数 `clusterScreenUnits(projectedItems, { radiusPx = 18, minClusterSize = 3 })` 返回单车节点与聚合簇列表（`{ isCluster: true, channel, dominantKind, count, unitIds, screenPt, selectedCount }`）。
- **密集簇聚合规则（`L2 / L3`）**：
  - 仅聚合**同一通道**（`ground` / `heli` / `plane`）且屏幕距离 `< 18px` 的单位；若满足 `count ≥ 3`，合并为单枚主兵种筹码 + 右上角高对比 `×N` 徽标（若簇内含选中单位，外框亮选中金）。
  - 鼠标悬停簇筹码时，在簇中心周围做轻量放射展开提示或列表气泡；左键点击簇筹码一次性选中该簇内全部允许通道单位（按 `Shift` 增减），保持框选与 `Tab` 重叠循环语义不冲突。
- **点选热区同步**（[src/交互系统/战场适配器.mjs](../src/交互系统/战场适配器.mjs)）：
  - 在 `L1~L3` 档位下，`pickUnits(localX, localY, channelFilter)` 除机身投影半径外，同步检测单位当前筹码/簇图标的屏幕矩形盒（`±(w/2 + 4), ±(h/2 + 4)`），做到中远景“看得到图标就能稳稳点中”。
- **与 `场景运行.mjs` 名牌阈值联动**：
  - 将 [场景运行.mjs](../src/程序化地图/场景运行.mjs) 中原固定 `currentSpan > 750` 隐藏名牌的规则与 4 级档位对齐：`L0 (≤260m)` 全量显示；`L1 (260~650m)` 仅显示选中/悬停单位的精简呼号；`L2/L3 (>650m)` 全部交由 2D 标绘层图标接管，零重复叠字。

### 2.3 Stage 1B：固定翼地面范围圈重设计

#### 1) 视觉与几何规格（已敲定方案）

在 [src/界面规范/图标与标绘.mjs](../src/界面规范/图标与标绘.mjs) 新增地面盘旋范围圈绘制原语 `drawGroundOrbitZone(...)`（保留原有 `drawHighOrbitTrack` 签名兼容 `/ui-spec` 或同步升级规范台展示，避免破坏 `验证界面规范.py`），并在 [src/交互系统/指令与标绘层.mjs](../src/交互系统/指令与标绘层.mjs) 中对所有 `role === 'fixed_wing'` 单位切换为新方案：

1. **贴地主范围圈（`y = queryGroundHeight(wx, wz) + 0.15m`）**：
   - 以 `u.orbitCenter` 为圆心、`u.orbitRadius`（默认 `85m`）为半径，按 48~64 段均匀采样真实地形高程 `queryGroundHeight(wx, wz) + 0.15`，投影为贴合起伏地形的闭合多边形；
   - **填充**：淡紫微填充 `rgba(181, 148, 255, isSelected ? 0.10 : 0.05)`（从语义色板 `pal.plane` 派生，严禁硬编码）；
