## 格式兼容性与问题处理

| 实测 | 结论 |
| --- | --- |
| RIFF/FEV | 主 bank 的 FMT 数据为 `8700000084000000`；没有凭缺少明文 FSB5 判定全部封装性质 |
| 随附 FMOD | 实际 `2.01.11`；初始 7 个 bank 读取到 352 个事件 |
| 样本设置 | A-10 未应用源设置时样本加载状态为 ERROR；应用实际序列化设置后为 LOADED，事件渲染成功；没有猜测键值 |
| vgmstream | 官方 `r2168` Windows x64 下载摘要匹配，帮助可读但退出码为 1；直接识别 `SFX_Unit.bank` 失败，不扩张为所有解码路线都不可用 |
| 缺项复核 | 额外扫描安装中 37 个非 strings bank 的事件元数据；Kiowa 旋翼实际在 `Dialog.bank`；毁伤路径经原生 GUID 查找证实大小写别名 |
| 输出路径 | 随附 WAV writer 的中文绝对路径报文件错误，改为经边界校验的批次内工作目录与相对文件名 |
| WAV 容器 | 原运行库 RIFF 总长度少 4 字节；保留原件并仅重封装 data 块，PCM 不变 |

接口字段参考 [FMOD 官方 Unity 源码](https://github.com/fmod/fmod-for-unity/tree/2.02/Assets/Plugins/FMOD/src)，其分支版本与实测运行库分别记录。无声卡离线混音模式参考 [FMOD Core 系统接口](https://www.fmod.com/docs/2.04/api/core-api-system.html)；工具来源为 [vgmstream r2168 官方发布](https://github.com/vgmstream/vgmstream/releases/tag/r2168)。跨版本参考只用于理解接口，不代替本批次实测。
