## 交付版本选择

空中 46 项采用视觉通过的装配版；F-35A、F-35B、B-1B、B-2 采用已通过的原始机体版，未采纳未通过的默认外挂装配。另有 2 个旧 AC-130 根仅作参考。地面 77 项采用当前装配流程的结果，其中 2 项列为待修。

| 型号 | 选择与原因 |
| --- | --- |
| `US_A10` | 装配版；机翼下炸弹、导弹与干扰吊舱位置通过正面和斜向复查 |
| `US_F35A`、`US_F35B` | 机体版；默认装配部分 AIM-120 槽位重合，发射节点不足以证明静态安装位置 |
| `US_B1B`、`US_B2` | 机体版；默认装配弹药悬浮在机体前方，无法证明弹舱显隐及安装语义 |
| `US_CV22` | 修复后装配版；共同骨架尺度差异造成尾门过大，改用保留静态几何尺寸的刚体帧候选并重新审图；未证明运行时骨架等价 |
| `US_AAVP_Arty` | 按数据库槽位消除重复 MICLIC，仅保留一份对应部件 |
| Patriot 三型 | 按共同根和直接父骨架证实锚点后合并，位置通过多视角检查 |

“默认装配”来自数据库与序列化引用：优先基础配置、显式默认选项；无默认字段时按最小 `Order` 再最小 `Id` 选择并记录。它不是玩家存档配装，也不覆盖所有改装组合。

## 实施与修复

1. 固定输入构建号、单位包完整 SHA-256 与工具版本，流式解压并建立对象索引。单位包解析到 161687 个对象，包括 4429 个 Mesh 和 2297 个 Material。
2. 选取最高细节 LOD 与初始有效显隐，保留层级、双 UV、法线和材质引用；蒙皮在初始绑定姿态下转静态。
3. 按材质 `groupName/itemName` 选择提取虚拟纹理。Normal/Mask 的语义、色彩空间及迷彩公式由属性与实际编译 Shader 核验；保留原始和派生贴图。
4. 解析数据库与 Addressables 正式映射，按已核验锚点合并独立炮塔、外挂与尾门；不凭名称相似猜装配。
5. 后台 Blender 构建、保存、独立进程重开和 GLB 回读；对照包围盒、三角形、缺图与非有限坐标。
6. 每项实际查看整体、反侧、正面、顶部和 GLB 回读图。修复 Granite 并发独占导致的缺图、FA-18D 纹理重试及 39 项乘员 `_Albedo` 属性未识别问题，修复产物重新审图。
7. 根据通过版本写交付选择，核对载荷回执与当前审核图指纹，复制后逐文件再次计算 SHA-256，生成离线模型库。

AssetRipper 2.0.0 小包探针仅证明该接口的解析范围；它未承担主批次导出。主流程使用 UnityPy 1.25.4、GraniteTextureReader 1.1.5、本地 .NET 9.0.22 与 Blender 5.2.3 LTS。具体脚本与复现接口见 [脚本维护说明](../../scripts/脚本维护说明.md)。
