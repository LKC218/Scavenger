# Codex风格对话分享

双击“断箭资源与地图-Codex对话.html”离线打开。

- 主区直接显示用户消息和助手历史答复，按时间顺序连续阅读。
- 左侧29轮目录点击定位；手机点击左上角菜单打开目录。
- 顶部搜索可筛选轮次并高亮关键词，Ctrl或Command加K聚焦搜索。
- 默认隐藏过程更新，可勾选显示；技术导览和计划附件从侧栏进入。
- 支持深色／浅色切换与打印当前内容，无外部运行依赖。

V002包含独立保存的29轮脱敏数据和计划快照，不跟踪其他执行对话的后续结果。不包含游戏资产、本机路径、内部标识、工具日志或系统上下文。此为Codex风格的只读分享页面，并非官方Codex产品，也不能在页面中发送消息。
