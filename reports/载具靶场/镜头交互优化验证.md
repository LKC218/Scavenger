# 载具靶场镜头交互优化验证

日期：2026-11-03。运行入口：[打开载具靶场.cmd](../../打开载具靶场.cmd)，操作与源码参数见[靶场模块说明](../../src/载具靶场/README.md)。本轮针对工程师反馈的平移、缩放和旋转生硬进行调整。

## 实施范围

| 已确认要求 | 当前实现 |
| --- | --- |
| 平移更顺、松键尽快停稳 | WASD短加速和快速减速，斜向输入归一化，真实帧时间与速度解析积分 |
| 缩放围绕关注点 | 滚轮以鼠标指向的地面位置为锚点，约150毫秒完成95%的响应 |
| 旋转减敏与少量平滑 | 中键0.004弧度／显示像素，约84毫秒完成95%的响应，指北针按投影北向同步 |
| 默认阅读局部战斗，拉远总览 | 正交视野跨度129改为96，范围58至180，俯角保持约49.7° |
| 主动聚焦，选择和命令不抢镜头 | C或按钮只聚焦一次，支持Tab子选择及空中高度；不自动跟随 |

3至5辆车是局部战斗的阅读目标，单位密集时可见数量可以更多。没有为了限制可见数而改动部署或隐藏单位。F平滑复位，重置立即复位；小地图平滑定位。手动镜头输入打断聚焦；失焦清除输入、速度及未完成镜头动作；暂停模拟时仍可观察战场。

平移启动／松键时间常数为45／22毫秒，聚焦时间常数75毫秒；时间常数的三倍约完成95%的响应，不能把它当作精确收敛总时长。速度为当前跨度×0.48米／秒。参数是本项目的调试值，不是《RESTAND》或《断箭》的官方相机参数；RESTAND精确投影、俯角与阻尼曲线尚未测定。

## 功能与数值检查

Chrome 156.0.8078.79和Edge 156.0.4314.58分别通过8组镜头专项检查及10组完整靶场回归，页面错误与控制台错误记录均为空。真实浏览器键鼠检查和控制器数值检查分别记录。

| 检查 | 实际结果 |
| --- | --- |
| 默认与按钮状态 | 初始跨度96；未选单位时聚焦按钮禁用 |
| 滚轮锚点 | 每显示帧采样，Chrome 101次、Edge 100次；最大偏差均约0.0934显示像素，缩放单调，连续滚轮可收敛到最小跨度58 |
| 中键与指北针 | 真实拖动130显示像素后角度0.52弧度，指北针与投影世界北向误差小于0.001弧度 |
| 聚焦与镜头归属 | 按钮和C分别聚焦地面、空中单位，屏幕中心误差小于0.1像素；选择及下令不移动镜头，移动后不跟随，聚焦按钮不下达载具命令 |
| 打断、失焦与暂停 | WASD打断聚焦；注入窗口失焦事件后无残余平移；暂停期间镜头可动，模拟时钟冻结 |
| 确定时间步长 | 30／60／144时间步长下，半秒平移加约0.3秒停稳的位移差约0.000032米；单轴与斜向距离一致；默认跨度松键滑行约1.014米 |
| 十单位与镜头并行 | 向靶标下达攻击后，用真实键鼠平移、缩放，分别记录约6.1秒采样与截图，共16次发射 |

数值检查直接调用同一实际镜头控制器，验证帧时间计算；它不代表三种刷新率硬件均已试玩。失焦专项通过派发窗口事件检查清理回调，不等于长时间真实切后台验收。完整回归还覆盖选择、队列、受阻、暂停下令、声音实例和三次重置。11组独立战斗规则复核通过；原件与派生资源摘要复核通过，涉及10项输入、10项媒体路由。

## 帧时间与测量条件

本机Windows 11，Ryzen 7 9800X3D，约31 GiB内存，RX 7900 XTX，ANGLE Direct3D11；独立无窗口浏览器、1600×1000页面视口，战场显示区域1290×796。10单位、6个初始靶标、4组障碍，三维内部640×395或480×296，HUD保持显示分辨率。两款浏览器串行采样。

| 浏览器／样本 | 时长 | 帧数 | P95／P99毫秒 | 大于20毫秒帧数 |
| --- | ---: | ---: | ---: | ---: |
| Chrome 640档完整回归 | 约10秒 | 1652 | 6.2／6.2 | 0 |
| Chrome 480档完整回归 | 约10秒 | 1651 | 6.2／6.2 | 0 |
| Edge 640档完整回归 | 约10秒 | 1652 | 6.2／6.2 | 0 |
| Edge 480档完整回归 | 约10秒 | 1641 | 6.2／6.2 | 1 |
| Chrome 640档镜头专项 | 约6.1秒 | 1010 | 6.2／6.2 | 0 |
| Edge 640档镜头专项 | 约6.1秒 | 1010 | 6.2／6.2 | 0 |

完整回归各档均有16次发射、12次伤害命中、1个靶标销毁，包含接近、射击与销毁后的待命阶段，不是连续全火力压测。完整回归末帧211次绘制、573033个三角形；镜头专项末帧215次绘制、573353个三角形，视野与临时效果不同会改变统计。三次重置后几何资源由76回到66、纹理保持29；本样本未见持续增长。

P95低于60 FPS对应的16.67毫秒预算，但短时无窗口结果不能证明可见窗口长期稳定60 FPS。最慢帧、其他电脑、更多单位、真实后台恢复和主观手感没有因此获得验收。首轮129视野数据保留于[原型实现与验证](原型实现与验证.md)，不混用阶段统计。

## 证据、边界与试玩

镜头专项入口：[验证靶场镜头.py](../../scripts/验证靶场镜头.py)；完整回归入口：[验证载具靶场.py](../../scripts/验证载具靶场.py)。完整JSON和截图保存在忽略目录的原型验证区，镜头专项使用`验证/镜头修订1/`，正文不包含本机原件绝对路径或私人配置。

镜头中心边界为x范围−65至65、z范围−75至65。中部锚点偏差通过检查，触及中心边界时优先限位，不能保证鼠标地面锚点仍完全固定。主动聚焦保持当前跨度；大范围分散的选中组不会自动拉远至全部入画。

建议试玩约2分钟：按住WASD后松键观察停稳，滚轮指向某辆车反复缩放，中键转向，选择移动载具后按C观察一次聚焦；重点反馈启动、停稳和缩放是否仍生硬。此项由工程师实际体验确认。
