01

文件放在哪里

先判断授权与内容，再决定存储位置。私有仓库或网盘只控制访问，不替代再分发许可。

文件去向与交付条件；筛选仅改变显示，不修改文件。
文件 / 资源去向交付条件
src/、scripts/GitHub自有源码、实际维护脚本及就近说明；检查硬编码路径和第三方许可。
docs/、README、AGENTS、启动器、忽略规则GitHub保留团队规则和无敏感值模板；审核个人专属配置。
research/、reports/审核后进入 GitHub检查第三方图片、视频帧、预览及私人信息，控制媒体体积；不整目录默认放行。
靶场模型、动作声音独立运行资源包必须允许团队共享，匹配代码与模型部件接口，按摘要去重。
Blender 工程、贴图、源模型按需编辑资源包仅交给需要编辑的人，附许可、修改说明和软件版本。
Three.js 与第三方工具固定依赖交付 / 官方获取固定版本、官方来源、许可证和摘要；不复制整个虚拟环境。
丧尸候选素材核对许可后独立交付项目清单标记 CC BY 4.0；首次共享前核对来源并附作者、许可及修改说明。
私有路由、真实路径配置接收端生成保存在 local-data/，不提交原机绝对路径。
缓存、日志、临时文件、虚拟环境本机保留 / 重建沿用忽略规则；必要证据单独归档。
《断箭》提取模型、贴图、音频及派生工程授权待确认确认团队再分发授权前不放入仓库或共享包；首轮优先使用许可明确的替代素材。
游戏安装文件、资源包、随游戏 DLL不进入通用共享包研究人员自行从合法来源准备，具体操作仍须符合适用许可。
密钥、Cookie、账号凭据不进入仓库或普通资源包确有需要时按人员单独授予访问权限。

目录边界：local-data/、tmp/、temp/ 继续忽略。未来明确批准的正式运行资产另行确定目标目录，不按媒体扩展名全局排除。

后续独立确认。交付选定版本的实际引用媒体及必要记录，不要求所有人复刻全部批次。

04

从你的工作角色开始

切换角色查看需要拿到什么。接入步骤是目标流程，其中资源导入与独立检查尚未实现；当前不能直接照此完成全流程。

首轮优先交付

先让靶场在自己的电脑运行

需要：代码仓库、运行资源包、固定 Three.js。Python 建议统一 3.12；浏览器使用 Chrome 或 Edge。准备好的靶场服务仅依赖 Python 标准库，不要求 Blender、Node.js 或游戏目录。

  1. 克隆代码，切到指定版本

    代码提交或标签必须与资源包清单匹配；仓库尚未建立。

  2. 准备固定依赖与批准资源

    取得 Three.js 0.187.0 的文件、许可证及配套摘要，获取许可已核对的运行包。

  3. 导入到本地，生成路径 待实现

    校验包摘要和目录边界，不复制原机私有路由。

  4. 校验运行资源 待实现

    不依赖原始提取目录，缺文件或不兼容时停止。

  5. 启动并完成操作检查

    确认模型显示、移动、攻击和声音；跨机验证仍待进行。

按需交付

编辑源工程，交付新版本

需要：代码说明、许可明确的源工程、贴图、修改说明，以及已确认的 Blender 版本。

  1. 核对来源与编辑范围

    确认资产 ID、源工程版本、许可及本次需要修改的部件。

  2. 领取主要编辑职责

    同一个 Blender 文件指定主要编辑者；并行编辑用不同版本文件交接。

  3. 保留模型接口约定

    替代素材需满足部件、动作和运行数据接口，不能只换文件名。

  4. 交付新资源版本

    记录修改、摘要和兼容代码；模型外观、运行表现和设备性能分别验收。

后续独立范围

交付需要的资料，不复制整台机器

资料库需要选定版本的索引与实际媒体、接收端路由。研究复现另行确认工具、许可和只读输入范围。

  1. 明确资料库或研究范围

    普通开发不附带批量提取、历史迁移或清理任务。

  2. 准备选定版本与必要文件

    资源按稳定 ID 和摘要定位；工具按官方固定来源准备，不搬运虚拟环境。

  3. 重建接收端路径与版本记录 待实现

    保留来源端历史快照，不全局替换路径后继续沿用旧指纹。

  4. 查询、启动及核验

    资料库使用 8767；研究所需游戏和工具路径自行配置，不作为靶场前提。

导入时必须确认

  • 代码与资源包版本兼容。
  • 每个文件的字节数与摘要正确。
  • 拒绝绝对输入路径、路径穿越和逃逸目录的链接。
  • 遇到已有不同内容时停止，避免覆盖。
  • Three.js 版本指针、元数据和实际文件一致。

来源证据与运行检查分开：普通开发者不必取得所有历史输入。仅设置一个环境变量，目前不会自动改写现有路由。

已有启动命令

前提：资源、固定依赖及本机路由已准备完整。以下命令不会下载资源，也不会替你完成导入。请在项目根目录执行。
载具靶场 · 前台启动
python -X utf8 -B scripts/预览载具靶场.py --serve

浏览器访问 http://127.0.0.1:8768/；Ctrl+C 结束前台服务。也可双击“打开载具靶场.cmd”。

资料库 · 资源准备完整后
python -X utf8 -B scripts/断箭/启动正式资料库.py --open

浏览器访问 http://127.0.0.1:8767/。仅本机访问；不要通过通用静态服务暴露整个项目。

运行、派生和自动验证分别需要什么？

准备好的靶场：Python 标准库、浏览器、Three.js 和运行资源。模型派生：另需 NumPy、Pillow 及资料库源资产。模型编辑：需要匹配的 Blender。规则验证：需要 Node.js。浏览器自动验证：需要 Playwright 和对应浏览器。当前靶场没有 npm 安装步骤。

缺文件、摘要错误或 Three.js 校验失败怎么办？

优先核对包版本与完整性、接收端绝对路径、目录边界及固定依赖元数据。缺资源时不要直接要求新人执行 --prepare。先用前台启动查看错误；端口冲突需核对程序身份，不批量结束服务。声音程序检查与人工听审分别记录。
