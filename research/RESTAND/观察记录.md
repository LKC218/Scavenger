## 实际交互链

### 一、载具不是只有一个目的地点

选中载具 → 本体白色选中环、单位名称和指令格同步出现 → 地面出现与车身形状相似的目标轮廓和连线 → 目标位置/朝向变化 → 车辆移动、转向，期间战斗仍持续。4–13秒做5fps复查；76.8秒高清帧可读BRADLEY IFV与护甲/燃料标签。

目标轮廓表达了到达姿态，连线表达本体与目标的关系；不能称为已验证导航路径，不能据此反推右键长按或拖动定向。未验证阻塞、不可达和命令队列。

### 二、真正的多选在2分19秒附近

139.2秒绿色矩形出现 → 139.3–139.6秒边界连续向右下扩张并覆盖两组步兵 → 139.7秒矩形消失，多个成员脚下出现选中环，面板显示RIFLE SQUAD ×2、两张队伍卡、10/10 → 后续显示两组目的地连线。138.8–140.4秒以10fps核对。

**纠正：** 56.8–58.0秒白色矩形伴随REINFORCED WALL与MG NEST切换，是建筑选中边界证据，不能混作拖拽框选。已确认矩形选择多个小队；鼠标键、Shift/Ctrl、永久编队和取消规则仍未核实。

### 三、选择决定当前可用动作

直升机：选择GUNSHIP → 圆环、在空中状态、护甲/燃料与指令格 → 悬停显示LAND和FIGHT HERE等动作说明 → 继续调整地面目标和机位。只确认提示与移动，没有看到完整落地/加油。

兵营：选择BARRACKS → 建筑白色边界、3000/3000和带数字的动作格 → 切换步兵后面板转为成员卡。没有完整“支付→排队→训练完成→新单位出现”链，不能把数字自行解释为已核对成本。

### 四、局势变化需要前后结果

190.5秒FIRE HERE提示向指定地点持续射击（标注Z）；城市中的坦克射击、爆炸与建筑持续冒烟 → 约218–220秒建筑分块坠落、尘雾扩张 → 镜头拉远重新观察街区。证实该建筑的破坏表现；不证明全部场景可破坏或道路碰撞已正确更新。

### 五、火炮能力有预览、延迟与风险说明

选择“LONG TOM”203毫米火炮 → 246秒悬停提示203 MM FIRE MISSION（标注快捷键F） → 253.6秒指令格高亮 → 254.5秒双圆范围预览与方向刻线 → 约256秒预览消失 → 约259秒基地内炮位烟团、260.5秒任务通知与9:55冷却 → 约265秒起目标区域连续爆炸。

提示文案声称10发、覆盖70米圆、地图任意位置、重装填10分钟、每发惊动300米内敌人。这些是**UI提示数值**，不是测量结果：未逐发计数，未验证米制尺度、惊动AI或10分钟冷却；双圆不能直接指定一个是70米、另一个是300米。实际通过鼠标还是F触发也未知。该段不是仅凭特效推定的空袭。

## 可归纳的局部玩法与仍缺失的循环

画面支持的局部循环是：巡视战线 → 选择地面/空中单位或设施 → 检查当前状态和动作 → 调整位置/朝向或指定火炮区域 → 观察行动、损毁和爆炸 → 再部署。选择不同对象会显著改变操作上下文，战斗并不随面板查看而停止。

未补齐的是“获取资源→建造/训练→补给运输→维持作战→达成胜负”的完整循环。顶部存在NIGHT 1、DAY 2、资源/人口/CP/RP和噪声/光照等字样，但名称并不能建立各系统的因果规则；片尾没有结算。
