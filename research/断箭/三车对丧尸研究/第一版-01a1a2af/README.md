## 研究口径

样本固定为`model:US_M1A2`、`model:US_AH64D`、`model:US_A10`，单位ID依次245、19、282，沿用构建26273833静态配装。没有混入其他型号或未选改装。原始数据不冒充现实性能或当前安装最新版；方法签名只证明声明，不证明执行顺序与公式。

原始表行中保留枚举数值、位掩码、距离／速度／时间原值与关系数量，不静默换算。所有对丧尸建议以100生命为独立量表。工程师已确认基地／防线压力、不强制爆头、Hydra后置；碰撞尺寸、伤害、速度、半径、波次和基地生命仍待对应阶段验证。
