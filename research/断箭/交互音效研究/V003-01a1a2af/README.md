# 断箭交互与空中音效研究

V003研究使用两段作者公开教学、官方手册、本地构建26273833的原始表、GUI与VFX资源以及原FMOD事件。工程师最新指定避免启动原作测试游玩，已退出此前刚启动的原作；未产生有效实机观察，后续仅研究视频和只读静态资源。

[视频审阅记录](视频审阅记录.json)保留来源、完整媒体摘要、解码覆盖、字幕识别间隔、观察时间码和未核实项。[机炮特效原始字段](机炮特效原始字段.json)保留M230与MinigunAircraft预设、集合指针、曳光参数和不同碰撞类型的对象关系。视频为2025年教学，不代表本机较新构建的每一项运行行为；字幕OCR与连续选帧辅助分析，不宣称逐帧人工看完或听审通过。

M230与GAU8的InfantryImpact和GroundImpact均指向同一30毫米地面爆炸对象，不能按名称随意替换成血肉声或大火球。原作资源为Unity VisualEffect图，网页用Three.js重建小型闪光、烟尘和曳光；原始HDR颜色与尺寸不直接照搬到低分辨率画面。

方法入口：[公开视频审阅脚本](../../../../scripts/审阅公开视频.py)、[资源索引与提取](../../../../scripts/断箭/索引交互资源.py)。行为迁移、原始值和网页适配差异见[设计经验](../../../../docs/地图与载具/断箭交互设计经验与原型约定.md)及[靶场模块](../../../../src/载具靶场/README.md)。
