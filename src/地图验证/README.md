# 地图验证模块

## 当前统一原型

8784正式显示名为“战术演训原型”，副标题“Airbase全图 · 空地载具验证”，从根目录[打开战术演训原型.cmd](../../打开战术演训原型.cmd)启动；旧载具靶场快捷文件兼容转到同处。[启动器](../../scripts/启动战术演训原型.py)读取固定配置，复用r14地图及独立r17命名副本，拒绝源码或服务身份漂移。命名变更、实际双浏览器回归及旧版保留见[实施记录](../../docs/地图与载具/战术演训原型统一命名-实施记录.md)。

正式库revision7及原性能证据保持；r17只改显示文案，原r16／game-r01长测不改写为新样本。以下源码目录及内部地图ID继续按既有约定使用。

流式显示采用准备与提交两步：待请求不直接清空当前画面。当前可见区块仍覆盖新相机视口时保持细节，新地表、材质和植被全部准备后同步切换并释放旧引用；跳转出覆盖范围才显示粗总览。过渡期间的新旧资源均计入原预算；最多49块实际可见细节不放宽。取消或失败清理尚未提交的资源，不能留下无归属纹理。`displayCommits`与`overviewFallbacks`用于检查移动和缩放中的切换行为。

固定Three.js版本的默认深度材质跨无贴图与有贴图对象复用，可能在无贴图绘制中上传旧uniform指向的已释放纹理。单材质场景实例使用按源材质缓存的`MeshDepthMaterial`，由源材质的dispose事件一同释放；源贴图仍由区域媒体引用计数管理，不另行复制或提前销毁。

近景与总览属于两套显示集合，跨越500米水平跨度时先显示已就绪粗层并撤下旧集合，再准备另一集合，避免两套完整几何同时驻留超过原预算。同层平移和缩放继续保留覆盖视口的旧区，不恢复每次区域请求先隐藏细节的做法。

## 全图模块化规划

区域就绪、显示与模拟分别驻留、缓存预算、多层支撑及释放要求见[Airbase全图与场景资产双层入库实施计划V004](../../docs/Airbase全图与场景资产双层入库-实施计划.md)。工程师已允许省略草丛并调整植被以优先保证网页性能；源数据、原型及作者布局保留，运行显示数量单独统计。全图A0至A4技术实施与本地revision7发布已完成，人工验收待审，具体范围见[全图报告](../../reports/断箭/Airbase全图与双层入库验证报告.md)。下述接口开发与旧运行段落保留相应阶段语境，当前结果以报告和冻结证据为准。

`airbase-streaming-scene-v1`清单将粗总览、地表、支撑、实例页、原型和每份媒体摘要分开登记。网页不读取Blender或原游戏输入。`heightAt`未知时返回NaN；`querySupport`区分pending、unsupported、ready。`prepareRegion(owner,bounds)`保留租约，`releaseRegion(owner)`仅释放对应消费者，`dispose()`取消本实例请求和引用。区域接口9组专项检查通过，但新增全图显示、碰撞页和媒体管理仍须实际浏览器与独立几何核验，不沿用旧2公里性能结论。

全图静态候选入口为`python -X utf8 -B scripts/断箭/预览全图.py --directory 本轮运行目录 --revision 新服务修订 --port 未占用端口`；须先登记服务依赖。服务冻结源码与清单白名单，内容寻址媒体允许HTTP缓存。`验证全图显示.py`在可见Chrome或Edge检查静态显示、草丛省略、切换、预算及取消，正式载具负载、限速和180秒回访另验。

镜头与全局细节层按计划V004的补充授权执行：最高相对观察中心9000米，中景100米、远景800米为候选参数，实际阈值继续实测。Ebbtide参考只依据开发者公开说明的连续地图缩放与战斗继续，不宣称知道其LOD内部算法。相机目标优先读真实地面或受控粗地形，不能固定零高度后进入高地内部。当前静态候选与后续载具入口分别记录验证。

## 载具候选适配

植被保留LOD0／LOD1及原生LOD2图集。密集区的LOD1完整提交可能超过四千万面，不能凭“原生低细节”名称视为性能合格。候选可用原生图集的两三角形载体替代降级树木，真实作者矩阵中心、大小及碰撞保留；相机旋转或俯仰变化触发半球图集的相邻四帧混合。四边形及实例帧属性分别释放并计入缓冲预算。网页适配须单独审图及采样。

候选负载配置在异步等待前同步重建单位卡片，避免帧循环读取已重置的单位。采样器一次读取running／completed状态，失败保存错误堆栈及最后Benchmark，避免完成瞬间的状态竞争。

`地图运行.mjs`保留旧2公里契约，新清单显式进入`全图显示.mjs`及`attachStreamingSimulation`。单位、导航块和弹丸分别持有精细页租约；显示回收不释放这些引用。默认出生区和局部网格在交互就绪前完成，必需声音下载与单位准备通过同一个4并发队列；正常启动不靠点击后再补记必需下载。独立候选源码由脚本复制，当前尚未据此宣布共享靶场源码已合入或A3通过。

局部路径工作器只保存至多6块静态网格，先用125米成本选候选方向，再用4米网格及真实Collider、坡度、水域和连续支撑复核。未知目的地命令进入准备状态；无连续通行则返回明确不可达。0.3米地表台面合并为同一行走支撑，真正分离表面保留参考高度；固定翼机动边界采用实际非对称范围及外侧1300米缓冲，安全高度从该范围源几何重新估算。连续弹道直接与源三角形求交，不能拿最高高度面阻挡桥下射线。

网络记录把实际传输、编码响应体、解码体及唯一内容分别列出。静态源码不采用永久HTTP缓存，内容寻址媒体允许复用；原始完整文件表继续作为服务和交付依据，客户端仅删去模拟打包后不会单独请求的重复条目。限速启动和真正移动仍须逐次通过15秒，未达标保留失败并修复，不能只引用回环时延。

## 运行契约

全图实例数据采用独立`airbase-instance-pages-v1`契约，由[分页入口](../../scripts/断箭/分页全图实例.py)生成，`实例页.mjs`提供浏览器及Node共用的BAIP回读。16字节头记录身份、版本、计数和104字节记录长度；每条保留原型、来源组、原编号、跨界／树木标记、列主序矩阵及完整包围盒。独立回读检查页摘要、来源唯一性、125米所有者及所有相交块引用。草丛密度不被误当成固定实例。该数据层尚须与全图显示和模拟驻留接入，不据此宣布地图已经流式运行。

`地图运行.json`包含米制`bounds`、区域转换、`ground`、高度文件和编码、建筑`prototypes`及稳定`instances`。实例保留源矩阵、凸占地、垂直范围与跨界标记；同一原型按125米空间归属建立实例批。高度来自实际高细节地表和道路最高支撑面，空洞为NaN，越界返回未知，不补平面。

加载后提供`heightAt(x,z)`、`obstacles`、`root`、`groundMeshes`、`visibleGroundMeshes()`及核验叠加。碰撞与导航是全局数据，不随可见渲染块移除。静态碰撞采用作者旋转后凸占地棱柱；M1A2动态碰撞使用5.3米保守圆形余量，规划使用5.8米预留转向空间，不模拟悬挂或炮管精确扫掠。超过30度、无支撑及越界区域禁止通行。

作者实例矩阵与原型内部节点分别检查行列式。源谷仓`Farm_BarnO_L`含镜像子节点；运行时只对该网格克隆几何、烘焙子节点变换并交换三角形绕序，保留作者放置矩阵。`mirroredPrototypeMeshes`记录处理数量，浏览器遍历实际静态实例矩阵确认负行列式为零；源GLB与Blender工程不改写。

## 分块与共享

2公里清单额外包含256个125米地表`chunks`、共享`assets`及`streaming`。低精度总览常驻，局部块串行加载；所需块齐备后整体切换，跨度480米以上显示总览。最多驻留49块，旧块按最近使用顺序回收几何和材质；高度与碰撞始终可用。34种建筑原型预载，162作者实例按125米位置组成实例批；跨块建筑只绘制一次。

独立页面开启Three.js文件缓存，内容摘要图像复用下载与KTX2转码；同名同采样参数纹理共享GPU对象。有限的256张地表图和原型图可驻留，块回收不销毁被其他材料引用的贴图。`stats`记录驻留、待加载、回收、总览与错误；`visibleGroundMeshes()`用于射线核验当前真正可见的地表。纹理字节是含mip和阴影的估算，不能替代驱动显存测量。

## 显示与验证

机场候选局部镜头默认跨度58米，旧城市和小靶场保持原96米。2公里地图默认地面出生间距24米，以控制密集初始编队的局部提交；数量和资源规格不变，100单位代表交战仍使用原固定28米锚点布置。地图模式按视锥压紧载具显示实例；实时投影同时核对光源视锥和可见地面接收范围，保留画外投影者。总览继续采用既有阴影分级策略。鼠标地面拾取、车辆高度和坡面朝向、靶体、弹道地面命中、选择环及底影读取同一高度。

“核验叠加”显示125米参考格、建筑占地和真实道路三角形；正常审图与性能采样关闭叠加。调试图不能代替正常外观审图。固定翼使用高于区域建筑的安全高度和外侧机动缓冲，不含机场起降。

## 入口与证据

在项目根目录运行`python -X utf8 -B scripts/断箭/预览地图.py --directory 候选交付目录 --revision 未占用服务版本 --port 8780`。只绑定127.0.0.1；占用端口拒绝启动，源码快照拒绝覆盖。服务身份、路由摘要和冻结源码保存在交付目录。

`验证地图.py`提供Chrome／Edge真实键鼠、五次切换重置、音频解码、2公里90秒跨区和60／60／180秒负载；`--window`记录可见窗口，否则仅为无窗口证据。跨区每秒检查25条实际可见地表射线并记录截图，回访核对回收与重载。解除垂直同步上限后记录整帧分位和实际移动、模拟、可见、发声数量，不将CPU耗时当成整帧性能。命令与来源限制见[地图提取说明](../../scripts/断箭/地图提取说明.md)。


媒体计数另含等待解析的重建GLB及外置图像Blob暂存，释放或取消时在finally扣除，转码缓存单独计算。显示过渡和预取仍计入地图CPU预算；下载缓存口径另列，不把这些数值直接相加冒充进程总内存。

中／远景实际投影超门限时，可逐字节回退已核验近景GLB及其纹理，未失败的层级保持原字节。全图总览对实际镜头中源世界包围盒八角的屏幕矩形对角线≤1.5像素的建筑，使用相同世界包围盒和真实源图平均底色聚合；`aggregateInstances`与`aggregateMaxDiameterPixels`记录范围。原形和派生轮廓都受该屏幕包围范围约束，近处继续真实几何，不因拉远停止模拟。


首次流式装配先应用地图默认镜头，再同步显示和单位，避免58米默认区域、96米构造初值和复位镜头重复加载。就绪验证要求显示pending与转码均为0。近景纯旋转只更新现有植被实例帧属性，不释放地表和重建区域；远景旋转仍重新核对屏幕聚合范围。


原生替身的尺寸和偏移来自Unity，作者原型GLB为(x,y,-z)坐标。偏移Z及取帧视向Z必须转换后再应用作者实例矩阵；来源参数保持原值，不把原生参数直接当成GLB局部坐标。五方向审图同时检查中心、朝向及颜色。


可选背景载荷使用原生Splat及12层底色。有效支撑需要背景、靠近边界或水域时准备全局源背景；其就绪后停绘区块内同源背景，避免同位置两次绘制造成深度竞争。显示替换不修改BAGE／BACO、源孔洞、实际地面选择或单位驻留。

独立`water`载荷保留原池塘与外围海面。它与替换后的背景分别加载、计数和释放，不把物理页含水当成画面已有水。`visibleWaterMeshes()`提供实际渲染对象，`waterReady`／`waterMeshes`记录驻留；池塘点的可见网格射线高度须与物理水位一致。


活动命令以`command:单位ID`持有目标8米邻域的精细数据。新增目标准备仅清未引用缓存，并为单位和局部寻路保留12MiB余量；该余量包含在原64MiB模拟预算内，不放宽上限。目标未准备时地面／旋翼等待，固定翼继续安全盘旋；有效支撑、坡度、水域和静态碰撞核验后才执行，真实不可达显式提示。取消立即释放目标引用，重置核对协调表及实际owner／pending表；旧异步回调不能删除新的租约。

临时消费者没有有效owner且所有准备操作已结束后，代次和操作表一起回收。不得在旧操作尚未结束时复用取消代次；旧信号不能撤销新引用。区域接口专项覆盖1200个短生命周期引用、软预算余量及旧信号复用。粗路由阻断记录第一条相邻格边，异步粗路由／局部准备每次返回后都重核命令及epoch。


载具正交相机的最低世界高度为本图安全飞行高度加40米，避免聚焦空中单位后落在近裁面后。屏幕跨度保持原缩放方式；中景至少180米水平跨度、远景至少1290米，与两像素投影核验条件绑定，不能只因抬高观察点而降低近景几何。聚焦高度扣除当前位置粗地面，普通城市和旧小靶场保持原参数。
