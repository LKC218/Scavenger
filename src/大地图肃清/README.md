## 动画来源

当前载具使用原作模型、武器部件及已核炮口／转轴；位移、转向、炮塔／炮管动作、飞行高度与盘旋由网页代码驱动原作模型节点，未直接移植整套原作载具动画片段。M1A2炮管按5个完整连接分量作有限运行派生，炮管810三角形、剩余炮塔7690三角形，源GLB未改；防盾及附件仍静态。M2使用实际网格控制链。履带、悬挂、后坐力、旋翼和起落架等专属动作进入G05／G06逐车型卡，分别登记原作可用项、代码驱动项和待补项，不因模型存在就标动画完成。

丧尸使用原作九段骨骼片段中的四主状态，网页GPU共享采样播放；原生片段、烘焙近似与规则状态机分开记录。

## 数据归属

主入口签发命令序号，C规则检查本轮身份并只执行一次。A只持有镜头／选择，B只消费状态与事件。显示插值不改变当前规则位置；渲染分级、静音和特效预算不改变人数、听觉或伤害。规则公开视图停止更新失联敌人的位置，最后发现位置带时间。

新增车型通过配置复用“发射→声源→尸群响应→命中→伤害／死亡→反馈”；炮口、射界、移动射击及专用能力逐车核验。原作值、网页适配与人工接受值不混写。

## 运行与检查

本机候选入口建议8810，使用[本模块工具](../../scripts/大地图肃清/README.md)冻结源码与资源后启动。服务只读取本批白名单，运行媒体来自统一库revision7、原作双角色r03及独立视听派生，Three.js固定0.187.0。

测试专用`window.scavenger`提供规则、交互、镜头、表现、重置与采样句柄；正常界面不展示内部数据字段。正式性能须在Chrome／Edge前台串行、固定配置下测量，原生窗口焦点与页面可见状态均留证。无窗口检查只作为技术检查。
