# 网页资源验证台

当前日常浏览统一使用根目录[打开前线资产库.cmd](../../打开前线资产库.cmd)及http://127.0.0.1:8767/。以下保留早期独立验证台的职责和历史流程，不另提供同用途的根目录资产库快捷文件。

运行`python -X utf8 -B scripts/资源优化/验证服务.py`，访问`http://127.0.0.1:8770/`。这是独立整库优化验证入口，不替换正式资料库或当前靶场。

`index.html`提供原件与派生切换和音效播放；`app.mjs`接入同版本Three.js的Meshopt、KTX2及骨骼动画加载。服务仅绑定回环地址，媒体来自冻结盘点与通过回执，源码固定白名单，工具目录限定Three.js固定版本。页面不向外部CDN请求资源。

当前默认保留原版几何，贴图上限1024且含Mip链。静态载具另有候选细节层；骨骼角色不套用静态减面。验证钩子供自动化完整加载、动画采样与截图比较使用，程序通过不代替人工外观和听感验收。

清单包含未入正式资料库的历史候选，以源摘要唯一标识；正式ID和原待修状态由盘点记录关联。不要把全部候选都视为已验收的正式游戏资源。

## 游戏派生浏览入口

统一后的[前线资产库](../../打开前线资产库.cmd)直接选择当前保留的256／512与几何细节层。早期独立版本清单曾在模型名中标注256／512和几何0／1／2：几何0为完整拓扑，1和2为静态细节层；骨骼、动作模型只有几何0。旧页面原版按钮与游戏派生按钮的对照仅作历史流程说明。不同细节层分别携带贴图，当前尚未实现跨GLB外部贴图共享。

本入口复用此模块的显示和骨骼采样界面，专用清单与回环服务由`scripts/资源优化/游戏版服务.py`提供；不覆盖旧模型库或正式资料索引。显示效果自动核验不等于工程师主观签收。
