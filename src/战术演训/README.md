## 操作

- 左键点选、拖框，Shift增减；标签和卡片可辅助选择。地面／空中／全部筛选保持一致，Tab循环鼠标附近的重叠单位。
- WASD、中键拖动平移，Q／E水平旋转，滚轮围绕地面落点缩放；俯角候选48度。默认水平视野220米、最近70米，最远沿Airbase全图范围，保留总览。世界内单位标签上的滚轮也可缩放，侧栏和表单继续隔离。
- F或“聚焦”定位一次，“跟随”单独持续跟随一个单位；手动平移或点击小地图退出跟随。
- 右键按住预览，拖动设置到达朝向，松开提交；Shift追加。普通有效新命令立即替换当前任务并清空队列。
- 多车保留相对队形并拉开间距，拖朝向时展开横队；空地分别安排落点，固定翼到目标区域附近盘旋。
- X或“停止”清空移动队列：地面停车、直升机悬停、固定翼继续盘旋。Esc只撤销尚未提交的预览。
- 路径、终点、朝向和队列持续反馈；地形准备与真正不可达分开显示。已知非法目的地不提交、不擅换终点，保留该单位原任务并显示拒绝原因；其余可达单位继续。
- 直升机以运行基准点保持局部离地30米，提前平滑越障；前方未知时悬停。高度数字与完整辅助线同基准，机身几何中心用于选择、标签和构图，不混入高度数字，避免多出原约2.6米偏移。近景聚焦兼顾直升机与脚下投影，极高状态优先保证机身可见；固定翼保持机身聚焦。
- 默认五架以24米二维分行，地形投射后复核间距，不同高度不再承担摆场去重。正常到达须实际完成高度尾段并归零升降速度；手动停止仍按当前高度悬停。

## 接口与检查

`Commander`保留选择和移动入口，增加`layerFilter`、`setLayerFilter()`、`following`、`toggleFollow()`及显示同步后的`afterSync()`。`Battlefield.projectUnit(id)`提供实际机身CSS位置供选择、标签和回归使用。

`Simulation.planCommand(ids,command,append)`只生成预览，不改变执行任务；`command()`返回受理数，`lastCommandResult`保存可序列化的逐项结果。普通非法命令拒收，可受理的准备中命令替换旧任务；异步真正失败不恢复旧任务。输入、规则和界面共用这些状态，不凭短提示推断执行成功。

## 局部高度的数据边界

高度模块只读使用既有地面支撑、碰撞、实例页和下载接口，并持有自己的区域租约，不反向修改地图模块。树干约6米的源碰撞不能当作树冠高度；局部原实例BAIP完整世界边界仅作保守飞行安全包络，不冒充精确碰撞。

前瞻90米、水平包络14.5米和顶部8米余量为本轮AH-64D候选；半径依据实模全朝向包围角约13.933米留余量。局部页复用既有4并发下载、身份校验和有限缓存，不每帧扫描全图；32页／8MiB为受控计数预算，不宣称测得浏览器真实堆内存。后续地图接口变化集中在高度模块适配，不让输入与显示直接管理其租约。


## V004贴身名牌

当前工作源基于原V003完整源码，新增`AttachedLabelLayout`，仅在局部槽位布置；拥挤时降级为紧凑兵种图标，不在全屏寻找空位。主体投影排除旋翼及炮管，真实拾取仍保留所有实际几何。名称和高度只在主名牌呈现；高度投影用蓝色虚线，短实线表示名牌归属。悬停以`setHoveredUnit(id)`同步，键盘聚焦也可强调名牌。仅悬停时按指针移动节流50毫秒射线检测，拖动期间不额外检测。

选中、悬停、其他单位按优先级布置，标签宽高与DOM显式一致；引线和角标均不拦截输入。原地图、规则、资源和命令语义保持原接口，无新增跨模块依赖。局部极密集时允许隐藏低优先级名牌，侧栏仍可选择；人工可用性待复测。
