## 约束边界

- 任何已接入模块不得复制本目录下的颜色令牌或载具剪影路径，必须通过本机白名单静态路由 `/ui/*` 同源加载，由 [检查项目结构.py](../../scripts/检查项目结构.py) 自动校验。
- 新增或修改语义令牌组、剪影/情景图标键名后，须同步更新 [全局 UI/UX 规范](../../docs/全局UI-UX规范.md) 与活体规范展示页；严禁修改 `8767`、`8768`、`8769`、`8780`、`8781`、`8784`、`8811`～`8814`、`8794` 等历史 SHA-256 冻结端口快照。
- 本轮 V2.1 双浏览器验证证据保存在已忽略目录 `local-data/界面规范/V003-c7c1e6f7/`（历史 V002 与 V001 证据保持原样）。
