## 十三款交付与配置

[角色配置](角色配置.mjs)提供单款／十三款清单检查、固定种子的均匀分配、逐款数量和采样完整性汇总。逐款使用真实骨骼数，不要求全部23骨；模型分配使用独立随机流，避免改变相同种子的导航负载。少一款、重复源网格或逐帧统计缺失不能标为完整十三款证据。

[群体资源交接](../../scripts/群体资源交接.py)只读核对约定交接JSON、双档文件、回执及当前统一库指针，生成服务可用的白名单和不含本机路径的资源清单。8769已接入冻结`ZOM-13-261103-003`及统一库revision4，13款双档摘要与默认档HTTP核验通过。256档共2580544字节；编号11真实21骨、约0.967米，其他款保留各自身高。完整性能以[混合报告](../../reports/丧尸模型/十三款混合群体性能报告.html)的样本身份与状态为准，不能从资源技术通过推断容量。

交接目录为本地`local-data/丧尸模型/十三款优化/交接/`。资源对话唯一写`当前交付.json`，性能对话唯一写`性能协作状态.json`。技术通过、朝向与落地验证、人工外观验收分别记录；初批技术通过但朝向未统一的资源不作为最终采样输入。最终交付与源码冻结后，新批次使用大于33.3毫秒的长帧阈值；旧单款样本不改写。

纯配置检查运行`node scripts/验证混合角色配置.mjs`，只证明分配与证据完整性规则，不证明GLB可加载或FPS达标。冻结资源核验使用`python -X utf8 -B scripts/群体资源交接.py`；尚无有效交付时应拒绝继续，不取中间批次替代。

## 当前混合采样与归档

选择“十三款均匀混合”或“编号0单款对照”，明确标注浏览器，进行20／60／180秒采样。“完整矩阵”依次执行500单款开阔60秒、100／300／500混合四模式60秒、500混合开阔与通道各180秒，共15组约22分钟。采样锁定角色、浏览器、数量、画质和镜头；窗口不合格或归档失败时停止，不自动抢前台。

同款共享几何、材质、贴图与片段，每只独立骨架、Mixer及相位，仍是逐只蒙皮绘制。逐款记录实际数量、视锥、动画、移动；缺帧或分母变化标记不完整。保留共同来源尺度和不同体型，自制待机2秒、移动1.25秒；人工外观和动作观感待验。

[群体采样归档](../../scripts/群体采样归档.py)由服务调用，约0.5秒只读观察Windows前台目标进程，记录覆盖、间隔与比例，不记录其他应用名称或标题。结合页面隐藏／失焦判断，短测和无效窗口保留数据但不作为稳定60帧验收。样本通过本机同源接口自动独立保存到`local-data/丧尸模型/性能测试/十三款混合/ZOM-MIX-261103-001/样本/`，JSON／CSV逐帧包含各款四类计数，不覆盖旧证据。

服务启动时冻结源码字节、资源清单和源码快照；运行中源码改变会拒收新样本，须重启后重测。GPU查询异步返回，有效数量单列，不阻塞等待最后查询。矩阵只保留最近一组结果引用，避免无用历史样本常驻JS堆。

采样后运行`python -X utf8 -B scripts/生成混合丧尸性能报告.py`，核对JSON／CSV帧数、帧间隔和逐款列，重算FPS与完整判定，再生成独立离线报告和研究摘要。不要在采样期间运行报告分析、Blender渲染或其他WebGL回归。遵循[模型与音频优化复用指南](../../docs/项目开发经验/模型与音频优化复用指南.md)，本实验没有声音负载。

真实UI下载与自动归档的帧间隔、逐款四类计数、配置和摘要核对通过。GPU查询异步回填：本次通道手动晚下载的最后2帧GPU值晚于自动归档获得，摘要及正式报告继续采用归档时24625份有效查询，不混用晚到值；证据见本批次`功能验证/下载核验.json`。取消采样后恢复配置控件，已完成样本不删除。

## 操作

容量探索版提供100、300、500至2000每50只一档，以及2500、3000、4000、5000档。5000是界面保护上限，不表示该数量能达到60帧。超过500只时把生成位置收紧在左侧有效区域，并限制目标区宽度；密度增加会加重拥堵，不能外推成同等密度的大地图结果。地面投影缓冲随容量扩展，避免只增加角色却漏绘投影。

| 操作 | 行为 |
| --- | --- |
| 右键地面 | 整群移动到目标区域，关闭自动往返；障碍内目标拒绝 |
| 往返按钮 | 开启或关闭每24秒换向的往返负载 |
| WASD | 平滑平移，斜向归一化，松键快速停稳 |
| 滚轮／中键拖动 | 鼠标位置缩放／柔和旋转 |
| C／聚焦群体 | 按当时群体中心聚焦一次，不自动跟随 |
| F／复位镜头 | 恢复默认总览 |
| 空格／暂停 | 冻结群体和动画，镜头仍可操作 |
| 重置群体 | 保持当前数量与模式，按固定种子重新生成 |
| 采样／长测 | 重置群体，固定总览，预热10秒后记录60／180秒 |
| 快测20秒 | 预热10秒后探索数量边界，不作为稳定60帧验收 |
| 导出JSON／CSV | 下载最近完成样本，包含配置、环境及逐帧数据 |

三档内部尺寸为640×360默认、480×270及1600×900对照。三维采用最近邻放大，UI清晰；DPR固定1，关闭抗锯齿、实时阴影和后处理。地面投影通过共享实例绘制。场地58×44米，正交俯角约49.7度，默认垂直跨度43米，范围14至75米。镜头平移时间常数45／22毫秒、缩放50毫秒、旋转28毫秒、聚焦75毫秒；中键灵敏度0.004弧度／显示像素。参数沿用现有靶场手感并按人群尺度调整，不代表RESTAND官方参数。

## 模式与算法

- 静态角色：保留真实蒙皮网格和独立骨架，但暂停动画更新，用于渲染基线。
- 原地骨骼动画：500个独立Mixer和动作相位，持续播放移动循环，角色不位移。
- 开阔群体移动：同一批角色根据目标区推进、减速和局部分离，速度关联步频，停下混入待机。
- 障碍窄通道：中央约4米通道及两侧障碍，流场绕行，检查拥挤及转向。

群体规则不依赖DOM或Three.js。共享四邻接距离场按目标改变重算，跟随方向允许检查对角通行；能直达个人落点时使用直接方向。个人落点分散在目标区。均匀空间网格查询附近角色，局部分离限16个有效邻居，速度与朝向平滑，移动位置受膨胀障碍边界约束。

模拟固定30Hz，显示插值。每帧最多追7步、帧差最多0.25秒，超额时间写入`dropped`及汇总，不隐瞒低帧率导致的模拟欠时。动画使用真实时间推进。避让是平面软分离，拥挤时身体可能交叠；无足部IK、完整动态人群碰撞或战斗。

## 统计口径

FPS为帧数除以实际帧间隔总和，不取瞬时FPS的算术平均。P95／P99和最长帧保留真实长帧；统计面板4Hz更新，曲线显示最近300帧。CPU分别记录群体模拟、Mixer动画、位置及矩阵同步、`render()`调用。CPU提交含渲染器内部上传／准备，不等于GPU耗时，也不与GPU时间简单相加推算帧间隔。

GPU通过`EXT_disjoint_timer_query_webgl2`异步查询，丢弃disjoint结果；不支持时显示不支持，不阻塞等待GPU。几何和纹理字段是资源数量，JS堆是浏览器可选数据，都不是总内存或显存字节。每只独立骨架可能产生独立骨纹理，因此约500份纹理资源并不意味着复制500份原始贴图。

标准采样会锁定镜头和配置，保持500只在视锥内、动画持续更新；静态模式动画更新数为0。视锥计数不是无遮挡像素可见数量，角色可能被墙体遮挡。窗口隐藏或失焦会标记整组无效，取消后可重新采样。配置记录内部与显示尺寸、模式、种子、源码和模型摘要；环境记录Three.js、WebGL、GPU、浏览器UA、窗口、DPR及硬件线程数。浏览器完整版本由验证脚本另行记录。

### 内置浏览器与容量边界

工程师选择的稳定60帧标准为：180秒平均FPS≥60、P95≤16.7毫秒、超过33.3毫秒的帧少于0.1%，全群位于视锥内、持续动画、模拟欠时为0。短测先逐档探索，再缩小至50只步长，最高通过档需分别完成开阔与通道180秒复核。报告只称为当前机器、版本、窗口和640×360配置下的最高已通过档位，不承诺所有场景的绝对上限。

Codex内置可见面板按独立浏览器环境归档，UA为Chromium 156，不冒充本机Google Chrome或Edge。只读宿主观察脚本每0.5秒记录Windows前台是否为ChatGPT，不激活窗口；归档时同时核对页面状态与完整覆盖。全程宿主前台与前后台混合样本分别标记；混合样本可作实际压力记录，但不能写成独立窗口前台验收。工程师暂需使用电脑，Chrome／Edge独立前台矩阵保留待补测。

扩展数量前的500只源码快照及原始记录保留在本地批次，容量版有独立源码摘要。跨版本结果展示身份，不把它们当作严格的同版本增量对照。修改运行源码后必须重新加载页面、采样并记录新摘要。

本轮最高已通过档为700只：开阔180秒73.57 FPS、P95 14.3毫秒；通道180秒78.96 FPS、P95 14.2毫秒。两组宿主前台观察均100%，动画与视锥最小数均700，模拟欠时0。750只开阔P95约20.6毫秒失败；800只通道通过而开阔失败。此结论限本机RX 7900 XTX、内置Chromium 156、640×360及当前源码；日常工作并行，未建立整机空载条件。Chrome／Edge独立前台矩阵未完成。
