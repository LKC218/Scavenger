# 前线资产库

正式名称为“前线资产库”，副标题为“模型 · 动画 · 音效”，页面按“模型库／音效库”浏览，动画随角色关联展示。名称用于页面、启动提示和使用说明；资源ID、目录、API应用身份与冻结索引保持原有契约。

页面已按[前线资产库UIUX设计-实施计划](../../docs/资源与资料库/前线资产库UIUX设计-实施计划.md)重构为“战术资产检验台”，等待工程师进行视觉与交互验收。资源索引、媒体文件、API 契约及 8768／8769 服务未改变。

当前索引和媒体位于`local-data/资源库/`，版本6；143模型入口、253声音事件。980份当前文件使用分类、型号及规格构成的可读名称，媒体网址保留摘要身份，文件定位使用当前路由。静态模型卡片可选256默认、256远景和512细节档，512按钮提示贴图最大边长及手动选择含义；骨骼角色只切贴图档、保持拓扑及动画，点击加载后才下载。独立编号0显示为“丧尸角色00”，整包显示为“丧尸角色整包（来源对照）”，详情明确其非独立运行角色；旧名继续可搜索。详情展示实际字节与三角形，声音下载标注真实格式。当前模型与音频技术核验范围见[统一库说明](../../docs/资源与资料库/统一模型音频库使用说明.md)。

正式CLI与API均优先当前统一指针，路径边界限制到项目本地资源目录。原件按分类7z恢复，131份最新工程直接下载；不依赖下文V2媒体。旧端口跳转8767，历史小元数据仅作追溯。完整结构见[统一库说明](../../docs/资源与资料库/统一模型音频库使用说明.md)。

## 场景与独立原型

模型索引可读取独立的`scenes`集合，并按场景、建筑、道具、植被和草丛筛选；当前正式索引没有场景时不显示空的新增类别。场景关系面板可定位其确定版本的独立原型，来源、许可范围、技术、AI和人工状态分别展示。列表只请求缩略图，点击后才加载三维。深链接指向分页外资产时自动展开到该项，仍保留“显示更多”。

`viewer.mjs`解析GLB时使用真实模型URL的目录作为外置资源基址。A1的`airbase-reference-scene-v1`支持源地表、独立原型和作者实例矩阵，按清单`package_base`解析相对路径，最多4个模型请求一组；该源级样本不作为全图运行加载器或性能通过版。场景预览使用独立的取景及照明，单体模型延续原设置。切换及销毁释放模型、正在装配的对象和请求。

候选服务复用相同界面，顶栏标注“候选”，保留正式revision并另外返回候选摘要。服务端须显式传入候选清单并使用独立端口；`--candidate`不改当前索引。CLI、收集依赖及工程独立回读见[资源库维护](../../scripts/资源库/README.md)。

## 使用入口

项目根目录唯一资产库快捷文件为[打开前线资产库.cmd](../../打开前线资产库.cmd)，自动启动或复用本机服务，然后在内置浏览器打开固定地址。也可运行`python -B scripts/断箭/启动正式资料库.py --start`；兼容参数`--open`仍用于打开系统默认浏览器。固定地址为 http://127.0.0.1:8767/ ，仅本机访问；首次启动需要本机已有Python 3.11及以上。页面需要HTTP服务，不直接打开源码HTML。

桌面端为资产索引、模型检验台、上下文三栏，播放器是底部传输条而非覆盖层。选模型后直接预览图片，点击“加载三维模型”才请求GLB；拖动旋转、滚轮缩放。相关声音按运动、射击、命中、毁伤等用途分组，点播放即可试听。“音效库”使用同一三栏结构，可筛选用途、关联与技术状态，并逐条查看事件、检查与来源。窄屏改为单列资产优先，使用“切换资产／切换声音”底部抽屉；传输条固定在底部，正文预留等高空间。

模型与声音均提供“打开文件位置”：页面只提交当前资产稳定ID与该资产已登记的URL，服务端再次核对归属、`local-data`路径边界及文件大小，随后在Windows资源管理器中定位并选中；响应不回传本机完整路径。该操作不会打开、移动或改写源文件。

键盘操作：`/`聚焦搜索，`↑／↓`或`J／K`切换模型，`Enter`加载三维，`1／2／3`切换规格，`Space`播放或暂停，`L`切换片段循环，`F`重置视角，`Esc`清除当前声音。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html` | 语义结构和本地Three.js导入映射 |

## 历史数据与更新机制

索引及私有文件路径位于被忽略的`local-data/断箭/正式资料库/`。V1直接复用001模型、007声音、009关系；V2已将635份媒体复制到`资源/模型/空中或地面/稳定ID/`及`资源/音效/用途/`，来源副本归入`入库记录/`，整理验收归入`验收/`。媒体URL、ID、内容、关系和质量状态不变；旧快照和原始证据保留，956份已批准的交付重复副本已删除，其他任务使用的原路径保留。V1按显式归档解析回读，日常使用V2。

V2文件及CSV是历史查阅快照。旧WAV／GLB直接发布器已禁止回写；后续新增资源需补统一归档及规格验收后的发布流程，当前重建只写待入库，不自动发布。见[使用说明](../../docs/正式资料库使用说明.md)、[增量入库说明](../../docs/资源与资料库/资料库增量入库说明.md)和[历史整理报告](../../reports/断箭/模型音效资料整理报告.md)。

旧文件清理先运行[重复文件依赖审计](../../scripts/断箭/重复文件依赖审计说明.md)，核对同内容副本、旧快照、来源证据和其他任务路由；审计仅生成本地清单，不执行删除。正式版已复制媒体不代表旧路径可直接删除。

历史交付可通过[旧版归档工具](../../scripts/断箭/旧版资料归档说明.md)显式解析同摘要正式副本，原始提取记录及版本快照保持原样。归档解析仅接入维护核验和历史样例，不改变正式库默认查询、HTTP路由或当前版本；其他对话资源继续原位保护。

独立删除执行器只处理工程师已批准的956份冻结重复副本，先刷新引用和保护范围，再验证证据、正式保留媒体及原型使用资源。完整逐文件结果与实际完成状态以本地阶段目录中的删除回执为准；冻结候选清单仍保留生成时的历史状态。

## 核验与限制

运行`python -B scripts/断箭/核验正式资料库.py`核对全部媒体摘要、双向关系、CLI/API、HTTP范围请求及隔离增量发布。隔离测试写入tmp，不切换正式版本。页面人工操作证据单独保存到本地正式资料库；程序检查不等于逐模型外观或逐条听审。

129入口含变体；125通过、4待修。250事件中247技术通过、3静音待复核，149项尚未关联当前模型。音频为有限事件渲染片段，循环按钮只重复片段，不代表无缝循环。旧7条回退路径缺项仍保留。正式化指固定入口、来源与更新流程，不改变上述验收状态。

## 全图区域预览

revision7登记1个全图和133独立原型，原模型、音效与规格身份保持。正式入口验证由[验证正式场景.py](../../scripts/断箭/验证正式场景.py)检查CLI／API、全部HTTP入口、工程定位、实际区域加载、水面和切回单体的释放；旧消费者由[验证场景消费者.py](../../scripts/断箭/验证场景消费者.py)另验。完整操作见[使用说明](../../docs/正式资料库使用说明.md)，帧时间与限定AI视觉范围见[全图报告](../../reports/断箭/Airbase全图与双层入库验证报告.md)。

`airbase-streaming-scene-v1`由包内冻结的`viewer_module`及`runtime_module`按需加载，不把整图缩放成单体模型。`scene-viewer.mjs`使用640像素内部宽度、相对地面的正交镜头、机场近景／全图总览／重试按钮；缩放控制细节层及有界区域加载，列表仍只取图片。观察俯角保持在约50度以上，地图画布保持至少1.75的横向比例；高窄容器采用留边，不拉伸地图或扩大未准备的地面。全图总览固定北向。

切换到单体时停止整图帧循环、取消初始化请求、释放区域数据与媒体、关闭该组件的转码器和渲染上下文；单体沿用原灯光及规格。源码和解码器跟随不可变场景包保留，正式服务通过登记白名单读取，场景与原型分别登记，运行不读取研究JSON。
