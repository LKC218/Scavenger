# 地面载具共通能力检验场

> 现行规划见[正式策划书](../../docs/大地图肃清-正式策划书.md)与[开发目标及人工验收](../../docs/大地图肃清-开发目标与人工验收.md)。本模块是历史独立检验试验，已有模型部署及技术检查不计作新目标完成，也不构成新规则验收；当前仅整理文档，后续每目标先审设计再实现。

V001保留[旧策划与地面实装计划](../../docs/大地图肃清-策划与地面载具实装计划.md)中的平地试验说明，历史地址为<http://127.0.0.1:8809/>，不表示服务正在运行。该试验提供型号部署、共通状态、M1A2主炮和M548A3补给检验；8784战术演训原型、8794 V003通过版及8798角色候选保持独立。

## 历史状态与边界

- revision7共77条地面资源登记，75条静态`passed`允许基础部署；旧LAV参考车体和Flyer GMV两条`partial`禁止部署。目录允许部署不等于75款武器、动画或完整玩法通过。
- C-RAM和三种Patriot共4个型号在本候选中按固定平台处理，允许部署及耐久检验、不自行移动；这不表示原作牵引／部署流程已移植。
- 共通能力包括型号搜索筛选、部署扣点、单选、平地直线移动、耐久／摧毁、重开状态；当前在场上限16，数值集中于`GROUND_PARAMETERS`，均为待人工验收的候选值。
- 仅`model:US_M1A2`接入主炮对耐久靶攻击、有限弹药、瞄准和装填；其余武器及逐车差异待核验。炮弹按到达时间结算试验伤害，未复用旧防线完整扫掠碰撞、爆炸遮挡或炮塔节点动画。
- 仅`model:US_M548A3`接入后方装载、运输、近距补弹维修；购买物资只增加后方库存，仍需装载运输。双方需停稳、保持补给范围，移动等中断按实际交付结算。
- “检验操作”中的模拟受击按钮显式扣耐久，用于检验维修及本局永久损失；没有尸群接触伤害或其他敌方伤害输入。
- 场景尚未接入Airbase、障碍寻路、尸群、战争迷雾、诱饵、占区奖励、任务胜负、空中系统或游戏声音；不以本候选成绩声称全图或正式战斗通过。
- 13项纯规则检查通过；Chrome完成75条允许部署记录的逐项加载与部署，Chrome／Edge均通过真实操作及窄屏检查，HTTP白名单和运行源身份检查通过。详见[首版技术验证](../../reports/地面载具/共通能力检验-V001.md)；工程师人工验收待审，未认定G1完成。

## 历史启动与操作

按[维护清理规则](../../docs/版本退役与缓存清理规则.md)登记制作与服务读写依赖后，从项目根目录运行：

```powershell
python -X utf8 -B scripts/地面载具/服务.py --serve --port 8809
```

打开<http://127.0.0.1:8809/>；页面默认部署一辆M1A2，可从目录选择型号并部署。前台服务按Ctrl+C结束，端口占用不接管；服务、白名单、来源校验和冻结凭证见[工具说明](../../scripts/地面载具/README.md)。

| 操作 | 当前行为 |
| --- | --- |
| 目录搜索／筛选及部署按钮 | 查询77条登记；仅允许部署通过资源，按候选价格扣点 |
| 左键载具或已部署列表 | 单选单位；没有沿用旧原型框选、编组和命令队列 |
| 右键地面 | 对选中可移动单位下达平地直线移动；固定平台拒绝 |
| 滚轮／中键拖动／聚焦选中 | 缩放、平移、定位当前单位 |
| 选择耐久靶后点击攻击 | 仅M1A2执行主炮试射，空弹或越程明确拒绝 |
| M548A3回站装载 | 返回后方站后，从有限库存逐步装载 |
| 选择补给对象后开始近距补给 | M548A3维修存活单位并为已接武器补弹；不能复活摧毁单位 |
| 购买物资 | 扣点并加到后方库存，不直接加到前线单位 |
| 模拟受击／重开检验 | 显式检验损伤与摧毁；重开清除本轮部队、损失及库存状态 |

## 验证与交付

```powershell
node scripts/地面载具/验证规则.mjs
python -X utf8 -B scripts/地面载具/验证页面.py --browser chrome --port 8809
python -X utf8 -B scripts/地面载具/验证页面.py --browser msedge --port 8809 --all-models
```

规则检查覆盖型号能力边界、partial禁止部署、点数不足、固定平台拒绝移动、空弹停火、损失不复活、补给范围／中断、库存与费用等。浏览器脚本依赖Playwright与已安装浏览器，Chrome／Edge串行运行；`--all-models`仅证明75条记录能实际加载与部署，不等于逐车外观或专用玩法验收。HTTP和真实浏览器另检查模型解析、实际点击、布局、运行异常、重开及资源释放；技术检查、工程师操作验收和目标设备性能分别记录。

服务使用独立冻结输出和只读资源引用，源码／媒体摘要随服务身份保存。当前候选未替换旧载荷，没有旧版退役；日志、截图和身份凭证不可未经核查当作缓存，验收及任务关闭由负责会话按具体清单登记。
