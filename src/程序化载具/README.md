# 程序化载具流式渲染与展示模块

本目录承载全部 129 款美军空地载具的**单源同源三档 LOD 流式加载器、组件级 `InstancedMesh` 渲染器、单车 360° 展示与拉帘对比台、多车型混编演训场及自动化六视角视觉夹具**。

## 核心文件职责

| 文件 | 职责说明 |
| --- | --- |
| [载具流式加载器.mjs](载具流式加载器.mjs) | 解析定长二进制索引 `vehicles-index.scvi`、HTTP `206 Partial Content` Range 读取 `.scvveh` 归档包、全局跨车跨 LOD 去重 KTX2 纹理池与 LRU 显存释放 |
| [载具实例化渲染器.mjs](载具实例化渲染器.mjs) | 按 `(车型 × LOD × 可动槽位 × 材质)` 维护共享 `InstancedMesh` 池、±15% 距离滞回平滑 LOD 切换与 `LOD1` 近景实时阴影解耦投射 |
| [展示对比台.html](展示对比台.html) | 独立 `/showcase` 单车 360° 军械展台（Studio IBL）、原版 256 vs 新版左右拉帘实时逐像素对比、炮塔/旋翼动作演示与 `16:9 / 21:9` 680p 切幅 |
| [混编演训场.html](混编演训场.html) | 独立 `/battlefield` 多车型同屏混编场（10 车近景 / 30 车型×100 混编 / 300 压力探索 / 129 全车大阅兵）及 `70m ↔ 9000m` 连续缩放测试 |
| [视觉测试夹具.html](视觉测试夹具.html) | 服务 Playwright 六视角双盲轮廓 IoU、前景 SSIM、异常黑面与可动部件旋转验真的 `1208×680` 固定测试夹具 |

## 架构与规范边界

- 所有运行页面强制直接引用唯一渲染基线配置源 [渲染基线.mjs](../程序化地图/渲染基线.mjs)（`stylized-680p-v1`：`1208×680` / `1588×680`、`antialias: true`、`pixelRatio: 1`）与全局 UI 共享令牌源 [界面规范](../界面规范/README.md)（`/ui/令牌.css`、`/ui/组件.css`、`/ui/图标与标绘.mjs`）。
- 与既有 `src/资料库/`、`src/载具靶场/`、`src/战术演训/` 完全解耦，独立服务默认绑定 `127.0.0.1:8822`，不修改 `revision 7` 正式资料库指针及历史端口。
- 实施计划见 [程序化载具优化与流式渲染-实施计划](../../docs/地图与载具/程序化载具优化与流式渲染-实施计划.md)，工具链见 [程序化载具工具](../../scripts/程序化载具/README.md)。
