# 本地工作项看板前端（Plane 风格多 Agent 协作台 · V002）

本目录承载专属端口 `18800` 工作项看板的离线自包含单页应用（零外部 CDN、零构建步骤、原生 ES Module），由 [启动看板服务.py](../../scripts/工作项看板/启动看板服务.py) 提供静态托管与同源 `/api/v1/*`、`/api/v1/events` SSE 接口。

## 文件清单

- [index.html](index.html)：应用壳页面（40px 极薄全局栏、可折叠侧栏项目树、44px 面包屑与视图/筛选/显示子顶栏、模态弹窗与双栏详情抽屉挂载点）。
- [样式.css](样式.css)：Plane 风格中性炭黑灰阶视觉体系、可折叠 42px 空列竖条、紧凑 22px 微边框属性胶囊、暗色浮层菜单与双栏详情抽屉响应式布局。
- [应用.mjs](应用.mjs)：1.5px 线性 SVG 状态/优先级图标库、前端状态机、SSE 实时同步、按状态/模块/优先级三向分组拖拽流转、乐观锁冲突恢复、`Ctrl+V` 截图粘贴上传、筛选与显示偏好持久化。

## 核心界面与交互特性

1. **统一「工作项」视图（看板 / 列表一键切换）**：
   - 看板默认自动将空列折叠为 `42px` 竖条，点击可展开，拖拽卡片可直接投放到折叠竖条完成流转；
   - 顶部「筛选」浮层聚合优先级、成员/Agent、5 大业务域 × 13 模块与路径冲突开关，顶部「显示」浮层支持按状态/模块/优先级分组、切换紧凑密度与自定义卡片属性胶囊；
   - 新建工作项弹窗内置 `[需求]`、`[缺陷]`、`[优化]`、`[任务]`、`[资产]` 5 类一键规范模板胶囊、标签多选与实时字数计，与项目级技能 [workboard-item-create](../../.agents/skills/workboard-item-create/SKILL.md) 保持人机同标准；
   - 快捷键：`/` 或 `Ctrl+K` 检索、`C` 快速建卡、`B` 折叠侧栏、`Esc` 逐层退出。
2. **双栏详情抽屉**：左主栏专注需求（What）、实施方案（Plan）、模块上下文包、附件贴图（`Ctrl+V`）与活动评论；右 276px 固定属性栏集中维护状态、优先级、模块、负责人、AI Agent、分支、标签与作用域路径。
3. **模块上下文包**：按 5 大业务域管理职责范围、现有能力、架构红线、入口路径与验证命令，供 AI Agent 拉单时自动注入。
4. **Agent 与冲突雷达**：实时展示「方案待审 / 进行中」工作项的作用域路径重叠预警、全员执行态与 CLI 接入指引。
5. **项目与成员设置**：切换项目严格流转模式、新增项目、增改人类/AI 成员、管理 PIN 与 Agent Token。
