# 本地工作项看板前端（对齐 /ui-spec Code SSOT V2.2 · 多 Agent 协作台 · V003）

本目录承载专属端口 `18800` 工作项看板的离线自包含单页应用（零外部 CDN、零构建步骤、原生 ES Module），由 [启动看板服务.py](../../scripts/工作项看板/启动看板服务.py) 提供静态托管、同源 `/api/v1/*` / `/api/v1/events` SSE 接口，并只读复用项目唯一设计规范源 [src/界面规范/](../界面规范/README.md)（`/ui/令牌.css`、`/ui/组件.css`、`/ui/交互控件.mjs`、`/ui/图标与标绘.mjs`、`/favicon.svg`），与 `8800` 游戏主服进程彻底隔离且视觉基因 100% 同源。

## 文件清单

- [index.html](index.html)：应用壳页面（44px 烟炭顶栏 + 生化肃清三楔盾品牌标、可折叠侧栏项目推进态势卡与项目树、46px 子顶栏与唯一 L3 香槟金主 CTA、零原生 `<select>`、毛玻璃模态浮层与双栏详情抽屉挂载点）。
- [样式.css](样式.css)：桥接 Code SSOT V2.2 令牌（「A3 烟炭双金 × B2 战术微描边 × C4 外柔内锐」）、超宽屏自适应弹性列宽（`298px ~ 450px`）与 `44px` 语义色折叠竖条、`.card { flex-shrink: 0 }` 防压扁保护、常驻零模糊暗实底与低频毛玻璃浮层分层。
- [应用.mjs](应用.mjs)：消费共享 `createBrandLogoSvg` / `bindAllUiSelects` / `createEscStack`、侧栏实时态势快筛、三段式降噪卡片（人物去重 + 父子进度条 + 阻塞徽章）、SSE 实时同步、四向分组拖拽流转、乐观锁冲突恢复、`Ctrl+V` 截图粘贴上传、筛选与显示偏好持久化。

## 核心界面与交互特性

1. **统一「工作项」视图（看板 / 列表一键切换）**：
   - 看板默认自动将空列折叠为 `42px` 竖条，点击可展开，拖拽卡片可直接投放到折叠竖条完成流转；
   - 顶部「筛选」浮层聚合优先级、成员/Agent、5 大业务域 × 13 模块、父工作项专题与路径冲突开关，顶部「显示」浮层支持按状态/模块/优先级/父工作项四向分组、仅看顶层切换、紧凑密度与自定义卡片属性胶囊；
   - 父工作项卡片展示子项完成度胶囊（`↳ 2/6`）与底缘进度条，子工作项卡片顶部显示可跳转父单标识（`↑ SCAV-10`），未解除前置阻塞的卡片展示 `⊘ 阻塞` 微胶囊；
   - 新建工作项弹窗内置 `[需求]`、`[缺陷]`、`[优化]`、`[任务]`、`[资产]` 5 类一键规范模板胶囊、所属父工作项/前置阻塞选择、标签多选与实时字数计，与项目级技能 [workboard-item-create](../../.agents/skills/workboard-item-create/SKILL.md) 保持人机同标准；
   - 快捷键：`/` 或 `Ctrl+K` 检索、`C` 快速建卡、`B` 折叠侧栏、`Esc` 逐层退出。
2. **双栏详情抽屉**：左主栏专注父级面包屑、需求（What）、实施方案（Plan）、子工作项进度与一键拆分子项、模块上下文包、附件贴图（`Ctrl+V`）与活动评论；右 276px 固定属性栏集中维护状态、优先级、所属父工作项、前置阻塞（`blocked_by` 增删与下游依赖列表）、模块、负责人、AI Agent、分支、标签与作用域路径。
3. **模块上下文包**：按 5 大业务域管理职责范围、现有能力、架构红线、入口路径与验证命令，供 AI Agent 拉单时自动注入。
4. **Agent 与冲突雷达**：实时展示「方案待审 / 进行中」工作项的作用域路径重叠预警、全员执行态与 CLI 接入指引。
5. **项目与成员设置**：切换项目严格流转模式、新增项目、增改人类/AI 成员、管理 PIN 与 Agent Token。
