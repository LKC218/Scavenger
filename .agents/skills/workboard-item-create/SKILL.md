# Scavenger 工作项规范化编写与建单（workboard-item-create）

本技能用于将零散的口述需求、缺陷反馈、截图或工程/资产任务，规范化为**精简、结构化、15 秒扫懂、可直接被多 AI Agent 并行认领且防改撞**的本地看板工作项（专属端口 `18800`，对应 [看板工具.py](../../../scripts/工作项看板/看板工具.py)）。

完整模板、正反案例、标签与路径填写细则见 [工作项编写规范与模板](./references/工作项编写规范与模板.md)。

---

## 核心铁律（必须严格遵守）

1. **只写 What，禁写 How（与 `plan_md` 严格分工）**：
   - 正文（`description_md`）仅描述背景目标、触发场景、复现步骤、核心变更与验收标准，有效字数严格控制在 **150 ~ 350 字**（不含截图；硬上限 650 字）。
   - **严禁**在正文中粘贴源码行号、函数实现、多套技术方案或代码改造步骤；实施方案留待执行 Agent 在 `方案待审` 写入 `plan_md`。
   - 若顺手已定位到源码线索或根因推测，**不得写入正文**，须通过 `--comment` / `--comment-file` 作为工作项的**第 1 条评论**外置附在下方。
2. **统一标题公式（≤ 32 字）**：
   - 格式：`[类型] 对象/场景 + 核心目标或异常现象`（硬上限 42 字）。
   - 类型前缀必选其一：`[需求]`、`[缺陷]`、`[优化]`、`[任务]`、`[资产]`。
3. **实时元数据真源（严禁硬编码或私造模块/标签）**：
   - 建单或整改前，必须先执行 `看板工具.py meta --json` 实时拉取目标项目的可用模块、已有标签与成员清单。
   - **严禁自造不存在的模块名或标签名**；优先从当前项目已有标签中选配 1~2 个。
4. **作用域路径必填（激活路径防撞雷达）**：
   - 除 `backlog`（纯构想/暂不排期）外，所有工作项**必须填写 1~3 条项目相对路径**（`--scope`），精确到具体子目录或核心文件；严禁填写盘符绝对路径、越界 `..` 或过宽根目录（如单纯 `src`、`scripts`）。
5. **属性进侧栏，不堆正文**：
   - 状态（默认 `todo`，暂不排期用 `backlog`）、优先级、所属模块、标签、人类责任人（默认 `工程师`）、AI Agent 槽位与前置阻塞（`--blocked-by`）均通过结构化参数写入，不在正文重复罗列元数据。
6. **强制 `--dry-run` 门禁校验 + 工程师预览确认**：
   - 严禁未经确认直接写库。必须先运行 `--dry-run` 校验格式与活动项路径冲突，再向工程师展示紧凑的**新建预览卡片**，经确认后再执行真实写入。

## 标准执行步骤

### 第 1 步：实时拉取看板元数据与冲突态势

```powershell
python -X utf8 -B scripts/工作项看板/看板工具.py meta --json
python -X utf8 -B scripts/工作项看板/看板工具.py conflicts
```

- 确认 18800 服务已运行（若提示连接失败，提醒工程师双击根目录 [启动工作任务看板.cmd](../../../启动工作任务看板.cmd) 或按指令启动）。
- 根据工程师意图匹配 1 个最贴合的**所属模块**、1~2 个**已有标签**、合理的**优先级**及 1~3 条**作用域相对路径**。

### 第 2 步：起草精简正文、跑 `--dry-run` 校验并展示预览卡片

- 按 [工作项编写规范与模板](./references/工作项编写规范与模板.md) 选择对应类型骨架编写正文（优先写入 `tmp/` 下临时草稿或通过 stdin 传入，切勿把临时文件留在正式源码目录）。
- 先执行 `--dry-run` 做机械门禁校验与路径冲突预演（不写库）：

```powershell
python -X utf8 -B scripts/工作项看板/看板工具.py create `
  --title "[缺陷] 21:9画幅下固定翼投弹圈偏移" `
  --state todo `
  --priority high `
  --module "操作交互与战术标绘" `
  --owner "工程师" `
  --label "缺陷修复,UI/UX" `
  --scope "src/交互系统/指令与标绘层.mjs" `
  --desc-file "<临时正文文件路径>" `
  --dry-run
```

- 若校验报告存在 `[错误]`，必须先修正至通过；若触发 `[⚠路径冲突预警]`，必须在预览卡片中醒目标注冲突单号与重叠路径。
- 向工程师呈报**紧凑预览卡片**（标题、状态、优先级、模块、标签、负责人、作用域路径、冲突提示、附件、精简正文、可选首条线索评论），**等待工程师明确确认**（批量建单时先列全量清单再统一落库）。

### 第 3 步：确认后强制门禁建单并返回单号

工程师确认无误后，将 `--dry-run` 替换为 `--check-spec` 执行真实创建（如附带源码线索或问题截图，一并传入 `--comment` 与 `--image`）：

```powershell
python -X utf8 -B scripts/工作项看板/看板工具.py create `
  --title "[缺陷] 21:9画幅下固定翼投弹圈偏移" `
  --state todo `
  --priority high `
  --module "操作交互与战术标绘" `
  --owner "工程师" `
  --label "缺陷修复,UI/UX" `
  --scope "src/交互系统/指令与标绘层.mjs" `
  --desc-file "<临时正文文件路径>" `
  --comment "<可选：外置源码排查线索>" `
  --image "<可选：问题截图路径>" `
  --check-spec
```

- 创建后清理临时草稿（若在 `tmp/` 建了草稿，避免遗留），向工程师汇报生成的工作项编号（如 `SCAV-1`）、看板浏览地址 `http://127.0.0.1:18800/` 及已绑定的模块/标签/路径冲突状态。

### 第 4 步（按需）：存量工作项规范巡检与整改

当工程师要求检查或规范化已有工作项时：

```powershell
# 全项目只读规范体检（默认跳过已完成项，加 --include-done 可含已完成）
python -X utf8 -B scripts/工作项看板/看板工具.py lint --all

# 单条体检
python -X utf8 -B scripts/工作项看板/看板工具.py lint SCAV-1

# 整改前先预演，经工程师确认后再去掉 --dry-run 并带 --check-spec 回写
python -X utf8 -B scripts/工作项看板/看板工具.py update SCAV-1 `
  --title "[优化] 优化9km远景地形LOD切换流畅度" `
  --add-label "性能优化" `
  --scope "src/程序化地图/" `
  --desc-file "<整改后正文文件>" `
  --dry-run
```

- 看板完整架构与 CLI 说明见 [看板服务 README](../../../scripts/工作项看板/README.md)。
